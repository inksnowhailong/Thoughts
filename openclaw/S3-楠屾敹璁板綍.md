## 已完成的验证

### 1. 离线自测（公司机，Node 22 + tsx，`test/selftest.mts`）

```
npx tsx test/selftest.mts
PASS levels classify (28 cases)
PASS masker + stream unmask
PASS redact proxy json + sse + audit
PASS guard L2 confirm / proactive / L3
PASS habit extract + ask/yes/no/late-night
PASS weather skeleton no-key skip
```

覆盖内容：

| 项 | 断言要点 |
|---|---|
| 分级 | read→L0；S2 启动器命令→L1；启动器后接 `; del`→L3；`automations`→L1；工作区写→L1；写 `guanjia/`→L3；工作区外写、`..` 路径→L2；未知工具→L2；cron 会话 L1→L2、L2→L3 |
| D8 覆盖 | 未过期生效；过期、无有效期、作用域不符均不生效 |
| 脱敏 | 人名/房间/设备/路径（正反斜杠、JSON 转义）/IP 全部替换；计数正确；跨 SSE 分片的占位符正确回填 |
| 代理 | 假上游收到的请求体不含任何登记实体；JSON 与 SSE 两种回包都正确回填（含工具参数里的路径）；每次请求写一条 cloud 审计且审计不含原文 |
| L2 口头确认 | 首次拦下 → 用户说"确认" → 同参数放行一次 → 再调又拦 |
| 习惯 | S2 的 timeline.md 格式与 JSONL 都能抽出周期事件；时间词清洗（"记一下明天晚上八点交房租"→"交房租"）；重复运行不重复加；首次开口发问、答非所问不纠缠、说好建 cron（`30 19 * * <周几>`）、说不进否决表、23 点后不问 |
