## 遗留

0. **exec 闸门改由 S3 的 guanjia-guard 插件统一管。** S3 已经把这里的白名单并进插件：`launch-app.ps1 -Name <键>` 为 L1 直接放行，其余 exec 默认 L3，要微信审批。以后两边都不单独设宿主 exec 审批，下面第 1 条只作备用。插件还没装，要等用户本人运行 `install-s3.mjs`，在那之前家里的 exec 仍然没有任何闸门。

1. **（备用）exec 白名单没应用。** `exec-approvals.json` 已写好（main 代理：allowlist + on-miss + askFallback deny，只放行 `powershell -NoProfile -ExecutionPolicy Bypass -File C:\Users\inksn\.openclaw\workspace\tools\launch-app.ps1 -Name <键>`），但我这边执行 `approvals set` 被权限拦截。当前仍是 OpenClaw 默认 security=full / ask=off（全局放开）。需要用户在家里执行：

   ```
   openclaw approvals get --json > approvals-before.json
   openclaw approvals set --gateway --file F:\coding\guanjia\openclaw\exec-approvals.json
   ```

   应用后要复测"开LOL"；argPattern 是按 Windows 反斜杠路径写的，若 exec 的参数解析吞了反斜杠会匹配失败，届时把 argPattern 放宽成 `^-NoProfile -ExecutionPolicy Bypass -File \S*launch-app\.ps1 -Name [A-Za-z0-9_-]+$`。另外它会让 windows-host-tasks 技能（schtasks、切 Clash 代理）变成每次要审批。
2. **模型偶尔把思考过程写进回复**（DeepSeek-V4-Flash，约三成）：例如回复开头出现"原神的 target 是空的……按技能规则……"。已在 AGENTS 加"回复只放说给用户听的中文"，有缓解但没根治；语音侧会把这段念出来，需要网关/模型层处理（可换 Qwen 或在 S1 侧过滤）。
3. **提醒只进主会话**（`agent:main:main` 的 system event），微信和音箱都还收不到；等 S1 守护进程接主会话事件再播报。
4. **时间线"来源"靠模型判断**：CLI 测试被标成"语音"。已改规则"看不出写其它"，真实来源要等语音/微信入口实测。
5. **没有真正的 web_search 服务商**：想要结构化搜索需配一个 key（Brave/Kimi/Tavily 等）或给网关配代理后用 DuckDuckGo。
6. 原神未安装，`apps.json` 里 genshin 留空待填；全面战争三国有快捷方式但 Steam 库里没有 manifest，可能未装。
