# 管家推进路线图 v2（2026-10-09 下午重排）

> 取代上午的 v1。每个阶段开工前，先由 Opus 5.5 写该阶段的实现计划，你看过再派 Grok 4.7 执行；Opus 审改动；验收只认你本人用语音或微信做成。

## 架构（已定）

- 只有一个长期在线的主 OpenClaw。主线会话 `agent:main:main` = 你的语音 + 你的微信。
- 家人每人一条支线会话，放在主 agent 下，和你完全同权。L3 审批谁发起谁批，只认发起人本人；家人发起的同时通知你。隐私只靠约定，你已接受。
- 微信保留 openclaw-weixin 插件（MIT 许可，不 fork），在我们自己的插件里用钩子认人、处理消息；家人消息整理成摘要静默放进主线。版本锁定在 OpenClaw 2026.9.6 + 插件 2.4.8。
- 语音调主程序的 HTTP 对话接口（`/v1/chat/completions` + `x-openclaw-session-key`）进主线。
- 主线休眠：你空闲 60 分钟 → 独立会话整理记忆 → 复核无新消息 → 换新。开机先换新、后台补整理，第一句话不等。家人支线空闲 4 小时休眠。休眠状态显示在托盘。
- 费用不设上限，看每日报告。

## P3 微信接入：保留插件 + 钩子（Opus 计划，Grok 实现，你配合实测）

依赖 P1、P2（共用主线会话和队列设置）。路线已改：保留 openclaw-weixin 插件（MIT），不 fork，在我们自己的插件里用钩子处理。核实报告：`2026-10-09-wechat-hooks-check.md`。工作量约 4–5.5 人日（含分级插件、休眠配合和联调，这几块走自写桥接也要做）。

实现：
- 配置：一条 binding 只把你的 18f8 号并进 `agent:main:main`，家人的 ef79 号保持按人独立会话；`commands.ownerAllowFrom` 与 `commands.allowFrom` 一起配（只配前者家人的 `/approve` 会失效）；审批目标改成原样大小写的 ID；`approvals.plugin.mode: "both"`
- 我们的插件：收到家人消息 → 生成摘要 → 用 `enqueueNextTurnInjection` 静默放进主线（持久、语音轮也会带上、不算你的活动）；家人那一轮结束后抽出「需要你决定」的事，单独发微信通知你
- 分级插件：按微信号认人；待确认记录按「会话 + 微信号」存；审批描述写明发起人
- 所有主动外发（审批、通知、主动消息）都显式写明 channel、发给谁、用哪个号，不依赖「最后路由」（家人一说话就会把主线的最后路由改成家人）
- 锁定 OpenClaw 2026.9.6 和插件 2.4.8，关闭自动更新（插件依赖的运行时接口已过兼容移除日期，升级可能让微信入站整体失效且不报警）

已知做不到（不影响首期）：
- 消息正文不能改写，只能在模型看到前补一段说明
- 不能按账号合并连发，只能按渠道或会话
- OpenClaw 原生 `/approve` 不校验审批人。你已定「谁发起谁批」，所以这一块不用原生审批：由分级插件自己发审批消息给发起人，并在入站钩子里只认发起人那个号的回复（约多半天）

开工前实测（★ 要真发微信）：
- ★ 你一段时间不来信后，主程序还能不能主动发给你
- ★ 家人先在 ef79 号发一条，再测回复和主动发送（家人那个号目前没有发送凭证）
- ★ 语音发起的 L3 只到你，不会落到家人微信
- ★ 配好权限后家人的 `/approve` 仍有效
- 换新（`sessions.reset`）后插件继续投递到新会话；未读的家人摘要先导出再补注入

验收：你在微信办一件事；家人在微信办一件事，主线能说出家人刚才说了什么；家人触发一次 L3，家人收到审批、你收到通知。

## P4 休眠（Opus 计划，Grok 实现）

依赖 P2；家人支线部分依赖 P3。

- 检测：OpenClaw 定时任务每 5 分钟检查；只有你的语音和微信算活动
- 门槛：空闲 60 分钟；这一段至少 1.2 万 token 或你说满 10 轮；两次换新至少隔 2 小时
- 整理：导出这一段记录，独立会话整理成记忆文件；暂存、备份、逐个原子替换
- 换新：复核水位线（sessionId、最大事件序号、最后活动时间），没变才换
- 开机：先存临时交接并换新，后台补整理；第一句话不等
- 家人支线：空闲 4 小时、1 万 token 或 10 轮
- 托盘显示休眠状态；每日报告
- 配置：压缩只兜底、心跳隔离、工具输出裁剪；顺手修记忆晋升报错和两个定时任务的投递目标；补 `cost`（等单价）
- 上线顺序：先演练 3–5 天只整理不提交 → 打开提交 → 打开真实换新

验收：空闲一小时后再说话，它记得之前聊的事；关机重启后记得关机前的事；整理期间开口不被卡。
