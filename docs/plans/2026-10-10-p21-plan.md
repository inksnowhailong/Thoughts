### 主人反馈 1「时不时胡乱回我」——证据与根因（`tmp\voice.log` 20:42–20:57）

| 20:46:11 | `[我 0.36] 周老师点的不一样吗` | 放行，模型认真回"我不认识周老师" |

根因三条：没有唤醒词（屋里任何人说的任何话只要过声纹就进主线）；声纹门槛 0.30 太低（今晚被放行的全在 0.31–0.41）；碎音不过滤（单字也触发整轮）。

**声纹门槛取 0.45 的依据：** 今晚放行的 6 句乱回全部 ≤ 0.41；10-01 早上主人对着它说的话分数是 0.56（「管家今天的天气怎么样」）、0.48、0.47（另一句 0.41 本身就是一段识别错乱的话）；9-30 近距离注册后主人 0.60–0.74，关掉 AEC 后降到约 0.61。0.45 能挡住今晚全部乱回，同时放过主人清楚说话的样本。主人离远或带情绪时会掉到 0.45 以下（历史上见过 0.48），所以门槛在面板里可调，每句的分数和"声纹 0.xx < 0.45"的拦截原因都显示在面板上；如果主人自己常被拦，建议在 AEC 关闭的状态下重录一次声纹（用户验收「可选」一节）。

### 唤醒词匹配方案

- 识别文字里**任意位置**出现唤醒词就算（「管家，打开记事本」「打开记事本，管家」都行），去掉唤醒词和两头残留的标点、语气词，把剩下的话送主线。
- 按**读音**比，不按字形：每个字取全部读音（多音字都算，例如「乐」= le/yue），做常见模糊音归并（zh/ch/sh→z/c/s、声母 n→l、后鼻音 ang/eng/ing/ong→an/en/in/on），唤醒词每个字都对上才算命中；4 个字以上的唤醒词允许错一个字。所以「关家/管加/光价」都等于「管家」，「关键/管理」不算。拼音用 pypinyin（纯 Python、自带字典、MIT 许可，Task 1 安装）。
- 只喊唤醒词（或唤醒词加语气词）：不送主线，立刻放一声应答（TTS 上线后后台合成好的「在呢」，TTS 不在时用提示音），从应答结束起打开 20 秒免喊窗口。
- 免喊窗口：它回完**最后一句**（播放结束）后 20 秒内，或者一轮正在进行时，不用再喊；窗口里「好/行/对/要/是/不/停」这类单字回答也放行。`/say`（主程序让电脑念）念完不开窗口。
- 去留顺序：碎音（去标点后少于 2 个字、或全是语气词）→ 声纹（< 门槛拦下）→ 唤醒词（没有且不在窗口里就拦下）。每一步拦下都记一条带原因的记录，在面板上标红。
- 唤醒词、是否必须唤醒、免喊秒数、声纹门槛、打断线、最少字数、提示音开关、应答语都在 `F:\coding\guanjia\data\voice-settings.json`，面板改了立即写盘并生效；手工改文件 2 秒内生效。

- **网关准备 2.0–2.5 秒**（空闲几分钟后的一轮；紧接着的一轮只要 0.2 秒；重启后第一轮 7.8 秒）。耗在 OpenClaw 内部：重新打开会话库并做完整性检查、给 55 个工具建检索目录。本期不改（改 OpenClaw 内部或网关配置风险大）；后续可在 P4 精简技能和工具数，或做一个"保持会话库热"的小实验。

- **合成首句 1.3–2.2 秒**：本期把首句在逗号处的最早切点从第 8 个字提前到第 6 个字，首句更短，预计省 0.3–0.6 秒。
- 提示音（说完立刻"叮咚"）已经在 P2 上线；本期加上唤醒词后，它只在真正放行时响，不再对碎音乱响。
- 面板每句话都显示耗时拆分：识别、声纹、排队、网关准备、模型首字（查会话库得到；查不到就合并显示"网关首字"）、首句成形、合成首句、开始出声，以及"听完到出声"总时长。

### 面板安全设计

- 只绑 127.0.0.1；Host 必须是 127.0.0.1/localhost（挡 DNS 重绑定）。
- 面板页面 `/panel` 里带一个**每次语音进程启动随机生成**的令牌。别的网站的页面受同源策略限制读不到这个页面，也就拿不到令牌。
- `/api/*` 只放行同源 Origin（`http://127.0.0.1:18795`、`http://localhost:18795`）或不带 Origin 的请求，并且必须带令牌：读接口放查询参数 `token=`（SSE 的 EventSource 不能加请求头），写接口（控制、设置、模拟）必须放请求头 `X-Guanjia-Token`。跨站页面带自定义请求头会先触发 CORS 预检，控制口不回 CORS 头，所以跨站改设置、点退出都做不到。
- 旧接口 `/say` `/status` `/sleep-state` 不变（仍然拒绝任何带 Origin 的请求，供 speak 工具和脚本用）。
- 页面响应头：`Content-Security-Policy`（不允许任何外部资源、`frame-ancestors 'none'`）、`X-Frame-Options: DENY`、`Cache-Control: no-store`。页面里所有识别文字、日志都按纯文本渲染（不用 innerHTML），防止注入。
- 面板日志和落盘记录先过一遍脱敏（`Bearer …`、`sk-…`、`token=…` 之类替换成 `***`）。守护进程本身不打印网关令牌。

### 托盘固定到任务栏（调研结论）

Windows 11 22H2 起，系统在 `HKCU\Control Panel\NotifyIconSettings\<编号>` 下给每个托盘图标记一项，值 `IsPromoted=1` 表示固定显示在任务栏（不在「^」里）。这个键未公开文档，但被广泛使用，只改当前用户。做法：托盘出现 5 秒和 60 秒后各找一次 `InitialTooltip` 以「管家」开头的那一项，只在 `IsPromoted` 还不存在时设成 1；主人以后自己拖回「^」，系统会写成 0，我们不再动它。Windows 10 没有这个键，什么也不做。生效时机取决于资源管理器，可能要等图标下次出现（重启语音）才固定显示。不管成不成，桌面快捷方式「管家面板」和托盘右键「打开面板」都能打开面板。

### 顺带发现（不在本期范围，交给管理者）

`20:54:00` 那次启动 LOL 被判 L3，是因为模型写的命令形状是 `powershell -ExecutionPolicy Bypass -File "C:\...\launch-app.ps1" -Name lol`（带引号、没有 `-NoProfile`），而 `levels.json` 里启动器的 L1 规则只认 `-NoProfile -ExecutionPolicy Bypass -File C:\...\launch-app.ps1`（不带引号）这一种写法。所以「打开记事本」这类请求现在很可能也要审批。建议单独起一个小任务，放宽这条规则（允许引号、`-NoProfile` 可选），同时核对 OpenClaw 的 `exec-approvals` 白名单。本期验收不用开程序的句子。

```python
"""语音守护进程的可调参数（唤醒词、免喊窗口、声纹门槛、打断线……）。

存在 F:\\coding\\guanjia\\data\\voice-settings.json（data/ 不进仓库）。面板改了立即写盘并通知守护进程热生效，
手工改文件也会在 2 秒内被主循环发现并生效。文件坏了或某项不合法时保留当前值，不会把守护进程弄崩。
"""

from __future__ import annotations

import json
import logging
import os
import threading
from collections.abc import Callable
from dataclasses import asdict, dataclass, replace
from pathlib import Path

log = logging.getLogger("guanjia.settings")

SETTINGS_PATH = Path(__file__).resolve().parents[2] / "data" / "voice-settings.json"


@dataclass(frozen=True)
class Settings:
    wake_words: tuple[str, ...] = ("管家",)  # 识别文字里含其一才进主线（按拼音容错匹配）
    wake_required: bool = True  # False = 不要唤醒词（P2 的行为）
    follow_up_sec: float = 20.0  # 它回完最后一句后这么多秒内接着说，不用再喊
    spk_threshold: float = 0.45  # 声纹放行门槛
    barge_rms_min: float = float(os.environ.get("GUANJIA_BARGE_RMS_MIN", "0.004"))  # 打断线下限（原始输入 RMS）
    min_chars: int = 2  # 去掉标点后少于这么多字的片段直接忽略（免喊窗口里"好/行/对/要/是/不/停"例外）
    earcon: bool = True  # 说完话立即放提示音
    ack_text: str = "在呢"  # 只喊唤醒词时的应答（TTS 不在时改放提示音）


_LIMITS = {
    "follow_up_sec": (0.0, 120.0),
    "spk_threshold": (0.0, 0.9),
    "barge_rms_min": (0.001, 0.05),
    "min_chars": (1, 6),
}


def from_dict(data: dict, base: Settings = Settings()) -> Settings:
    """把（部分）字典合并到 base 上并校验；不合法抛 ValueError，信息是给人看的中文。"""
    if not isinstance(data, dict):
        raise ValueError("设置必须是一个 JSON 对象")
    unknown = set(data) - set(asdict(base))
    if unknown:
        raise ValueError(f"不认识的设置项：{', '.join(sorted(unknown))}")
    vals = asdict(base)
    vals["wake_words"] = tuple(vals["wake_words"])
    if "wake_words" in data:
        raw = data["wake_words"]
        words = raw.replace("，", ",").split(",") if isinstance(raw, str) else raw
        if not isinstance(words, (list, tuple)):
            raise ValueError("唤醒词要写成列表或逗号分隔的文字")
        cleaned = tuple(dict.fromkeys(str(w).strip() for w in words if str(w).strip()))
        if not 1 <= len(cleaned) <= 5 or any(len(w) > 8 for w in cleaned):
            raise ValueError("唤醒词要 1～5 个，每个不超过 8 个字")
        vals["wake_words"] = cleaned
    for key in ("wake_required", "earcon"):
        if key in data:
            if not isinstance(data[key], bool):
                raise ValueError(f"{key} 只能是 true 或 false")
            vals[key] = data[key]
    for key, (lo, hi) in _LIMITS.items():
        if key in data:
            try:
                v = int(data[key]) if key == "min_chars" else float(data[key])
            except (TypeError, ValueError):
                raise ValueError(f"{key} 要是数字") from None
            if not lo <= v <= hi:
                raise ValueError(f"{key} 要在 {lo}～{hi} 之间")
            vals[key] = v
    if "ack_text" in data:
        text = str(data["ack_text"]).strip()
        if not 1 <= len(text) <= 10:
            raise ValueError("应答语要 1～10 个字")
        vals["ack_text"] = text
    return replace(base, **vals)


def to_dict(s: Settings) -> dict:
    d = asdict(s)
    d["wake_words"] = list(s.wake_words)
    return d


class SettingsStore:
    """当前设置 + 持久化 + 变更通知。path=None 时只在内存里（测试、半构造的守护进程用）。"""

    def __init__(self, path: Path | None = None) -> None:
        self.path = path
        self.current = Settings()
        self._mtime: float | None = None
        self._listeners: list[Callable[[Settings], None]] = []
        self._lock = threading.Lock()
        if path is not None:
            self.reload()

    def subscribe(self, fn: Callable[[Settings], None]) -> None:
        self._listeners.append(fn)

    def _notify(self) -> None:
        for fn in list(self._listeners):
            try:
                fn(self.current)
            except Exception:  # noqa: BLE001
                log.exception("settings listener error")

    def reload(self) -> bool:
        """从文件读；文件不存在用默认值；坏文件保留当前值。返回设置是否变了。"""
        if self.path is None or not self.path.exists():
            return False
        try:
            mtime = self.path.stat().st_mtime
            new = from_dict(json.loads(self.path.read_text(encoding="utf-8-sig")), Settings())
        except (OSError, ValueError) as e:
            log.warning("voice-settings.json 读不了，保留当前设置：%s", e)
            return False
        self._mtime = mtime
        changed = new != self.current
        self.current = new
        if changed:
            log.info("settings loaded: %s", to_dict(new))
        return changed

    def maybe_reload(self) -> bool:
        """主循环每 2 秒调一次：文件被手工改过就重读并通知。"""
        if self.path is None or not self.path.exists():
            return False
        try:
            mtime = self.path.stat().st_mtime
        except OSError:
            return False
        if mtime == self._mtime:
            return False
        with self._lock:
            changed = self.reload()
        if changed:
            self._notify()
        return changed

    def update(self, patch: dict) -> Settings:
        """面板改设置：校验 → 原子写盘 → 通知。不合法抛 ValueError。"""
        with self._lock:
            new = from_dict(patch, self.current)
            if self.path is not None:
                self.path.parent.mkdir(parents=True, exist_ok=True)
                tmp = self.path.with_suffix(".tmp")
                tmp.write_text(json.dumps(to_dict(new), ensure_ascii=False, indent=2), encoding="utf-8")
                os.replace(tmp, self.path)
                self._mtime = self.path.stat().st_mtime
            self.current = new
        log.info("settings updated: %s", to_dict(new))
        self._notify()
        return new
```

```python
"""一句话要不要进主线：碎音过滤 → 声纹门槛 → 唤醒词（免喊窗口内可省）。纯逻辑，可单测。

唤醒词按拼音容错匹配：识别常把"管家"写成"关家/管加/光价"，所以逐字比读音而不是比字形——
每个字取全部读音（多音字都算），再做常见的模糊音归并（zh/ch/sh→z/c/s、n→l、后鼻音 ng→n），
唤醒词连续每个字都对上才算命中；4 个字及以上的唤醒词允许错一个字。

    "关家，打开记事本"  ──命中"管家"──> 送主线"打开记事本"
    "管家"              ──只有唤醒词──> 应答"在呢"并打开免喊窗口
    "打开记事本"        ──没有唤醒词──> 不理（免喊窗口内照常送）
"""

from __future__ import annotations

import re
from dataclasses import dataclass
from functools import lru_cache

from pypinyin import Style, pinyin

FILLER_CHARS = set("嗯啊哦呃唉哎诶欸喂嘿哈呀吧呢嘛么哼咦噢哇呵啦咯嗨额")  # 纯语气词片段不当指令
SHORT_ANSWERS = set("好行对要是不停")  # 免喊窗口里允许的单字回答（"要我打开吗？""好"）
_PUNCT_RE = re.compile(r"[\s\W_]+")  # 中文标点也算 \W；汉字、字母、数字是 \w
_EDGE_RE = re.compile(r"^[\s\W_啊呀呢吧嘛哈]+|[\s\W_啊呀呢吧嘛哈]+$")  # 去掉唤醒词后两头残留的标点和语气词


def _is_han(ch: str) -> bool:
    return "\u4e00" <= ch <= "\u9fff"


def _fuzzy(py: str) -> str:
    """模糊音归并：zh/ch/sh→z/c/s，声母 n→l，后鼻音 ang/eng/ing/ong→an/en/in/on。"""
    for a, b in (("zh", "z"), ("ch", "c"), ("sh", "s")):
        if py.startswith(a):
            py = b + py[2:]
            break
    if py.startswith("n"):
        py = "l" + py[1:]
    if py.endswith("ng"):
        py = py[:-1]
    return py


@lru_cache(maxsize=4096)
def _readings(ch: str) -> frozenset[str]:
    if not _is_han(ch):
        return frozenset({ch.lower()})
    return frozenset(_fuzzy(p) for p in pinyin(ch, style=Style.NORMAL, heteronym=True)[0])


def core_text(text: str) -> str:
    """去掉标点和空白后的正文。"""
    return _PUNCT_RE.sub("", text)


def is_filler(text: str, min_chars: int, in_window: bool = False) -> bool:
    """碎音判定：太短、或全是语气词。免喊窗口里"好/行/对/要/是/不/停"这类单字回答不算碎音。"""
    core = core_text(text)
    if in_window and len(core) == 1 and core in SHORT_ANSWERS:
        return False
    return len(core) < min_chars or all(ch in FILLER_CHARS for ch in core)


@dataclass(frozen=True)
class WakeHit:
    start: int  # 在原文里的起止下标（含 start，不含 end）
    end: int
    word: str  # 命中的是哪个唤醒词
    heard: str  # 原文里实际写成什么（例如"关家"）


class WakeMatcher:
    def __init__(self, words: tuple[str, ...] | list[str]) -> None:
        self.words = tuple(words)
        self._patterns = [(w, [_readings(ch) for ch in w if not ch.isspace()]) for w in self.words]

    def find(self, text: str) -> WakeHit | None:
        """在识别文字里找唤醒词，返回最靠前的一个；找不到返回 None。"""
        chars = [(i, ch) for i, ch in enumerate(text) if not _PUNCT_RE.fullmatch(ch)]
        readings = [_readings(ch) for _, ch in chars]
        best: WakeHit | None = None
        for word, pat in self._patterns:
            n = len(pat)
            allowed = 1 if n >= 4 else 0
            for s in range(len(chars) - n + 1):
                miss = sum(1 for k in range(n) if not (pat[k] & readings[s + k]))
                if miss <= allowed:
                    start, end = chars[s][0], chars[s + n - 1][0] + 1
                    if best is None or start < best.start:
                        best = WakeHit(start, end, word, text[start:end])
                    break
        return best

    def strip(self, text: str) -> tuple[str, WakeHit | None]:
        """去掉所有唤醒词（以及两头残留的标点、语气词），返回 (剩下的话, 第一个命中)。"""
        first = None
        while True:
            hit = self.find(text)
            if hit is None:
                break
            first = first or hit
            text = (text[:hit.start] + " " + text[hit.end:]).strip()
        return _EDGE_RE.sub("", text).strip(), first


@dataclass(frozen=True)
class GateDecision:
    verdict: str  # accept / wake_only / ignored / rejected
    stage: str  # 拦在哪一环：filler / speaker / wake；放行时为 ""
    reason: str  # 给人看的原因，面板和日志用
    text: str  # 放行时送主线的话（已去掉唤醒词）
    wake: str = ""  # 原文里命中的唤醒词写法


def decide(text: str, score: float | None, *, threshold: float, matcher: WakeMatcher, wake_required: bool,
           min_chars: int, in_window: bool) -> GateDecision:
    """一句识别结果的去留。score=None 表示不过声纹（测试注入、没有声纹库）。"""
    if is_filler(text, min_chars, in_window):
        return GateDecision("ignored", "filler", f"碎音/语气词「{core_text(text) or text}」", "")
    if score is not None and score < threshold:
        return GateDecision("rejected", "speaker", f"声纹 {score:.2f} < {threshold:.2f}", "")
    rest, hit = matcher.strip(text)
    if hit is None:
        if wake_required and not in_window:
            return GateDecision("rejected", "wake", "没有唤醒词", "")
        return GateDecision("accept", "", "免喊窗口内" if in_window else "不需要唤醒词", text)
    if is_filler(rest, min_chars, True):
        return GateDecision("wake_only", "", f"只喊了「{hit.heard}」", "", hit.heard)
    return GateDecision("accept", "", f"唤醒词「{hit.heard}」", rest, hit.heard)
```

```python
def redact(msg: str) -> str:

def classify_log(name: str, msg: str) -> str:

class EventHub:
    """事件总线 + 每句话记录。所有方法线程安全。"""

    def __init__(self, keep_events: int = 2000, keep_records: int = 50, keep_logs: int = 2000,
                 records_file: Path | None = None, clock=time.time) -> None:
        self._lock = threading.RLock()
        self._seq = itertools.count(1)
        self._events: deque[dict] = deque(maxlen=keep_events)
        self._logs: deque[dict] = deque(maxlen=keep_logs)
        self._records: dict[str, dict] = {}
        self._order: deque[str] = deque()
        self._keep_records = keep_records
        self._subs: list[queue.Queue] = []
        self._ids = itertools.count(1)
        self.records_file = records_file
        self.clock = clock
        self.live: dict[str, dict] = {}  # 不属于某句话的实时环节状态（人声检测、识别中）

    # ---------- 事件 ----------
    def _emit(self, ev: dict) -> dict:
        with self._lock:
            ev = {"seq": next(self._seq), "t": self.clock(), **ev}
            if ev["type"] != "log":
                self._events.append(ev)
            subs = list(self._subs)
        for q in subs:
            try:
                q.put_nowait(ev)
            except queue.Full:  # 页面卡住不读：丢事件不阻塞语音
                pass
        return ev

    def subscribe(self, maxsize: int = 2000) -> queue.Queue:
        q: queue.Queue = queue.Queue(maxsize=maxsize)
        with self._lock:
            self._subs.append(q)
        return q

    def unsubscribe(self, q: queue.Queue) -> None:
        with self._lock:
            if q in self._subs:
                self._subs.remove(q)

    def events_since(self, seq: int) -> list[dict]:
        with self._lock:
            return [e for e in self._events if e["seq"] > seq]

    @property
    def last_seq(self) -> int:
        with self._lock:
            return self._events[-1]["seq"] if self._events else 0

    def status(self, status: dict) -> None:
        self._emit({"type": "status", "status": status})

    def log(self, level: str, module: str, msg: str) -> None:
        item = {"type": "log", "level": level, "module": module, "msg": redact(msg)}
        ev = self._emit(item)
        with self._lock:
            self._logs.append(ev)

    def logs(self, n: int = 300) -> list[dict]:
        with self._lock:
            return list(self._logs)[-n:]

    # ---------- 每句话 ----------
    def new_utterance(self, source: str, **fields) -> str:
        now = self.clock()
        uid = f"u{datetime.fromtimestamp(now):%H%M%S}-{next(self._ids):03d}"
        rec = {"id": uid, "t0": now, "source": source, "text": "", "score": None, "verdict": "", "reason": "",
               "sent": "", "stages": {}, "timeline": [], "tools": [], "reply": "", "spoken": [], "unspoken": [],
               "timings": {}, "done": False, **fields}
        with self._lock:
            self._records[uid] = rec
            self._order.append(uid)
            while len(self._order) > self._keep_records:
                self._records.pop(self._order.popleft(), None)
        self._emit({"type": "record", "record": self._copy(rec)})
        return uid

    def stage(self, uid: str | None, stage: str, state: str, note: str = "", **data) -> None:
        """一个环节的状态变化。uid=None 表示不属于某句话（人声检测、识别中这些实时状态）。"""
        now = self.clock()
        item = {"stage": stage, "state": state, "note": redact(note), **data}
        with self._lock:
            if uid is None:
                self.live[stage] = {"state": state, "note": item["note"], "t": now}
            else:
                rec = self._records.get(uid)
                if rec is not None:
                    st = rec["stages"].setdefault(stage, {"t0": now})
                    st.update({"state": state, "note": item["note"], "t1": now})
                    rec["timeline"].append({"t": now, **item})
        self._emit({"type": "stage", "uid": uid, **item})

    def update(self, uid: str | None, **fields) -> None:
        if uid is None:
            return
        with self._lock:
            rec = self._records.get(uid)
            if rec is None:
                return
            timings = fields.pop("timings", None)
            if timings:
                rec["timings"].update(timings)
            rec.update(fields)
            snap = self._copy(rec)
        self._emit({"type": "record", "record": snap})

    def add_tool(self, uid: str | None, tool: dict) -> None:
        if uid is None:
            return
        with self._lock:
            rec = self._records.get(uid)
            if rec is None:
                return
            rec["tools"].append(tool)
            snap = self._copy(rec)
        self._emit({"type": "record", "record": snap})

    def finish(self, uid: str | None, **fields) -> None:
        """一句话处理完：记最终字段、标记结束、追加一行到 utterances.jsonl。"""
        if uid is None:
            return
        self.update(uid, done=True, **fields)
        rec = self.record(uid)
        if rec is not None and self.records_file is not None:
            self._persist(rec)

    def _persist(self, rec: dict) -> None:
        try:
            self.records_file.parent.mkdir(parents=True, exist_ok=True)
            if self.records_file.exists() and self.records_file.stat().st_size > RECORDS_FILE_MAX:
                self.records_file.replace(self.records_file.with_suffix(".jsonl.1"))
            with self.records_file.open("a", encoding="utf-8") as f:
                f.write(json.dumps(rec, ensure_ascii=False) + "\n")
        except OSError:
            pass  # 落盘失败不影响对话

    def record(self, uid: str) -> dict | None:
        with self._lock:
            rec = self._records.get(uid)
            return self._copy(rec) if rec else None

    def records(self) -> list[dict]:
        with self._lock:
            return [self._copy(self._records[u]) for u in self._order]

    @staticmethod
    def _copy(rec: dict) -> dict:
        return json.loads(json.dumps(rec, ensure_ascii=False))
```

```python
"""跟随分级插件的审计文件（workspace\\guanjia\\audit.jsonl），把主线会话的工具调用实时交给面板。

网关的流式回复里没有内部工具的进度，所以从审计里拿：每次工具调用分级插件都写一行
{"ts", "tool", "level", "decision", "sessionKey", "summary", ...}。启动时从文件末尾开始，只看新写入的行。
"""

from __future__ import annotations

import json
import logging
import threading
from collections.abc import Callable
from pathlib import Path

log = logging.getLogger("guanjia.audittail")

AUDIT_PATH = Path.home() / ".openclaw" / "workspace" / "guanjia" / "audit.jsonl"
MAIN_SESSION_KEY = "agent:main:main"

DECISION_STATE = {  # 审计 decision → 面板「工具/审批」方框的状态
    "allow": "done", "allow-confirmed": "done", "allow-inner-dedup": "done", "approval-allow-once": "done",
    "approval-requested": "active", "block-need-confirm": "blocked", "block-no-confirmer": "blocked",
    "approval-deny": "blocked", "approval-timeout": "blocked", "approval-cancelled": "blocked",
}


def tool_entry(raw: dict) -> dict | None:
    """一行审计 → 面板用的工具记录；不是工具调用、或不是主线会话的返回 None。内层去重那行也跳过（外层已经记过）。"""
    if raw.get("kind") != "tool" or raw.get("sessionKey") != MAIN_SESSION_KEY or not raw.get("tool"):
        return None
    decision = str(raw.get("decision", ""))
    if decision == "allow-inner-dedup":
        return None
    return {"ts": raw.get("ts", ""), "tool": raw["tool"], "level": raw.get("level", ""), "decision": decision,
            "state": DECISION_STATE.get(decision, "info"), "summary": str(raw.get("summary", ""))[:160]}


class AuditTail:
    """后台线程每 0.5 秒读一次新增行，主线会话的工具调用回调 on_tool(entry)。"""

    def __init__(self, on_tool: Callable[[dict], None], path: Path = AUDIT_PATH, interval: float = 0.5) -> None:
        self.on_tool = on_tool
        self.path = path
        self.interval = interval
        self._pos: int | None = None
        self._buf = b""
        self._stop = threading.Event()

    def poll(self) -> int:
        """读一次新增内容，返回交给回调的条数。第一次调用只定位到文件末尾。"""
        try:
            size = self.path.stat().st_size
        except OSError:
            return 0
        if self._pos is None or size < self._pos:  # 第一次，或文件被截断/轮转
            self._pos, self._buf = size, b""
            return 0
        if size == self._pos:
            return 0
        with self.path.open("rb") as f:
            f.seek(self._pos)
            chunk = f.read(size - self._pos)
        self._pos = size
        lines = (self._buf + chunk).split(b"\n")
        self._buf = lines.pop()  # 最后一段可能是写了一半的行
        n = 0
        for line in lines:
            try:
                entry = tool_entry(json.loads(line.decode("utf-8")))
            except (ValueError, UnicodeDecodeError):
                continue
            if entry:
                n += 1
                try:
                    self.on_tool(entry)
                except Exception:  # noqa: BLE001
                    log.exception("audit tail callback error")
        return n

    def start(self) -> None:
        self.poll()
        threading.Thread(target=self._loop, name="audit-tail", daemon=True).start()

    def _loop(self) -> None:
        while not self._stop.wait(self.interval):
            self.poll()

    def stop(self) -> None:
        self._stop.set()
```

```python
def run_phases(run_id: str, db: Path = AGENT_DB) -> dict | None:
    """返回 {session_started, prompt_submitted, model_completed, first_tool}（epoch 秒），查不到返回 None。"""
```

```python
"""一轮语音回复的编排（与音频硬件无关，可用假对象单测）。

    网关流 piece ──> SentenceSplitter ──> speakable 过滤 ──> synth ──> enqueue(gen, pcm, sr)

- 打断 = 播放代次变了：剩下的句子不再合成、不再入队，但网关流照样读到结束。
  客户端断开连接会让网关取消这一轮（连同等着的审批），所以这里绝不 break、绝不 close 网关流。
- 每句没念出来的都记进 TurnResult.unspoken（被打断 / TTS 失败），"有字不出声"从此有据可查。
- /say 的内容（SayItem）不进网关，直接切句合成。
- on_event(名字, 数据) 给调试面板报进度：first_token / sentence / tts_start / tts_done / tts_fail / enqueued / stream_end。
"""

from __future__ import annotations

import logging
import time
from collections.abc import Callable, Iterator
from dataclasses import dataclass, field

import numpy as np

from guanjia.textseg import SentenceSplitter, speakable

log = logging.getLogger("guanjia.turns")


@dataclass
class SayItem:
    """主程序经控制口 /say 让电脑念的一段话（不进网关，直接合成播放）。"""
    text: str
    uid: str | None = None  # 调试面板的记录 id


@dataclass
class Heard:
    """识别出、已放行的一句话，带上调试面板的记录 id。"""
    text: str
    uid: str | None = None


@dataclass
class TurnResult:
    """一轮的结果：网关回复原文、念出来的句子、没念出来的句子、是否被打断、错误。"""
    reply: str = ""
    spoken: list[str] = field(default_factory=list)
    unspoken: list[str] = field(default_factory=list)
    aborted: bool = False
    error: str | None = None


class TurnRunner:
    """把一轮回复变成按句播放的音频；所有依赖都由调用方注入。"""

    def __init__(self, open_stream: Callable[[str], Iterator[str]], synth: Callable[[str], tuple[np.ndarray, int]],
                 enqueue: Callable[[int, np.ndarray, int], None], current_gen: Callable[[], int], *,
                 first_max_chars: int = 20, max_tts_fails: int = 2, first_soft_min: int = 8,
                 on_event: Callable[[str, dict], None] | None = None) -> None:
        self.open_stream = open_stream  # 文本 -> 网关回复增量（生成器）
        self.synth = synth  # 一句 -> (PCM, 采样率)，失败抛异常
        self.enqueue = enqueue  # (代次, PCM, 采样率) -> 进播放队列
        self.current_gen = current_gen  # 当前播放代次；与本轮代次不同即视为被打断
        self.first_max_chars = first_max_chars
        self.first_soft_min = first_soft_min  # 首句在逗号处最早第几个字就切：首句越短合成越快
        self.max_tts_fails = max_tts_fails
        self.on_event = on_event

    def _emit(self, name: str, **data) -> None:
        if self.on_event is not None:
            try:
                self.on_event(name, data)
            except Exception:  # noqa: BLE001  面板出错不能影响念
                log.exception("turn on_event error")

    def run_reply(self, text: str, gen: int) -> TurnResult:
        """一轮语音对话：读完整个网关流，能念的按句合成入队。"""
        res = TurnResult()
        splitter = SentenceSplitter(first_hard_max_chars=self.first_max_chars, first_soft_min_chars=self.first_soft_min)
        fails = [0]  # 本轮 TTS 连续失败次数（列表便于 _speak 里修改）
        first = True
        try:
            for piece in self.open_stream(text):  # 不 break、不 close：打断时也要读完
                if first:
                    first = False
                    self._emit("first_token", t=time.time())
                res.reply += piece
                for sent in splitter.push(piece):
                    self._speak(sent, gen, res, fails)
            for sent in splitter.flush():
                self._speak(sent, gen, res, fails)
            self._emit("stream_end", t=time.time(), ok=True)
        except Exception as e:  # noqa: BLE001  网关连接/报错：这一轮结束，交给上层记错误
            res.error = f"网关：{type(e).__name__}: {e}"
            res.unspoken.extend(s for s in map(speakable, splitter.flush()) if s)  # 断流时缓冲里半句也记账
            self._emit("stream_end", t=time.time(), ok=False, error=res.error)
        reply = res.reply.strip()
        if reply and reply.upper() != "NO_REPLY" and not (res.spoken or res.unspoken or res.error):
            res.unspoken.append(f"（整轮没有能念的内容）{reply[:60]}")  # 有字但全被过滤：也要在日志里看得见
        return res

    def run_say(self, text: str, gen: int) -> TurnResult:
        """/say：把给定文本切句合成入队，不经过网关。"""
        res = TurnResult(reply=text)
        splitter = SentenceSplitter()
        fails = [0]
        for sent in [*splitter.push(text), *splitter.flush()]:
            self._speak(sent, gen, res, fails)
        return res

    def _speak(self, sent: str, gen: int, res: TurnResult, fails: list[int]) -> None:
        """合成并入队一句；任何异常都在这里吞掉记账，绝不往外抛（外抛会中断读流、导致连接被关闭）。"""
        s = speakable(sent)
        if not s:
            return
        self._emit("sentence", t=time.time(), text=s)
        if gen != self.current_gen():
            res.aborted = True
            res.unspoken.append(s)
            return
        if fails[0] >= self.max_tts_fails:
            res.unspoken.append(s)
            return
        t0 = time.time()
        self._emit("tts_start", t=t0, text=s)
        try:
            pcm, sr = self.synth(s)
        except Exception as e:  # noqa: BLE001
            res.unspoken.append(s)
            if gen != self.current_gen():  # 打断时 tts.abort() 关掉了请求：算打断，不算 TTS 失败
                res.aborted = True
                return
            fails[0] += 1
            res.error = f"TTS：{type(e).__name__}: {e}"
            log.error("tts error (%d/%d): %s", fails[0], self.max_tts_fails, e)
            self._emit("tts_fail", t=time.time(), text=s, error=res.error)
            return
        self._emit("tts_done", t=time.time(), text=s, ms=round((time.time() - t0) * 1000))
        fails[0] = 0
        if gen != self.current_gen():
            res.aborted = True
            res.unspoken.append(s)
            return
        try:
            self.enqueue(gen, pcm, sr)
        except Exception as e:  # noqa: BLE001
            res.unspoken.append(s)
            res.error = f"播放：{type(e).__name__}: {e}"
            return
        res.spoken.append(s)
        self._emit("enqueued", t=time.time(), text=s, n=len(res.spoken))
```

```python
"""语音守护进程的本机控制口（只听 127.0.0.1:18795）。

给本机程序用（分级插件的 speak 工具、上线脚本），不带令牌：
    GET  /status                -> 托盘同款状态 JSON
    POST /say {"text": "..."}   -> 让电脑用管家音色念一句（走守护进程自己的播放队列，打断照样生效）
    POST /sleep-state {"state": "awake|sleeping|consolidating"} -> P4 休眠状态位（托盘显示）
给浏览器里的「管家面板」用（同源页面，要令牌）：
    GET  /panel                 -> 面板页面（页面里带着本次启动随机生成的令牌）
    GET  /api/snapshot、/api/utterance?id=、/api/events（SSE）   令牌放查询参数 token=
    POST /api/control、/api/settings、/api/inject                 令牌放请求头 X-Guanjia-Token

防护：只绑 127.0.0.1、只接受本机来源；Host 必须是 127.0.0.1/localhost（挡 DNS 重绑定）；POST 必须是 application/json；
独占端口，第二个实例绑不上。旧接口带 Origin 头一律 403（浏览器网页发起的都带）；/api/* 只放行同源 Origin
（http://127.0.0.1:18795 或 http://localhost:18795），并且要令牌——别的网页读不到面板页面（同源策略），
也就拿不到令牌；跨站带自定义请求头会先触发 CORS 预检，这里不回 CORS 头，所以跨站改设置、点退出都做不到。
"""

from __future__ import annotations

import hmac
import json
import os
import queue
import socket
import threading
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from typing import Protocol
from urllib.parse import parse_qs, urlsplit

CONTROL_PORT = int(os.environ.get("GUANJIA_CONTROL_PORT", "18795"))
SAY_MAX_CHARS = 300
SLEEP_STATES = ("awake", "sleeping", "consolidating")
SSE_HEARTBEAT_SEC = 15.0
SSE_MAX_CLIENTS = 5
_MAX_BODY = 8192
_LOCAL_HOSTS = ("127.0.0.1", "localhost", "::1")


class ControlAPI(Protocol):
    def say(self, text: str) -> tuple[bool, str]: ...

    def status(self) -> dict: ...

    def set_sleep_state(self, state: str) -> bool: ...


class PanelAPI(Protocol):
    token: str

    def html(self) -> bytes: ...

    def snapshot(self) -> dict: ...

    def record(self, uid: str) -> dict | None: ...

    def subscribe(self) -> queue.Queue: ...

    def unsubscribe(self, q: queue.Queue) -> None: ...

    def events_since(self, seq: int) -> list[dict]: ...

    def control(self, action: str) -> tuple[bool, str]: ...

    def update_settings(self, patch: dict) -> tuple[bool, dict | str]: ...

    def inject(self, text: str, dry_run: bool) -> dict: ...


class _ExclusiveServer(ThreadingHTTPServer):
    allow_reuse_address = False  # Windows 上 SO_REUSEADDR 会让第二个实例也绑上同一端口，宁可报错
    daemon_threads = True

    def server_bind(self) -> None:
        if hasattr(socket, "SO_EXCLUSIVEADDRUSE"):
            self.socket.setsockopt(socket.SOL_SOCKET, socket.SO_EXCLUSIVEADDRUSE, 1)
        super().server_bind()


def make_control_server(api: ControlAPI, port: int = CONTROL_PORT, host: str = "127.0.0.1",
                        panel: PanelAPI | None = None) -> ThreadingHTTPServer:
    """建好但不启动；port=0 让系统挑空闲端口（测试用）。端口被占时抛 OSError。panel=None 时没有面板接口。"""
    sse_clients = [0]
    sse_lock = threading.Lock()

    class Handler(BaseHTTPRequestHandler):
        def log_message(self, fmt, *args):  # 不往 stderr 打访问日志
            pass

        def _send(self, code: int, obj: dict) -> None:
            self._drain()
            data = json.dumps(obj, ensure_ascii=False).encode("utf-8")
            self.send_response(code)
            self.send_header("Content-Type", "application/json; charset=utf-8")
            self.send_header("Content-Length", str(len(data)))
            self.send_header("Cache-Control", "no-store")
            self.end_headers()
            self.wfile.write(data)

        @property
        def _port(self) -> int:
            return self.server.server_address[1]

        def _guard(self, is_api: bool) -> bool:
            if self.client_address[0] not in ("127.0.0.1", "::1"):
                self._send(403, {"ok": False, "reason": "not_local"})
                return False
            host = (self.headers.get("Host") or "").rsplit(":", 1)[0].strip("[]").lower()
            if host not in _LOCAL_HOSTS:  # DNS 重绑定：网页同源 GET 不带 Origin，但 Host 是攻击者的域名
                self._send(403, {"ok": False, "reason": "bad_host"})
                return False
            origin = self.headers.get("Origin")
            if origin is not None:
                same = origin in (f"http://127.0.0.1:{self._port}", f"http://localhost:{self._port}")
                if not (is_api and same):
                    self._send(403, {"ok": False, "reason": "browser_origin"})
                    return False
            return True

        def _token_ok(self, query: dict) -> bool:
            if panel is None:
                self._send(404, {"ok": False, "reason": "not_found"})
                return False
            given = self.headers.get("X-Guanjia-Token") or ""
            if self.command == "GET" and not given:
                given = (query.get("token") or [""])[0]
            if not hmac.compare_digest(given.encode(), panel.token.encode()):
                self._send(403, {"ok": False, "reason": "bad_token"})
                return False
            return True

        _body_read = False

        def _drain(self) -> None:
            """回应前把没读的请求体读掉：Windows 上带着未读数据关连接会发 RST，客户端可能收不到这条回应。"""
            if self._body_read or self.command != "POST":
                return
            self._body_read = True
            try:
                n = int(self.headers.get("Content-Length") or 0)
            except ValueError:
                n = -1
            try:
                if 0 <= n <= _MAX_BODY:
                    self.rfile.read(n)
                else:
                    self.connection.settimeout(0.2)
                    self.rfile.read1(65536)
            except OSError:
                pass

        def _json_body(self) -> dict | None:
            if not (self.headers.get("Content-Type") or "").lower().startswith("application/json"):
                self._send(415, {"ok": False, "reason": "need_json"})
                return None
            try:
                n = int(self.headers.get("Content-Length") or 0)
            except ValueError:
                n = -1
            if n < 0:
                self._send(400, {"ok": False, "reason": "bad_length"})
                return None
            if n > _MAX_BODY:
                self._send(413, {"ok": False, "reason": "too_large"})
                return None
            self._body_read = True
            try:
                body = json.loads(self.rfile.read(n) or b"{}")
            except (ValueError, UnicodeDecodeError):
                body = None
            if not isinstance(body, dict):
                self._send(400, {"ok": False, "reason": "bad_json"})
                return None
            return body

        def do_GET(self):
            url = urlsplit(self.path)
            is_api = url.path.startswith("/api/")
            if not self._guard(is_api):
                return
            query = parse_qs(url.query)
            if url.path == "/status":
                self._send(200, api.status())
            elif url.path == "/panel" and panel is not None:
                self._send_panel()
            elif is_api and self._token_ok(query):
                if url.path == "/api/snapshot":
                    self._send(200, panel.snapshot())
                elif url.path == "/api/utterance":
                    rec = panel.record((query.get("id") or [""])[0])
                    self._send(200 if rec else 404, rec or {"ok": False, "reason": "not_found"})
                elif url.path == "/api/events":
                    self._sse()
                else:
                    self._send(404, {"ok": False, "reason": "not_found"})
            elif not is_api:
                self._send(404, {"ok": False, "reason": "not_found"})

        def do_POST(self):
            url = urlsplit(self.path)
            is_api = url.path.startswith("/api/")
            if not self._guard(is_api):
                return
            if is_api:
                if not self._token_ok({}):
                    return
                if url.path not in ("/api/control", "/api/settings", "/api/inject"):
                    self._send(404, {"ok": False, "reason": "not_found"})
                    return
            elif url.path not in ("/say", "/sleep-state"):
                self._send(404, {"ok": False, "reason": "not_found"})
                return
            body = self._json_body()
            if body is None:
                return
            if url.path == "/say":
                text = str(body.get("text") or "").strip()
                if not text:
                    self._send(400, {"ok": False, "reason": "empty"})
                    return
                if len(text) > SAY_MAX_CHARS:
                    self._send(400, {"ok": False, "reason": "too_long"})
                    return
                ok, reason = api.say(text)
                self._send(200 if ok else 409, {"ok": ok, "reason": reason})
            elif url.path == "/sleep-state":
                state = str(body.get("state") or "")
                if state not in SLEEP_STATES:
                    self._send(400, {"ok": False, "reason": "bad_state"})
                    return
                api.set_sleep_state(state)
                self._send(200, {"ok": True, "reason": "set"})
            elif url.path == "/api/control":
                ok, msg = panel.control(str(body.get("action") or ""))
                self._send(200 if ok else 400, {"ok": ok, "reason": msg})
            elif url.path == "/api/settings":
                ok, result = panel.update_settings(body)
                self._send(200 if ok else 400, {"ok": ok, "settings": result} if ok else {"ok": False, "reason": result})
            else:
                text = str(body.get("text") or "").strip()
                if not text or len(text) > SAY_MAX_CHARS:
                    self._send(400, {"ok": False, "reason": "bad_text"})
                    return
                self._send(200, {"ok": True, **panel.inject(text, bool(body.get("dry_run", True)))})

        def _send_panel(self) -> None:
            data = panel.html()
            self.send_response(200)
            self.send_header("Content-Type", "text/html; charset=utf-8")
            self.send_header("Content-Length", str(len(data)))
            self.send_header("Cache-Control", "no-store")
            self.send_header("X-Frame-Options", "DENY")
            self.send_header("Referrer-Policy", "no-referrer")
            self.send_header("Content-Security-Policy",
                             "default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; "
                             "connect-src 'self'; img-src 'self' data:; frame-ancestors 'none'; base-uri 'none'")
            self.end_headers()
            self.wfile.write(data)

        def _sse(self) -> None:
            with sse_lock:
                if sse_clients[0] >= SSE_MAX_CLIENTS:
                    self._send(429, {"ok": False, "reason": "too_many_panels"})
                    return
                sse_clients[0] += 1
            q = panel.subscribe()
            try:
                self.send_response(200)
                self.send_header("Content-Type", "text/event-stream; charset=utf-8")
                self.send_header("Cache-Control", "no-store")
                self.end_headers()
                try:
                    last = int(self.headers.get("Last-Event-ID") or 0)
                except ValueError:
                    last = 0
                backlog = panel.events_since(last) if last else []
                self._write_event({"type": "hello", "seq": 0})
                for ev in backlog:
                    self._write_event(ev)
                while True:
                    try:
                        ev = q.get(timeout=SSE_HEARTBEAT_SEC)
                    except queue.Empty:
                        self.wfile.write(b": ping\n\n")
                        self.wfile.flush()
                        continue
                    self._write_event(ev)
            except (BrokenPipeError, ConnectionResetError, ConnectionAbortedError, OSError):
                pass
            finally:
                panel.unsubscribe(q)
                with sse_lock:
                    sse_clients[0] -= 1

        def _write_event(self, ev: dict) -> None:
            data = json.dumps(ev, ensure_ascii=False)
            head = f"id: {ev['seq']}\n" if ev.get("seq") else ""
            self.wfile.write(f"{head}event: {ev['type']}\ndata: {data}\n\n".encode("utf-8"))
            self.wfile.flush()

    return _ExclusiveServer((host, port), Handler)


def start_control_server(api: ControlAPI, port: int = CONTROL_PORT, panel: PanelAPI | None = None) -> ThreadingHTTPServer:
    """建好并在后台线程里启动；端口被占时抛 OSError（调用方据此判断是否已有实例在跑）。"""
    server = make_control_server(api, port, panel=panel)
    threading.Thread(target=server.serve_forever, name="control", daemon=True).start()
    return server
```

```python
class WinregNotifySettings:
    """NotifyIconSettings 的读写（只碰当前用户的 HKCU）。没有这个键（Windows 10）时 entries() 返回空。"""

    def entries(self) -> list[tuple[str, dict]]:
        import winreg

        out = []
        try:
            root = winreg.OpenKey(winreg.HKEY_CURRENT_USER, NOTIFY_SETTINGS_KEY)
        except OSError:
            return out
        with root:
            i = 0
            while True:
                try:
                    name = winreg.EnumKey(root, i)
                except OSError:
                    break
                i += 1
                vals = {}
                try:
                    with winreg.OpenKey(root, name) as k:
                        j = 0
                        while True:
                            try:
                                vname, vdata, _ = winreg.EnumValue(k, j)
                            except OSError:
                                break
                            j += 1
                            if isinstance(vdata, (str, int)):
                                vals[vname] = vdata
                except OSError:
                    continue
                out.append((name, vals))
        return out

    def promote(self, name: str) -> None:
        import winreg

        with winreg.OpenKey(winreg.HKEY_CURRENT_USER, NOTIFY_SETTINGS_KEY + "\\" + name, 0, winreg.KEY_SET_VALUE) as k:
            winreg.SetValueEx(k, "IsPromoted", 0, winreg.REG_DWORD, 1)


def promote_tray_icon(reg=None, prefix: str = TOOLTIP_PREFIX) -> list[str]:
    """把提示文字以「管家」开头、且从没设过 IsPromoted 的托盘项设为固定显示。返回改了哪些子键。"""
    reg = reg or WinregNotifySettings()
    changed = []
    try:

            if str(vals.get("InitialTooltip", "")).startswith(prefix) and "IsPromoted" not in vals:

    except OSError as e:

    if changed:

    return changed


class Tray:
    def __init__(self, view: Callable[[], TrayView], muted: Callable[[], bool], on_toggle_mute: Callable[[], None],
                 on_restart: Callable[[], None], on_exit: Callable[[], None],
                 on_open_panel: Callable[[], None] | None = None) -> None:
        self.view = view
        self.muted = muted
        self.on_toggle_mute = on_toggle_mute
        self.on_restart = on_restart
        self.on_exit = on_exit
        self.on_open_panel = on_open_panel
        self._icon = None
        self._shown_key = ""
        self._lock = threading.Lock()

    def start(self) -> None:
        threading.Thread(target=self._run, name="tray", daemon=True).start()
        threading.Thread(target=self._promote_later, name="tray-promote", daemon=True).start()

    def _promote_later(self) -> None:
        """图标出现后系统才建注册表项：5 秒、60 秒各试一次。"""
        for delay in (5, 55):
            time.sleep(delay)
            if promote_tray_icon():
                return

    def menu_items(self, pystray) -> list:
        """右键菜单（单独成函数便于单测检查有哪些项）。"""
        items = [pystray.MenuItem(lambda item: self.view().label, None, enabled=False)]
        if self.on_open_panel is not None:
            items.append(pystray.MenuItem("打开面板（控制与调试）", lambda icon, item: self.on_open_panel()))
        items += [
            pystray.MenuItem("静音", lambda icon, item: self.on_toggle_mute(), checked=lambda item: self.muted(),
                             default=True),  # default = 左键单击触发
            pystray.Menu.SEPARATOR,
            pystray.MenuItem("重启语音", lambda icon, item: self.on_restart()),
            pystray.MenuItem("退出语音", lambda icon, item: self.on_exit()),
        ]
        return items

    def _run(self) -> None:
        """托盘线程：构造 Icon 并跑它的消息循环（两者必须同一线程）。"""
        try:
            import pystray  # 延迟导入：单测和 --no-tray 不需要它

            v = self.view()
            self._shown_key = v.key
            self._icon = pystray.Icon("guanjia", make_icon_image(v.color), v.tooltip, pystray.Menu(*self.menu_items(pystray)))
            self._icon.run()
        except Exception:  # noqa: BLE001  托盘挂了不影响听说
            log.exception("tray stopped with error")

    def refresh(self) -> None:
        """状态变化后调用：换图标颜色、提示文字，刷新菜单勾选。"""
        if not self._icon:
            return
        with self._lock:
            v = self.view()
            try:
                if v.key != self._shown_key:
                    self._icon.icon = make_icon_image(v.color)
                    self._shown_key = v.key
                self._icon.title = v.tooltip
                self._icon.update_menu()
            except Exception:  # noqa: BLE001
                log.exception("tray refresh failed")

    def stop(self) -> None:
        if self._icon:
            try:
                self._icon.stop()
            except Exception:  # noqa: BLE001
                pass
```

```python
def pick_stream_rate(in_dev, out_dev) -> int:
    """选一个输入输出都接受、且是 16k 整数倍的流采样率。

    优先 16000（Windows 默认的 MME 通道会自行重采样，省掉降采样和 AEC 的高采样率开销）；
    WASAPI 这类只认原生采样率的设备退到 48000 / 32000；都不行就抛错说明设备默认率。
    """
    dev_in = sd.query_devices(in_dev if in_dev is not None else sd.default.device[0])
    dev_out = sd.query_devices(out_dev if out_dev is not None else sd.default.device[1])
    for rate in (16000, 48000, 32000):
        try:
            sd.check_input_settings(device=in_dev, samplerate=rate, channels=1, dtype="float32")
            sd.check_output_settings(device=out_dev, samplerate=rate, channels=1, dtype="float32")
            return rate
        except Exception:  # noqa: BLE001  该采样率不被接受，试下一个
            continue
    raise RuntimeError(
        f"输入 {dev_in['name']}({dev_in['default_samplerate']:.0f}) / 输出 {dev_out['name']}({dev_out['default_samplerate']:.0f}) "
        "都不接受 16k/48k/32k，请用 --in/--out 指定 MME 设备"
    )

def aec_cancel(aec: Aec, mic: np.ndarray, ref: np.ndarray) -> np.ndarray:
    """对一帧 float32 做回声消除，返回同长度 float32（截到帧长，防 pyaec 返回长度不符打乱降采样相位）。"""
    mic_i16 = (np.clip(mic, -1, 1) * 32767).astype(np.int16)
    ref_i16 = (np.clip(ref, -1, 1) * 32767).astype(np.int16)
    out = np.asarray(aec.cancel_echo(mic_i16.tolist(), ref_i16.tolist()), dtype=np.float32) / 32768.0
    return out[: len(mic)]


def apply_mic_gain(x: np.ndarray, gain: float) -> np.ndarray:
    """软件增益 + tanh 软限幅：小信号近似线性放大，接近满幅时平滑压缩，不硬削波。守护进程与声纹注册共用。"""

    return np.tanh(x * gain).astype(np.float32, copy=False)

            synth=self.tts.synth, enqueue=self._enqueue_pcm, current_gen=lambda: self._gen,
            first_max_chars=FIRST_SENT_MAX_CHARS, max_tts_fails=TTS_MAX_FAILS, first_soft_min=FIRST_SENT_SOFT_MIN,
            on_event=self._on_turn_event)
        self._earcon = earcon(self.sr)
        self._ack_text = ""  # _ack_pcm 是哪句应答合成的
        self.barge = BargeDetector(BargeConfig(guard_ms=BARGE_GUARD_MS, tail_ms=BARGE_TAIL_MS, rms_min=s.barge_rms_min,
                                               floor_ratio=BARGE_FLOOR_RATIO, trigger_ms=BARGE_MS))
        self._mon_ms, self._mon_peak = 0, 0.0  # barge-mon 日志计时与区间 RMS 峰值（只有前端线程读写）
        self.monitor = HealthMonitor({"gateway": lambda: tcp_alive("127.0.0.1", GATEWAY_PORT), "tts": self.tts.alive},
                                     on_change=self._on_health, interval=HEALTH_EVERY_SEC)
        self.panel = PanelBackend(self.hub, self.store, status=self.status, control=self._panel_control, inject=self.inject)
        self.audit = AuditTail(self._on_tool)
        self.store.subscribe(self._apply_settings)
        self.tray = None  # run() 里按 tray_on 创建
        self.control = None  # run() 里启动
        # 前端线程状态（只有前端线程读写）
        self._asr_stream = self.asr.new_stream()  # 当前这句话的 ASR 流，每段结束换新流
        self._preroll: deque[np.ndarray] = deque(maxlen=PREROLL_MS // 10)  # 最近 0.5s 的 16k 块
        self._was_speech = False  # 上一块 VAD 是否处于人声状态，用于捕捉起判沿

    # ---------- 音频回调 ----------
    def _callback(self, indata, outdata, frames, time_info, status) -> None:
        if status.output_underflow:
            self._underflows += 1
        cur = self._gen
        if self._buf_gen != cur:  # 已换代：正在播的旧句作废
            self._play_buf, self._play_pos, self._buf_gen = np.zeros(0, dtype=np.float32), 0, cur
        out = np.zeros(frames, dtype=np.float32)
        filled = 0
        while filled < frames:
            if self._play_pos >= len(self._play_buf):
                try:
                    g, pcm = self.play_q.get_nowait()
                except queue.Empty:
                    break
                if g == cur:
                    self._play_buf, self._play_pos, self._buf_gen = pcm, 0, g
                    self._play_events.append((time.time(), len(pcm) / self.sr, g))  # 真正开始写入输出流的时刻
                continue
            k = min(frames - filled, len(self._play_buf) - self._play_pos)
            out[filled:filled + k] = self._play_buf[self._play_pos:self._play_pos + k]
            self._play_pos += k
            filled += k
        if filled:
            self._played_gen = cur
        voiced = filled > 0 and float(np.abs(out[:filled]).max()) > 1e-4  # 150ms 静音前导不算出声，打断底噪从真声开始学
        # 叠加保活噪声（循环取预生成缓冲）：输出流从不"纯零"，音响不会因静默进入待机
        n0 = self._noise_pos
        idx = (np.arange(n0, n0 + frames)) % len(self._noise)
        out += self._noise[idx]
        self._noise_pos = (n0 + frames) % len(self._noise)
        outdata[:, 0] = out
        try:
            self.in_q.put_nowait(Frames(mic=indata[:, 0].copy(), ref=out, playing=voiced))
        except queue.Full:
            self._dropped += 1

    def _reset_frontend(self) -> None:
        """VAD / ASR 流 / 预滚 / 打断状态全部复位（游戏态恢复、静音恢复时调用）。"""
        self.vad = VAD()
        self._vad_pos = 0
        self._raw_ring.clear()
        self._asr_stream = self.asr.new_stream()
        self._preroll.clear()
        self._was_speech = False
        self.barge.reset()

    def _playing(self) -> bool:
        return self._play_pos < len(self._play_buf) or not self.play_q.empty()

    # ---------- 前端线程 ----------
    def _frontend(self) -> None:
        while not self._stop_evt.is_set():
            try:
                fr = self.in_q.get(timeout=0.2)
            except queue.Empty:
                continue
            if self._paused.is_set():  # 游戏态：丢弃停流前残留的帧
                continue
            if self._muted.is_set():  # 静音：不听
                self._front_dirty = True
                continue
            if self._front_dirty:
                self._reset_frontend()
                self._front_dirty = False
            try:
                self._frontend_step(fr)
            except Exception:  # noqa: BLE001  单帧出错不能让整条听觉链"变聋"
                log.exception("frontend error")

    def _frontend_step(self, fr: Frames) -> None:
        """处理一帧：(AEC) → 16k → 增益 → VAD → 预滚/ASR → 打断判定 → 段结束出文字。"""
        x = aec_cancel(self.aec, fr.mic, fr.ref) if self.aec else fr.mic
        y = apply_mic_gain(self.down.process(x), self.mic_gain)
        self._raw_ring.append((self._vad_pos, fr.mic))
        self.vad.push(y)
        self._vad_pos += len(y)
        speaking_now = self.vad.is_speech()
        if speaking_now:
            if not self._was_speech:  # 起判沿：VAD 要人声满 0.25s 才翻 true，先把预滚补喂进 ASR
                self.hub.stage(None, "vad", "active", "有人在说话")
                for c in self._preroll:
                    self.asr.feed(self._asr_stream, c, SR16K)
            self.asr.feed(self._asr_stream, y, SR16K)
        elif self._was_speech:
            self.hub.stage(None, "vad", "done", "说完了")
        self._preroll.append(y)
        rms = float(np.sqrt(np.mean(x * x))) if len(x) else 0.0  # 增益前的原始电平，打断阈值按它标定
        self._barge_step(rms, fr.playing)
        self._was_speech = speaking_now
        for seg in self.vad.pop_segments():
            stream, self._asr_stream = self._asr_stream, self.asr.new_stream()  # 每句一条新流，不带上一句残留
            if seg.duration < MIN_UTT_SEC:
                continue
            self.hub.stage(None, "asr", "active", "识别中")
            t_asr = time.monotonic()
            self.asr.feed(stream, np.zeros(SR16K * 3 // 10, dtype=np.float32), SR16K)  # 补 0.3s 静音冲刷尾字
            self.asr.finish(stream)
            stream_text = self.asr.text(stream)  # 流式结果，留着与精识别对比
            text = self.asr_final.transcribe(seg.samples, fallback=stream_text)
            asr_ms = round((time.monotonic() - t_asr) * 1000)
            self._dump_segment(seg, text)
            if not text:  # 精识别也为空：不过声纹、不记录，直接丢
                self.hub.stage(None, "asr", "done", "没识别出字")
                log.debug("丢弃空文本段 %.2fs", seg.duration)
                continue
            self.hub.stage(None, "asr", "done", text[:20])
            t_spk = time.monotonic()
            score = self.gate.identify(seg.samples)[1] if self.gate else None
            spk_ms = round((time.monotonic() - t_spk) * 1000)
            self._on_heard(text, score, source="mic", stream_text=stream_text, seg_sec=seg.duration,
                           asr_ms=asr_ms, spk_ms=spk_ms)

    def _on_heard(self, text: str, score: float | None, *, source: str, stream_text: str = "",
                  seg_sec: float | None = None, asr_ms: int | None = None, spk_ms: int | None = None,
                  dry_run: bool = False) -> dict:
        """一句识别结果的去留（麦克风和面板注入共用）：记一条面板记录，放行就交给大脑，只喊唤醒词就应答。"""
        s = self.store.current
        in_window = self._in_followup()
        threshold = 0.0 if self.gate_mode == "log" else s.spk_threshold
        d = decide(text, score, threshold=threshold, matcher=self.wake, wake_required=s.wake_required,
                   min_chars=s.min_chars, in_window=in_window)
        uid = self.hub.new_utterance(source, text=text, stream_text=stream_text,
                                     score=None if score is None else round(score, 3), in_window=in_window,
                                     timings={k: v for k, v in (("asr_ms", asr_ms), ("speaker_ms", spk_ms)) if v is not None})
        if seg_sec is not None:
            self.hub.stage(uid, "vad", "done", f"{seg_sec:.1f} 秒")
        self.hub.stage(uid, "asr", "blocked" if d.stage == "filler" else "done",
                       d.reason if d.stage == "filler" else text[:20])
        if d.stage == "filler":
            self.hub.stage(uid, "speaker", "skipped")
        elif score is None:
            self.hub.stage(uid, "speaker", "skipped", "未过声纹（注入/无声纹库）")
        else:
            self.hub.stage(uid, "speaker", "blocked" if d.stage == "speaker" else "done",
                           d.reason if d.stage == "speaker" else f"{score:.2f} ≥ {threshold:.2f}")
        if d.stage in ("filler", "speaker"):
            self.hub.stage(uid, "wake", "skipped")
        else:
            self.hub.stage(uid, "wake", "blocked" if d.stage == "wake" else "done", d.reason)
        label = "注入" if source == "inject" else ("我" if score is not None else "未过声纹")
        shown = f"{label} {score:.2f}" if score is not None else label
        if d.verdict == "accept":
            log.info("[%s] %s  → 送主线「%s」（%s）(stream: %s)", shown, text, d.text, d.reason, stream_text)
        elif d.verdict == "wake_only":
            log.info("唤醒：[%s] %s（%s），免喊 %.0f 秒", shown, text, d.reason, s.follow_up_sec)
        elif d.verdict == "ignored":
            log.info("忽略：%s text=%r", d.reason, text)
        else:
            log.info("拒绝：%s text=%r (stream: %r)", d.reason, text, stream_text)
        result = {"uid": uid, "verdict": d.verdict, "stage": d.stage, "reason": d.reason, "text": d.text,
                  "wake": d.wake, "in_window": in_window, "dry_run": dry_run}
        if dry_run:
            self.hub.finish(uid, verdict=d.verdict, reason=d.reason + "（模拟，未执行）", sent=d.text)
        elif d.verdict == "accept":
            self.hub.update(uid, verdict="accept", reason=d.reason, sent=d.text)
            self._accept_utterance(d.text, uid)
        elif d.verdict == "wake_only":
            self.hub.update(uid, verdict="wake_only", reason=d.reason)
            self._wake_ack(uid)
        else:
            self.hub.finish(uid, verdict=d.verdict, reason=d.reason)
        return result

    def inject(self, text: str, dry_run: bool = True) -> dict:
        """面板「模拟一句话」/上线验证用：当作识别出的文字走一遍去留判定（不过声纹）。dry_run 只判定不执行。"""
        return self._on_heard(text, None, source="inject", dry_run=dry_run)

    def _accept_utterance(self, text: str, uid: str | None = None) -> None:
        """一句话放行：正在说就停（只停播放）；立刻放提示音；文字排进大脑队列。"""
        if self.state == "SPEAKING":
            self.stop_speaking("新一轮")
        if self.store.current.earcon:
            self.play_q.put((self._gen, self._earcon))
        self.text_q.put(Heard(text, uid) if uid else text)

    def _wake_ack(self, uid: str | None) -> None:
        """只喊了唤醒词：应答一声（合成好的「在呢」，TTS 不在时用提示音），从应答结束起打开免喊窗口。"""
        if self.state == "SPEAKING":
            self.stop_speaking("唤醒")
        pcm = self._ack_pcm if self._ack_pcm is not None else self._earcon
        self.play_q.put((self._gen, pcm))
        self._followup_until = time.monotonic() + len(pcm) / self.sr + self.store.current.follow_up_sec
        self.hub.stage(uid, "play", "done", "应答「在呢」" if self._ack_pcm is not None else "提示音")
        self.hub.finish(uid)
        self.hub.status(self.status())

    def _prepare_ack(self) -> None:
        """后台合成应答语并缓存（TTS 上线时、改了应答语时调用）；失败就继续用提示音。"""
        text = self.store.current.ack_text
        if text == self._ack_text and self._ack_pcm is not None:
            return

        def work() -> None:
            try:
                pcm, sr = self.tts.synth(text)
            except Exception as e:  # noqa: BLE001
                log.warning("tts ack synth failed: %s", e)
                return
            if sr != self.sr:
                x_old = np.linspace(0, 1, len(pcm), endpoint=False)
                x_new = np.linspace(0, 1, int(len(pcm) * self.sr / sr), endpoint=False)
                pcm = np.interp(x_new, x_old, pcm).astype(np.float32)
            self._ack_pcm, self._ack_text = pcm, text
            log.info("tts ack ready: %s (%.2fs)", text, len(pcm) / self.sr)

        threading.Thread(target=work, name="ack-synth", daemon=True).start()

    def _in_followup(self) -> bool:
        """免喊窗口：它回完最后一句后 follow_up_sec 秒内，或者一轮正在进行时。"""
        return time.monotonic() < self._followup_until or self.state == "SPEAKING"

    def _open_followup(self) -> None:
        self._followup_until = time.monotonic() + self.store.current.follow_up_sec
        self.hub.status(self.status())

    def _raw_for(self, seg) -> np.ndarray:
        """从原始环形缓冲取出与 VAD 段对齐的设备采样率原始音频（AEC 前、无增益）。"""
        decim = self.sr // SR16K
        start16 = int(round(seg.start * SR16K))
        end16 = start16 + len(seg.samples)
        parts = [(i, m) for i, m in self._raw_ring if i < end16 and i + len(m) // decim > start16]
        if not parts:
            return np.zeros(0, dtype=np.float32)
        raw = np.concatenate([m for _, m in parts])
        off = max(0, (start16 - parts[0][0]) * decim)
        return raw[off: off + (end16 - start16) * decim]

    def _dump_segment(self, seg, text: str) -> None:
        """落盘一段送识别的音频：_raw.wav（设备采样率原始）+ _proc.wav（增益+16k），只留最近 SEG_KEEP 段。"""
        try:
            SEG_DUMP_DIR.mkdir(parents=True, exist_ok=True)
            label = re.sub(r'[\\/:*?"<>|\s]', "", text)[:10] or "空"
            stem = f"{datetime.now():%Y%m%d-%H%M%S-%f}"[:-3] + f"_{label}"
            for suffix, pcm, sr in (("raw", self._raw_for(seg), self.sr), ("proc", seg.samples, SR16K)):
                with wave.open(str(SEG_DUMP_DIR / f"{stem}_{suffix}.wav"), "wb") as w:
                    w.setnchannels(1)
                    w.setsampwidth(2)
                    w.setframerate(sr)
                    w.writeframes((np.clip(pcm, -1, 1) * 32767).astype(np.int16).tobytes())
            procs = sorted(SEG_DUMP_DIR.glob("*_proc.wav"))
            for old in procs[:-SEG_KEEP]:
                old.unlink(missing_ok=True)
                old.with_name(old.name.replace("_proc.wav", "_raw.wav")).unlink(missing_ok=True)
        except OSError as e:  # 取证失败不影响对话
            log.warning("segment dump failed: %s", e)

    def _barge_step(self, rms: float, ref_active: bool) -> None:
        """打断判定（每 10ms 一帧，前端线程）：交给 BargeDetector；出声期间每秒打一行 barge-mon 供校准。"""
        hit = self.barge.step(rms, ref_active)
        if self.barge.playing:
            self._mon_ms += 10
            self._mon_peak = max(self._mon_peak, rms)
            if self._mon_ms >= BARGE_LOG_EVERY_MS:
                log.debug("barge-mon rms_peak=%.5f energy=%.5f floor=%.5f line=%.5f hot=%dms", self._mon_peak,
                          self.barge.energy, self.barge.floor, self.barge.line, self.barge.hot_ms)
                self._mon_ms, self._mon_peak = 0, 0.0
        else:
            self._mon_ms, self._mon_peak = 0, 0.0
        if hit and self.state == "SPEAKING" and self._played_gen == self._gen:
            log.info("barge-in: energy=%.4f floor=%.4f line=%.4f", self.barge.energy, self.barge.floor, self.barge.line)
            self.stop_speaking("barge-in")

    # ---------- 大脑线程 ----------
    def _brainloop(self) -> None:
        while not self._stop_evt.is_set():
            try:
                item = self.text_q.get(timeout=0.2)
            except queue.Empty:
                continue
            if self._paused.is_set() or self._muted.is_set():  # 游戏态 / 静音：积压的话直接丢掉
                continue
            try:
                self._handle_item(item)
            except Exception:  # noqa: BLE001  一轮出错不能让大脑线程退出
                log.exception("brain loop error")

    def _handle_item(self, item: str | Heard | SayItem) -> None:
        """一轮：放行的话进主线会话 / /say 的话直接念；等本轮播完再回到监听，然后打开免喊窗口。"""
        uid = item.uid if isinstance(item, (Heard, SayItem)) else None
        gen = self._begin_speaking()
        self._turn_first = True
        self._turn_t0 = time.monotonic()
        self._turn_uid, self._turn_gen = uid, gen
        self._turn_marks = marks = {"turn_start": time.time()}
        try:
            if isinstance(item, SayItem):
                res = self.runner.run_say(item.text, gen)
                log.info("say: %s", item.text)
            else:
                text = item.text if isinstance(item, Heard) else item
                self.hub.stage(uid, "gateway", "active", "请求已发出")
                res = self.runner.run_reply(text, gen)
                log.info("reply: %s", res.reply)
            if res.unspoken:
                log.warning("unspoken %d (aborted=%s): %s", len(res.unspoken), res.aborted, " / ".join(res.unspoken)[:300])
            if res.error:
                self._set_error(res.error)
            elif res.spoken:
                self._set_error("")
            while gen == self._gen and self._playing() and not self._stop_evt.is_set():
                time.sleep(0.05)
            current = gen == self._gen
            if current and not isinstance(item, SayItem):  # 主程序让念的话不是在跟主人对话，不开免喊窗口
                self._open_followup()
            if res.spoken and current:
                self.hub.stage(uid, "play", "done", f"念完 {len(res.spoken)} 句")
            elif res.aborted or not current:
                self.hub.stage(uid, "play", "blocked", "被打断")
            else:
                self.hub.stage(uid, "play", "skipped", "没有能念的句子")
            self.hub.finish(uid, reply=res.reply, spoken=res.spoken, unspoken=res.unspoken, error=res.error or "",
                            timings=self._turn_timings(uid, marks))
            run_id = getattr(self.brain, "last_run_id", None)
            if uid and run_id and not isinstance(item, SayItem):
                threading.Thread(target=self._fill_gateway_phases, args=(uid, run_id, dict(marks)), name="runtrace",
                                 daemon=True).start()
        finally:
            self._turn_uid, self._turn_marks = None, None
            with self._lock:
                if gen == self._gen:
                    self.state = "LISTENING"

    def _turn_timings(self, uid: str | None, m: dict) -> dict:
        """耗时拆分（毫秒）：听完 → 排队 → 网关首字 → 首句成形 → 合成首句 → 真正出声。"""
        rec = self.hub.record(uid) if uid else None
        heard = rec["t0"] if rec else None

        def ms(a: float | None, b: float | None) -> int | None:
            return round((b - a) * 1000) if a is not None and b is not None else None

        t = {"queue_ms": ms(heard, m.get("turn_start")), "gateway_first_ms": ms(m.get("turn_start"), m.get("first_token")),
             "first_sentence_ms": ms(m.get("first_token"), m.get("first_sentence")), "tts_first_ms": m.get("tts_first_ms"),
             "play_lag_ms": ms(m.get("first_enqueue"), m.get("first_play")),
             "first_sound_ms": ms(heard if heard is not None else m.get("turn_start"), m.get("first_play"))}
        return {k: v for k, v in t.items() if v is not None}

    def _fill_gateway_phases(self, uid: str, run_id: str, marks: dict) -> None:
        """轮次结束后去网关会话库查这一轮的内部时间点，把网关首字拆成"网关准备"和"模型首字"。"""
        for _ in range(3):
            ph = run_phases(run_id)
            if ph and "prompt_submitted" in ph:
                t = {"gateway_prep_ms": round((ph["prompt_submitted"] - marks["turn_start"]) * 1000)}
                if "first_token" in marks:
                    t["model_first_ms"] = round((marks["first_token"] - ph["prompt_submitted"]) * 1000)
                self.hub.update(uid, run_id=run_id, timings=t)
                return
            time.sleep(1.0)

    def _on_turn_event(self, name: str, data: dict) -> None:
        """TurnRunner 的进度 → 面板环节状态与耗时记点。"""
        uid, m = self._turn_uid, self._turn_marks
        if m is None:
            return
        t = data.get("t", time.time())
        if name == "first_token":
            m["first_token"] = t
            self.hub.stage(uid, "gateway", "active", f"首字 {round((t - m['turn_start']) * 1000)}ms")
        elif name == "sentence":
            m.setdefault("first_sentence", t)
        elif name == "tts_start":
            self.hub.stage(uid, "tts", "active", data.get("text", "")[:16])
        elif name == "tts_done":
            m.setdefault("tts_first_ms", data.get("ms"))
            self.hub.stage(uid, "tts", "done", f"{data.get('text', '')[:12]} {data.get('ms')}ms")
        elif name == "tts_fail":
            self.hub.stage(uid, "tts", "blocked", data.get("error", ""))
        elif name == "enqueued" and data.get("n") == 1:
            m.setdefault("first_enqueue", t)
            self.hub.stage(uid, "play", "active", "开始播放")
        elif name == "stream_end":
            self.hub.stage(uid, "gateway", "done" if data.get("ok") else "blocked",
                           "回复完毕" if data.get("ok") else data.get("error", ""))

    def _on_tool(self, entry: dict) -> None:
        """审计跟随：主线会话的工具调用记到当前这一轮上（没有进行中的语音轮就只打日志）。"""
        log.info("tool %s %s %s: %s", entry["tool"], entry["level"], entry["decision"], entry["summary"])
        uid = self._turn_uid
        if uid:
            self.hub.add_tool(uid, entry)
            note = f"{entry['tool']} {entry['level']} {entry['decision']}"
            if entry["decision"] == "approval-requested":
                note = f"{entry['tool']} {entry['level']} 等审批"
            self.hub.stage(uid, "tools", entry["state"], note)

    def _enqueue_pcm(self, gen: int, pcm: np.ndarray, sr: int) -> None:
        """TurnRunner 的入队回调：重采样到流采样率；本轮第一句前补静音前导并记首音延迟。"""
        if sr != self.sr:
            x_old = np.linspace(0, 1, len(pcm), endpoint=False)
            x_new = np.linspace(0, 1, int(len(pcm) * self.sr / sr), endpoint=False)
            pcm = np.interp(x_new, x_old, pcm).astype(np.float32)
        if self._turn_first:
            pcm = np.concatenate([np.zeros(self.sr * LEAD_SILENCE_MS // 1000, dtype=np.float32), pcm])
            self._turn_first = False
            log.info("first audio %.2fs after turn start", time.monotonic() - self._turn_t0)
        self.play_q.put((gen, pcm))  # 即使此刻恰好被打断，回调也会按代次丢掉它

    def _begin_speaking(self) -> int:
        with self._lock:
            self.state = "SPEAKING"
            return self._gen

    def stop_speaking(self, reason: str) -> None:
        """打断：换代（回调自行丢弃旧代音频）、断开进行中的 TTS 请求、清播放队列、回到监听。

        不碰网关流：断开连接会让网关取消这一轮（连同它等着的审批）；大脑线程会把流读完，只是不再合成。
        """
        with self._lock:
            self._gen += 1
            self.state = "LISTENING"
            self.tts.abort()
        while True:  # 清播放队列（回调也会按代次丢弃，这里立即清掉省得积压）
            try:
                self.play_q.get_nowait()
            except queue.Empty:
                break
        log.info("stop speaking (%s)", reason)
        if reason == "barge-in":
            self.hub.stage(self._turn_uid, "barge", "done", "被主人打断")
            self._open_followup()

    # ---------- 控制口 / 面板 / 托盘 ----------
    def say(self, text: str) -> tuple[bool, str]:
        """控制口 /say：静音或游戏中拒绝，排队超过上限回 busy，否则排进大脑队列（与语音轮按顺序念）。"""
        if self._muted.is_set():
            return False, "muted"
        if self._paused.is_set():
            return False, "gaming"
        if sum(isinstance(x, SayItem) for x in list(self.text_q.queue)) >= SAY_MAX_PENDING:
            return False, "busy"
        uid = self.hub.new_utterance("say", text=text, verdict="say", reason="主程序让电脑念")
        self.text_q.put(SayItem(text, uid))
        log.info("say queued: %s", text)
        return True, "queued"

    def status(self) -> dict:
        """控制口 /status 与面板状态栏。"""
        v = self.view()
        return {"view": v.key, "label": v.label, "state": self.state, "muted": self._muted.is_set(),
                "gaming": self._paused.is_set(), "runtime": self.runtime.state, "gateway": self.health.gateway,
                "tts": self.health.tts, "error": self.last_error, "sleep": self.sleep_state, "pending": self.text_q.qsize(),
                "followup_left": max(0.0, round(self._followup_until - time.monotonic(), 1)),
                "wake_words": list(self.store.current.wake_words), "panel": PANEL_URL}

    def set_sleep_state(self, state: str) -> bool:
        """控制口 /sleep-state：P4 休眠状态位，只做显示。"""
        self.sleep_state = state
        self._refresh_tray()
        self.hub.status(self.status())
        return True

    def view(self) -> TrayView:
        return tray_view(muted=self._muted.is_set(), gaming=self._paused.is_set(), busy=self.state == "SPEAKING",
                         health=self.health, last_error=self.last_error, sleep_state=self.sleep_state)

    def toggle_mute(self) -> None:
        """托盘左键 / 面板按钮：静音（不听不说，立即停播）/ 取消静音。"""
        if self._muted.is_set():
            self._muted.clear()
            log.info("unmuted")
        else:
            self._muted.set()
            self.stop_speaking("静音")
            log.info("muted")
        self._refresh_tray()
        self.hub.status(self.status())

    def request_exit(self, code: int) -> None:
        """托盘/面板：退出语音（0，看门狗不再拉起）/ 重启语音（3，看门狗立即拉起）。"""
        log.info("exit requested: code=%d", code)
        self._exit_code = code
        self._stop_evt.set()

    def _panel_control(self, action: str) -> tuple[bool, str]:
        """面板按钮。重启/退出延迟半秒执行，先让 HTTP 回应发出去。"""
        if action in ("mute", "unmute"):
            if self._muted.is_set() != (action == "mute"):
                self.toggle_mute()
            return True, "已静音" if action == "mute" else "已取消静音"
        code = EXIT_RESTART if action == "restart" else EXIT_QUIT
        threading.Timer(0.5, self.request_exit, args=(code,)).start()
        return True, "正在重启语音" if action == "restart" else "语音已退出，看门狗不会再拉起（双击桌面「管家面板」可重新打开）"

    def open_panel(self) -> None:
        """托盘「打开面板」：用默认浏览器打开。"""
        webbrowser.open(PANEL_URL)

    def _apply_settings(self, s: Settings) -> None:
        """设置变了（面板或手工改文件）：唤醒词、声纹门槛、打断线、应答语立即生效。"""
        self.wake = WakeMatcher(s.wake_words)
        if self.gate:
            self.gate.threshold = s.spk_threshold
        self.barge.cfg = replace(self.barge.cfg, rms_min=s.barge_rms_min)
        if s.ack_text != self._ack_text and self.health.tts:
            self._prepare_ack()
        log.info("settings applied: %s", to_dict(s))
        self.hub.status(self.status())

    def _set_error(self, msg: str) -> None:
        msg = msg[:120]
        if msg != self.last_error:
            self.last_error = msg
            if msg:
                log.warning("error: %s", msg)
            self._refresh_tray()

    def _on_health(self, h: Health) -> None:
        self.health = h
        log.info("health: gateway=%s tts=%s", h.gateway, h.tts)
        if h.tts:
            self._prepare_ack()
        self._refresh_tray()
        self.hub.status(self.status())

    def _refresh_tray(self) -> None:
        if self.tray:
            self.tray.refresh()

    # ---------- 运行态 ----------
    def _on_runtime(self, old: str, new: str) -> None:
        """监控线程回调：只置位/清标志并打断当前播放，真正停开音频流留给主循环做（流操作集中在一个线程）。"""
        if old == ACTIVE:
            log.info("runtime: 离开 ACTIVE → %s，主动侧静默", new)
        if new == GAMING:
            self._paused.set()
            self.stop_speaking("gaming")
        elif old == GAMING:
            self._paused.clear()

    def quiet(self) -> bool:
        """主动侧查询：游戏中或开机/游戏后 5 分钟静默期内返回 True，不许主动开口。"""
        return self.runtime.is_quiet()

    @property
    def quiet_until(self) -> float:
        """静默期截止时间戳（epoch 秒）；游戏中另由 quiet() 判定。"""
        return self.runtime.quiet_until

    def set_gaming(self, on: bool) -> None:
        """手动开关："我打游戏了" / "不打了"。"""
        self.runtime.set_manual_gaming(on)

    def _suspend_audio(self, s: sd.Stream) -> None:
        """进入游戏态：停流、清空积压、释放 ASR（CPU 内存）、通知 TTS 服务释放显存。主循环调用。"""
        s.stop()
        for q in (self.in_q, self.text_q):
            while not q.empty():
                q.get_nowait()
        self.asr = None
        self.asr_final = None
        threading.Thread(target=self.tts.control, args=("unload",), name="tts-unload", daemon=True).start()
        log.info("gaming: 音频流已停，ASR（流式+精识别）已释放")

    def _resume_audio(self, s: sd.Stream) -> None:
        """离开游戏态：重建 ASR/VAD 与前端状态，重开音频流，后台让 TTS 预加载。主循环调用。"""
        self.asr = StreamingASR()
        self.asr_final = FinalASR()
        self._reset_frontend()
        s.start()
        threading.Thread(target=self.tts.control, args=("load",), name="tts-load", daemon=True).start()
        log.info("gaming 结束: 音频流已恢复")

    # ---------- 主循环 ----------
    def run(self) -> None:
        logging.getLogger().addHandler(HubLogHandler(self.hub))
        s = self.store.current
        log.info("device rate %d, in=%s out=%s, speakers=%s(%s), gate=%s@%.2f, wake=%s(required=%s) followup=%.0fs, "
                 "mic_gain=%.1f, aec=%s, barge=%dms guard=%dms rms_min=%.4f ratio=%.1f, tts_timeout=%.0fs, session=%s, "
                 "control=127.0.0.1:%d", self.sr, self.in_dev, self.out_dev, self.gate.names() if self.gate else "off",
                 self.gate.model.stem if self.gate else "-", self.gate_mode, s.spk_threshold, "/".join(s.wake_words),
                 s.wake_required, s.follow_up_sec, self.mic_gain, "on" if self.aec else "off", BARGE_MS, BARGE_GUARD_MS,
                 s.barge_rms_min, BARGE_FLOOR_RATIO, TTS_TIMEOUT_SEC, MAIN_SESSION_KEY, self.control_port)
        try:
            self.control = start_control_server(self, self.control_port, panel=self.panel)
        except OSError as e:
            log.error("控制口 127.0.0.1:%d 绑不上（是不是已经有一个语音进程在跑？）：%s", self.control_port, e)
            sys.exit(EXIT_CRASH)
        threads = [threading.Thread(target=self._frontend, name="frontend", daemon=True),
                   threading.Thread(target=self._brainloop, name="brain", daemon=True)]
        for t in threads:
            t.start()
        self.monitor.start()
        self.audit.start()
        if self.tray_on:
            from guanjia.tray import Tray  # 延迟导入：--no-tray 时不需要 pystray/Pillow

            self.tray = Tray(view=self.view, muted=self._muted.is_set, on_toggle_mute=self.toggle_mute,
                             on_restart=lambda: self.request_exit(EXIT_RESTART),
                             on_exit=lambda: self.request_exit(EXIT_QUIT), on_open_panel=self.open_panel)
            self.tray.start()
        failed = False
        shown = ""
        last_stats, stats = time.monotonic(), (0, 0)
        last_settings_poll = time.monotonic()
        with sd.Stream(samplerate=self.sr, blocksize=self.frame, dtype="float32", channels=1, latency="low",
                       device=(self.in_dev, self.out_dev), callback=self._callback) as s:
            log.info("listening ... (latency in/out %.3f/%.3f s; output stream always-open, comfort noise %.0f dBFS, "
                     "lead %dms, panel %s, dump %s)", *s.latency, COMFORT_NOISE_DBFS, LEAD_SILENCE_MS, PANEL_URL,
                     SEG_DUMP_DIR)
            self.hub.stage(None, "mic", "active", "在听")
            self.runtime.start()  # 开机补写离线区间 + 5 分钟静默；之后每 2s 检测游戏态
            try:
                while not self._stop_evt.is_set():
                    time.sleep(0.5)
                    paused = self._paused.is_set()  # 本轮只读一次，防监控线程中途翻转导致误判"流死了"
                    if paused and s.active:
                        self._suspend_audio(s)
                    elif not paused and not s.active:
                        self._resume_audio(s)
                    dead = [t.name for t in threads if not t.is_alive()]
                    if dead or (not s.active and not paused):
                        log.error("worker died: threads=%s stream_active=%s，退出等待看门狗拉起", dead, s.active)
                        failed = True
                        break
                    key = self.view().key
                    if key != shown:  # 说话中 ↔ 在听 等状态变化同步到托盘和面板
                        shown = key
                        self._refresh_tray()
                        self.hub.status(self.status())
                        self.hub.stage(None, "mic", "blocked" if key in ("muted", "gaming") else "active", self.view().label)
                    while self._play_events:  # 回调记下的"真正写入输出流"的时刻与时长
                        t0, dur, g = self._play_events.popleft()
                        marks = self._turn_marks
                        if marks is not None and g == self._turn_gen and "first_enqueue" in marks:
                            marks.setdefault("first_play", t0)
                        log.info("play: start=%s dur=%.2fs gen=%d", datetime.fromtimestamp(t0).strftime("%H:%M:%S.%f")[:-3],
                                 dur, g)
                    if time.monotonic() - last_settings_poll >= SETTINGS_POLL_SEC:
                        last_settings_poll = time.monotonic()
                        self.store.maybe_reload()
                    if time.monotonic() - last_stats >= STATS_EVERY_SEC:
                        last_stats = time.monotonic()
                        if (self._dropped, self._underflows) != stats:
                            stats = (self._dropped, self._underflows)
                            log.warning("累计丢帧 %d，输出欠载 %d", *stats)
            except KeyboardInterrupt:
                self._exit_code = EXIT_QUIT
        self._stop_evt.set()
        self.runtime.stop()  # 最后一次心跳，下次开机据此算离线区间
        self.monitor.stop()
        self.audit.stop()
        if self.tray:
            self.tray.stop()
        self.control.shutdown()
        code = EXIT_CRASH if failed else (EXIT_QUIT if self._exit_code is None else self._exit_code)
        log.info("voice daemon exit code=%d", code)
        sys.exit(code)
```
