# 管家 P2「语音直连主线 + 托盘入口 + 主程序能开口」Implementation Plan

> **For agentic workers:** To implement this plan, use `executing-plans` (inline) or `subagent-driven-development` (parallel, explicit user request only). Follow project Git rules — do not create branches or worktrees unless the user asks. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 语音识别出的话直接流式进网关主线会话 `agent:main:main`（不再经 front/backoffice 转述），回复按句交给 TTS；打断只停播放、不断开连接；说完话立刻有提示音；微信里说「念一句：……」电脑用 SCV 音色念出来；TTS 与语音守护进程登录后自启、崩溃自拉起；托盘图标显示 在听 / 静音 / 出错 并可切换静音、重启、退出；然后直接上线。

**Architecture:** 语音守护进程 `guanjia.voice` 保留现有的音频前端（VAD / 流式 ASR / SenseVoice 精识别 / CAM++ 声纹 / 保活噪声），把「一轮回复」抽成与硬件无关的 `TurnRunner`（网关流 → 切句 → 过滤 → 合成 → 入播放队列，打断只换代、流照样读完），打断判定抽成 `BargeDetector`（不再依赖 VAD）。守护进程内开一个只听 127.0.0.1 的控制口（`/say`、`/status`、`/sleep-state`）和 pystray 托盘；分级插件 `guanjia-guard` 注册 `speak` 工具（L1）去调 `/say`。PowerShell 看门狗 `scripts/voice-supervisor.ps1` 负责等依赖、按退出码拉起、进程树清理；两个计划任务改为登录触发。主线队列用会话级 `/queue followup` 只设在 `agent:main:main` 上。

**Tech Stack:** Python 3.12（`F:\coding\guanjia\.venv`，uv 管理；httpx、numpy、sounddevice；新增 pystray + Pillow），OpenClaw 2026.9.6（Node v24.21.0；插件 TypeScript 由网关直接加载），IndexTTS-2.5（WSL Ubuntu，端口 18791），Windows 计划任务 + WScript + Windows PowerShell 5.1。测试：Python 用最小断言脚本（项目里没有 pytest，也不新增），插件用 `node:assert/strict` + `npx --yes tsx`（沿用 P1），看门狗用 PowerShell 断言脚本。

## 背景（执行者必读：为什么这样改）

### 已查清的 OpenClaw 行为（证据在 OpenClaw 自带 docs/dist，路径相对 `node_modules\openclaw\`）

1. **HTTP 客户端断开 = 取消本轮。** `docs/gateway/openai-http-api.md`：「Disconnecting the HTTP client cancels active source-URL downloads and the agent run.」所以语音侧打断时**绝不能**关闭网关流，只停播放，流要读到 `[DONE]`。读超时也会断开，所以流式读超时设 900 秒（L3 审批 120 秒、慢工具都在这之内）。
2. **system 消息 = 本轮 extraSystemPrompt。** `dist/openai-http-Gs9PjNdV.mjs:311-346`：`messages` 里的 system/developer 合成 `extraSystemPrompt` 只作用于这一轮，user/assistant 被拼成一条消息。旧 `voice.py` 每轮发「人设 + 精确到分钟的当前时间」作 system，系统提示每分钟变一次，会打掉提示缓存。P2 改为**用户消息前缀标记** `[语音 …]` + `AGENTS.md` 规则，系统提示保持稳定，微信轮不带前缀就不受字数限制。
3. **队列模式。** 配置键 `messages.queue.mode`（全局）和 `messages.queue.byChannel.<channel>`（按渠道；HTTP 接口的渠道默认是 `webchat`），优先级最高的是**会话级覆盖**：在会话里单独发一条 `/queue followup` 会把 `queueMode` 存进该会话条目（`docs/concepts/queue.md:110-124`）。`sessions.patch` 不能改它（`dist/src-BRUl7oDv.mjs:2140` 的 schema 里没有 queueMode），但 `sessions.reset` 换新时会保留它（`dist/session-reset-service-z65ES5vD.mjs:1184` `queueMode: currentEntry?.queueMode`），所以 P4 休眠换新后仍是 followup。`/queue followup` 是纯指令消息，只回一句 `Queue mode set to followup.`，不调模型（`dist/directive-handling.impl-BdmftRhg.mjs:646`）。`sessions.list` 的行里有 `queueMode` 和 `effectiveQueueMode`（`dist/session-row-prepared-read-C4fL38cb.mjs:799-800`），用它核对。本计划**只给主线会话设 followup**，不动 `openclaw.json`。
4. **插件注册工具。** `api.registerTool({ name, description, parameters, execute(toolCallId, params, signal?) })`，返回 `{ content: [{ type: "text", text }], details }`；`parameters` 可以是普通 JSON Schema 对象（不必引 typebox，插件从仓库目录加载，解析不到 typebox）。每个注册的工具必须写进清单 `contracts.tools`（`docs/plugins/building-plugins.md:120-123, 313-327`；`docs/plugins/manifest/capabilities.md:89`）。`openclaw plugins inspect <id> --runtime --json` 会加载插件模块并列出注册的工具，可在重启前验证。插件当前 `trust.reason = origin-path`（来自配置路径），没有能力授权记录问题。
5. **工具搜索下会变成延期工具。** `tools.toolSearch` 未设置时默认结构化 `tools` 模式（`docs/tools/tool-search.md:22-27, 96-99`），插件工具进目录、不直接暴露，目录 id 是 `openclaw:guanjia-guard:speak`（`dist/local-model-lean-CHSAjCEl.mjs:203-214`），模型要用 `tool_call`（`id: speak`，参数放 `args`）调用；搜索词必须是英文，所以工具描述写英文。和 P1 的 `web_fetch` 一样，在 `AGENTS.md` 写明调用方式。分级插件对 `tool_call` 外层按真实工具定级，裸名字不在分级表里会被强制 L3，所以分级表必须有 `speak: L1`。
6. **语音轮的口头确认。** 分级插件 L2 靠「用户下一句以 确认/好/可以… 开头」放行；语音轮的消息带 `[语音 …]` 前缀，不剥掉就永远对不上。P2 在插件里剥掉这个前缀再判断。

### 「有字不出声」根因（证据：被控机 `F:\coding\guanjia\tmp\voice.log`，家里时间）

- **A. TTS 不可用时，文字照样出现、声音没有。** 09-30 23:42:45 / 23:43:15 / 23:43:45 连续三条 `tts error: timed out`（当时 TTS 被另一个实验占着，30 秒超时），23:43:45 仍记下 `reply: 我在呢，刚才就回你了……`；23:59:54 `tts error (1/2): [WinError 10061]`（TTS 服务不在）后同样记下 reply。前台窗口只显示文字，用户看到「有字」。旧代码失败只打日志，没有任何可见状态。
- **B. 合成成功、也写进了输出流，但人没听到（音箱侧吞音）。** 10-01 00:32:17–00:32:19 TTS 返回 200（合成 2.27s，168KB），随后 00:32:20–00:32:23 有 `barge-mon` 行（只在「本块写出了真实语音」时打印），说明音频确实写进了输出流；00:32:44–00:32:49 第二轮同样如此；但主人 00:33:05 说「听得见？」、00:33:41 说「说话呀」，00:35 反馈「高概率出现出文字但是不出声音」。那时输出流空闲时写的是纯零（保活噪声 00:47 才加），音箱条（内置 DSP、自动待机/噪声门）在静默后吞掉了整句。00:47 加上 -70 dBFS 保活噪声与 150ms 前导后，06:07 那次主人能听到并反馈「他循环了」。
- **结论与 P2 处理：** A 是确定根因；B 是高度可能的根因（有「写进输出流但没被听到」与「加保活后能听到」两组对照，但没有逐句的主人确认）。P2：保留保活噪声与前导，并允许 `GUANJIA_COMFORT_DBFS` 调高；每句没念出来都记 `unspoken`（被打断 / TTS 失败 / 过滤为空）；TTS 或网关不在线、最近一轮 TTS 失败时托盘变红；看门狗等 TTS 就绪才起语音；用户验收逐句核对。另外把 `NO_REPLY`、纯标点、Markdown 符号等念不出来的句子过滤掉，避免「有字但 TTS 合成了个空」。

### 「打断不生效」根因（证据同上）

- 旧逻辑要求「打断专用 VAD 判为人声」**且**「平滑能量 > 自适应底噪 × 2.5」，累计 180ms 才打断，VAD 一掉线累计就清零；底噪在「没过线」的帧上持续学习。
- 10-01 06:07:49–06:07:52 播放期间 `barge-mon raw_peak=0.03281 / 0.03653 / 0.09830 / 0.02493`（主人在说话，原始输入明显有声），能量峰值 0.0166、0.0288 已超过线 0.0090，但四次采样都是 `voice=False`、`hot=0ms`；06:07:43 那一行 `voice=True` 时底噪已从 0.0007 涨到 0.0182，线被抬到 0.0463。也就是：音箱条 DSP 处理过的近端人声让 Silero VAD 几乎判不出，底噪又会追着主人的声音涨，累计永远到不了 180ms。主人只有说完一整句、识别并过声纹后才会停（「新一轮」），体感就是「我说话它不停」。
- 回声本身很弱：只有回声时原始峰值 0.00015–0.002（08:18、08:52、06:07:03–05），起播瞬间有一个 0.013 的尖峰。
- **P2 处理：** `BargeDetector` 不再要求 VAD；保护期（300ms）里只学回声底噪，100ms 之后才计入（避开起播尖峰），之后冻结不再学；触发线 = max(0.004, 底噪 × 3)，过线累加、掉线按 5ms/帧回落（漏桶），累计 180ms 打断。打断只停播放，网关那一轮照常跑完。阈值 0.004 是按上面日志推的，验收时按 `barge-mon` 日志校准（`GUANJIA_BARGE_RMS_MIN` 可调）。

### 「开口慢」与硬件边界

- 日志里从送出请求到第一句可合成：00:21:34→00:21:45（11.5s）、00:32:09→00:32:17（8.0s）、00:32:36→00:32:44（7.2s）、00:33:41→00:33:50（8.2s），第一句合成 2.0–2.6s。慢主要在模型首字。P2 能做的：说完立刻放本地提示音（体感）、系统提示不再每分钟变（提示缓存）、仍按句合成（首句 20 字硬上限）。每轮记一行 `first audio X.XXs after turn start` 便于验收量化。真正把首声压到 2 秒内是 P8（本地快路径）。
- **不在本期解决：** 离远听不懂、转文字差（音箱条麦克风电平低、只能贴近说；软件增益已到 3 倍上限）；远场拾音需要换硬件，主人已定暂不买设备。本期验收只要求「正常距离（1 米内）说话能识别」。声纹在关掉 AEC 后分数从 0.75 降到 0.61，建议重录但不强制（见用户验收「可选」）。
- **不在本期：** 游戏时静默的完善（P7）、开机首条消息闸门与休眠（P4，本期只在托盘和控制口留 `sleep` 状态位）、微信并进主线（P3，所以本期主线里只有语音，followup 设置是为 P3 准备的）。

```python
"""把流式到达的回复文本切成可朗读的句子：按中文/英文句末标点切，逗号处只在句子已经够长时切，保证第一句尽早出声。

speakable() 再把一句话里念不出来的东西去掉（Markdown 符号、链接、表情、静默标记 NO_REPLY），什么都不剩就不念。
"""

from __future__ import annotations

import re
from collections.abc import Iterator

END = set("。！？!?；;\n")
SOFT = set("，,、：:")

_SILENT_RE = re.compile(r"^\s*NO_REPLY\s*$", re.IGNORECASE)  # OpenClaw 的静默回复标记，整句就是它时不念
_URL_RE = re.compile(r"https?://\S+")
_EMOJI_RE = re.compile("[\U0001F000-\U0001FAFF\u2600-\u27BF\uFE0F\u200D]")
_BULLET_RE = re.compile(r"^\s*(?:[•·]\s*|[-*]\s+|\d+[.、)）]\s+)")  # 行首列表符号；"1.5 度"这类小数不算
_MD_RE = re.compile(r"[*#`>|_~\[\]]+")
_SPACE_RE = re.compile(r"\s+")
_WORD_RE = re.compile(r"[0-9A-Za-z\u4e00-\u9fff]")


class SentenceSplitter:
    def __init__(self, soft_min_chars: int = 18, hard_max_chars: int = 60, first_soft_min_chars: int = 8,
                 first_hard_max_chars: int | None = None) -> None:
        self.soft_min = soft_min_chars
        self.hard_max = hard_max_chars
        self.first_hard_max = first_hard_max_chars or hard_max_chars  # 第一句的硬上限：无标点时不等满 hard_max 才出声
        self.first_soft_min = first_soft_min_chars  # 第一句在逗号处更早切，让首字尽快出声
        self._buf = ""
        self._emitted = 0

    def push(self, piece: str) -> Iterator[str]:
        """喂一段增量文本，yield 已经完整的句子。"""
        self._buf += piece
        while True:
            cut = self._find_cut()
            if cut is None:
                return
            sent, self._buf = self._buf[:cut].strip(), self._buf[cut:]
            if sent:
                self._emitted += 1
                yield sent

    def flush(self) -> Iterator[str]:
        rest, self._buf = self._buf.strip(), ""
        if rest:
            yield rest

    def _find_cut(self) -> int | None:
        first = self._emitted == 0
        soft_min = self.first_soft_min if first else self.soft_min
        hard_max = self.first_hard_max if first else self.hard_max
        for i, ch in enumerate(self._buf):
            if ch in END:
                return i + 1
            if ch in SOFT and i + 1 >= soft_min:
                return i + 1
            if i + 1 >= hard_max:
                return i + 1
        return None


def speakable(sent: str) -> str:
    """一句回复里能念出来的部分；只剩标点、表情或静默标记时返回空串（调用方据此跳过这一句）。"""
    if _SILENT_RE.match(sent):
        return ""
    s = _URL_RE.sub("", sent)
    s = _EMOJI_RE.sub("", s)
    s = _BULLET_RE.sub("", s)
    s = _MD_RE.sub("", s)
    s = _SPACE_RE.sub(" ", s).strip()
    return s if _WORD_RE.search(s) else ""


if __name__ == "__main__":
    s = SentenceSplitter()
    stream = ["今天天气不", "错，适合出去走走。", "要不要我帮你查一下附近的公园？", "顺便提醒，", "下午三点有会"]
    for p in stream:
        for sent in s.push(p):
            print("SENT:", sent)
    for sent in s.flush():
        print("FLUSH:", sent)
```

```python
"""大脑客户端：把识别出的文字交给 OpenClaw 网关（OpenAI 兼容的 /v1/chat/completions），流式收回回复文本。

- token 从 ~/.openclaw/openclaw.json 读（gateway.auth.token），也可用环境变量 GUANJIA_GATEWAY_TOKEN 覆盖；
- 语音（P2 起）：带 x-openclaw-session-key: agent:main:main 进主线会话，不带 user、不带 system、默认不换模型
  （走网关默认 DeepSeek-V4-Flash）；每句话前加「[语音 时间]」标记，AGENTS.md 据此只在语音轮简短作答。
  标记放在用户消息里而不是 system：system 每轮变化会打掉网关的提示缓存，首字更慢；
- stream(text) 是同步生成器，逐段 yield 回复文本。语音侧不得提前关闭它：网关把客户端断开当作取消本轮
  （连同这一轮里等着的审批），所以打断只停播放，流要读到 [DONE]；读超时同样会断开，故设得很长；
- user 会话方式（backoffice 用）保留兼容。
"""

from __future__ import annotations

import json
import os
from collections.abc import Iterator
from datetime import datetime
from pathlib import Path

import httpx

DEFAULT_URL = "http://127.0.0.1:18789/v1/chat/completions"
MAIN_SESSION_KEY = "agent:main:main"  # 主线会话：主人的语音 + 微信共用
# 语音入口指定的网关模型（x-openclaw-model 头）；空串 = 不加头，走网关默认模型（DeepSeek-V4-Flash）
VOICE_MODEL = os.environ.get("GUANJIA_VOICE_MODEL", "")
# 流式读超时：要远长于 L3 审批（120 秒）和慢工具。读超时会断开连接 = 取消本轮，宁可多等
STREAM_READ_TIMEOUT_SEC = 900.0
_WEEKDAY_CN = "一二三四五六日"


def voice_tag(now: datetime | None = None) -> str:
    """语音轮标记，例如「[语音 2026-10-10 18:05 周六]」；AGENTS.md 的语音规则和分级插件都认这个前缀。"""
    now = now or datetime.now()
    return f"[语音 {now:%Y-%m-%d %H:%M} 周{_WEEKDAY_CN[now.weekday()]}]"


def tag_voice_text(text: str, now: datetime | None = None) -> str:
    """给识别出的一句话加上语音轮标记。"""
    return f"{voice_tag(now)} {text}"


def load_gateway_token() -> str:
    env = os.environ.get("GUANJIA_GATEWAY_TOKEN")
    if env:
        return env
    cfg = Path.home() / ".openclaw" / "openclaw.json"
    data = json.loads(cfg.read_text(encoding="utf-8"))
    return data["gateway"]["auth"]["token"]


class Brain:
    """OpenClaw 网关的最小客户端。"""

    def __init__(self, url: str = DEFAULT_URL, token: str | None = None, timeout: float = STREAM_READ_TIMEOUT_SEC,
                 model: str | None = None, user: str | None = None, session_key: str | None = None,
                 transport: httpx.BaseTransport | None = None) -> None:
        self.url = url
        self.model = VOICE_MODEL if model is None else model  # x-openclaw-model 头；空串不加
        self.user = user  # 旧方式：网关按 user 派生会话（只在没有 session_key 时发送）
        self.session_key = session_key  # 新方式：显式会话键，例如 agent:main:main
        self.token = token or load_gateway_token()
        self._client = httpx.Client(timeout=httpx.Timeout(timeout, connect=5.0), trust_env=False,  # 本机网关，不走系统代理
                                    transport=transport)
        self._resp: httpx.Response | None = None  # 进行中的流式响应（仅供旧代码 abort 用，语音侧不调用）

    def _headers(self) -> dict[str, str]:
        h = {"Authorization": f"Bearer {self.token}", "Content-Type": "application/json"}
        if self.model:
            h["x-openclaw-model"] = self.model
        if self.session_key:
            h["x-openclaw-session-key"] = self.session_key
        return h

    def _body(self, text: str, system: str | None, stream: bool) -> dict:
        msgs = ([{"role": "system", "content": system}] if system else []) + [{"role": "user", "content": text}]
        body: dict = {"model": "openclaw", "messages": msgs}
        if stream:
            body["stream"] = True
        if self.user and not self.session_key:
            body["user"] = self.user
        return body

    def ask(self, text: str, system: str | None = None) -> str:
        """非流式：整句回复（后台任务用）。"""
        r = self._client.post(self.url, headers=self._headers(), json=self._body(text, system, stream=False))
        r.raise_for_status()
        return r.json()["choices"][0]["message"]["content"]

    def stream(self, text: str, system: str | None = None) -> Iterator[str]:
        """流式：逐段 yield 回复文本；流里出现 error 对象时抛 RuntimeError（网关已经结束这一轮）。"""
        with self._client.stream("POST", self.url, headers=self._headers(), json=self._body(text, system, stream=True)) as r:
            self._resp = r
            try:
                r.raise_for_status()
                for line in r.iter_lines():
                    if not line.startswith("data:"):
                        continue
                    payload = line[5:].strip()
                    if payload == "[DONE]":
                        break
                    try:
                        chunk = json.loads(payload)
                    except json.JSONDecodeError:
                        continue
                    err = chunk.get("error")
                    if isinstance(err, dict):
                        raise RuntimeError(f"网关报错：{err.get('message') or err.get('type') or err}")
                    delta = (chunk.get("choices") or [{}])[0].get("delta", {}).get("content")
                    if delta:
                        yield delta
            finally:
                self._resp = None

    def abort(self) -> None:
        """旧代码用的强制关闭；语音守护进程自 P2 起不调用（关闭连接会让网关取消本轮）。"""
        r = self._resp
        if r is not None:
            r.close()

    def close(self) -> None:
        self._client.close()
```

```python
    def __init__(self, pieces, fail_synth=0, bump_gen_after_enqueue=None, raise_after=None, abort_on_synth=None):
        self.pieces = pieces
        self.fail_synth = fail_synth  # 前 N 次合成抛错

            self.gen += 1
```

```python
"""一轮语音回复的编排（与音频硬件无关，可用假对象单测）。

    网关流 piece ──> SentenceSplitter ──> speakable 过滤 ──> synth ──> enqueue(gen, pcm, sr)

- 打断 = 播放代次变了：剩下的句子不再合成、不再入队，但网关流照样读到结束。
  客户端断开连接会让网关取消这一轮（连同等着的审批），所以这里绝不 break、绝不 close 网关流。
- 每句没念出来的都记进 TurnResult.unspoken（被打断 / TTS 失败），"有字不出声"从此有据可查。
- /say 的内容（SayItem）不进网关，直接切句合成。
"""

from __future__ import annotations

import logging
from collections.abc import Callable, Iterator
from dataclasses import dataclass, field

import numpy as np

from guanjia.textseg import SentenceSplitter, speakable

log = logging.getLogger("guanjia.turns")


@dataclass
class SayItem:
    """主程序经控制口 /say 让电脑念的一段话（不进网关，直接合成播放）。"""
    text: str


@dataclass
class TurnResult:
    """一轮的结果：网关回复原文、念出来的句子、没念出来的句子、是否被打断、错误。"""
    reply: str = ""
    spoken: list[str] = field(default_factory=list)
    unspoken: list[str] = field(default_factory=list)
    aborted: bool = False
    error: str | None = None


class TurnRunner:
    """把一轮回复变成按句播放的音频；所有依赖都由调用方注入。"""

    def __init__(self, open_stream: Callable[[str], Iterator[str]], synth: Callable[[str], tuple[np.ndarray, int]],
                 enqueue: Callable[[int, np.ndarray, int], None], current_gen: Callable[[], int], *,
                 first_max_chars: int = 20, max_tts_fails: int = 2) -> None:
        self.open_stream = open_stream  # 文本 -> 网关回复增量（生成器）
        self.synth = synth  # 一句 -> (PCM, 采样率)，失败抛异常
        self.enqueue = enqueue  # (代次, PCM, 采样率) -> 进播放队列
        self.current_gen = current_gen  # 当前播放代次；与本轮代次不同即视为被打断
        self.first_max_chars = first_max_chars
        self.max_tts_fails = max_tts_fails

    def run_reply(self, text: str, gen: int) -> TurnResult:
        """一轮语音对话：读完整个网关流，能念的按句合成入队。"""
        res = TurnResult()
        splitter = SentenceSplitter(first_hard_max_chars=self.first_max_chars)
        fails = [0]  # 本轮 TTS 连续失败次数（列表便于 _speak 里修改）
        try:
            for piece in self.open_stream(text):  # 不 break、不 close：打断时也要读完
                res.reply += piece
                for sent in splitter.push(piece):
                    self._speak(sent, gen, res, fails)
            for sent in splitter.flush():
                self._speak(sent, gen, res, fails)
        except Exception as e:  # noqa: BLE001  网关连接/报错：这一轮结束，交给上层记错误
            res.error = f"网关：{type(e).__name__}: {e}"
        return res

    def run_say(self, text: str, gen: int) -> TurnResult:
        """/say：把给定文本切句合成入队，不经过网关。"""
        res = TurnResult(reply=text)
        splitter = SentenceSplitter()
        fails = [0]
        for sent in [*splitter.push(text), *splitter.flush()]:
            self._speak(sent, gen, res, fails)
        return res

    def _speak(self, sent: str, gen: int, res: TurnResult, fails: list[int]) -> None:
        """合成并入队一句；任何异常都在这里吞掉记账，绝不往外抛（外抛会中断读流、导致连接被关闭）。"""
        s = speakable(sent)
        if not s:
            return
        if gen != self.current_gen():
            res.aborted = True
            res.unspoken.append(s)
            return
        if fails[0] >= self.max_tts_fails:
            res.unspoken.append(s)
            return
        try:
            pcm, sr = self.synth(s)
        except Exception as e:  # noqa: BLE001
            res.unspoken.append(s)
            if gen != self.current_gen():  # 打断时 tts.abort() 关掉了请求：算打断，不算 TTS 失败
                res.aborted = True
                return
            fails[0] += 1
            res.error = f"TTS：{type(e).__name__}: {e}"
            log.error("tts error (%d/%d): %s", fails[0], self.max_tts_fails, e)
            return
        fails[0] = 0
        if gen != self.current_gen():
            res.aborted = True
            res.unspoken.append(s)
            return
        try:
            self.enqueue(gen, pcm, sr)
        except Exception as e:  # noqa: BLE001
            res.unspoken.append(s)
            res.error = f"播放：{type(e).__name__}: {e}"
            return
        res.spoken.append(s)
```

```python
现在：
  每次开始出声后的保护期（300ms）只学回声底噪，前 100ms 不计（避开起播尖峰），保护期后冻结；
  触发线 = max(绝对下限, 底噪 × 倍数)；平滑能量过线就累加，掉线按 decay 回落（漏桶），累计到 180ms 即打断。
"""

from __future__ import annotations

from dataclasses import dataclass


@dataclass(frozen=True)
class BargeConfig:
    frame_ms: int = 10          # 每帧时长
    guard_ms: int = 300         # 出声后的保护期：只学回声底噪，不触发
    learn_after_ms: int = 100   # 保护期里从这之后才计入底噪（起播瞬间有尖峰）
    tail_ms: int = 300          # 参考信号停了以后仍按"在播"算的尾巴（输出延迟 + 混响）
    rms_min: float = 0.004      # 触发线绝对下限（原始输入 RMS，增益前）
    floor_ratio: float = 3.0    # 触发线 = 回声底噪 × 此倍数
    trigger_ms: int = 180       # 累计过线时长达到此值即打断
    decay_ms: int = 5           # 没过线时每帧回落的累计毫秒（一两帧掉线不清零）
    smooth: float = 0.3         # 能量 EMA 系数（约 30ms 时间常数）


class BargeDetector:
    """每 10ms 喂一帧 step(rms, ref_active)，返回 True 表示该打断了。只在前端线程使用。"""

    def __init__(self, cfg: BargeConfig = BargeConfig()) -> None:
        self.cfg = cfg
        self.reset()

    def reset(self) -> None:
        """全部状态归零（启动、游戏态恢复、静音恢复时调用）。"""
        self.since_ref_ms = 10**9  # 距最近一帧"我们在出声"的毫秒数
        self.play_ms = 0           # 本次连续出声已持续的毫秒数
        self.floor = 0.0           # 回声底噪（保护期内的平均能量）
        self._floor_n = 0
        self.energy = 0.0          # 平滑后的原始输入 RMS
        self.hot_ms = 0            # 过线累计（漏桶）

    @property
    def playing(self) -> bool:
        return self.since_ref_ms <= self.cfg.tail_ms

    @property
    def line(self) -> float:
        return max(self.cfg.rms_min, self.floor * self.cfg.floor_ratio)

    def step(self, rms: float, ref_active: bool) -> bool:
        c = self.cfg
        self.since_ref_ms = 0 if ref_active else self.since_ref_ms + c.frame_ms
        self.energy += c.smooth * (rms - self.energy)
        if not self.playing:
            self.play_ms, self.hot_ms, self.floor, self._floor_n = 0, 0, 0.0, 0
            return False
        self.play_ms += c.frame_ms
        if self.play_ms <= c.guard_ms:
            if self.play_ms > c.learn_after_ms:
                self._floor_n += 1
                self.floor += (self.energy - self.floor) / self._floor_n
            return False
        if self.energy > self.line:
            self.hot_ms += c.frame_ms
        else:
            self.hot_ms = max(0, self.hot_ms - c.decay_ms)
        if self.hot_ms >= c.trigger_ms:
            self.hot_ms = 0
            return True
        return False
```

```python
"""本地提示音：主人说完一句、声纹放行后立刻播放，压住等大脑回话的空白（"开口慢"的体感主要来自这段静默）。"""

from __future__ import annotations

import numpy as np

EARCON_AMP = 0.2  # 峰值幅度（满幅 1.0）；音箱条音量本身可调，这里取不刺耳的中等值


def _tone(sr: int, freq: float, ms: int, amp: float) -> np.ndarray:
    """一段带 8ms 淡入淡出的正弦音（防爆音）。"""
    n = sr * ms // 1000
    i = np.arange(n)
    ramp = max(1, sr * 8 // 1000)
    env = np.minimum(1.0, np.minimum(i, n - 1 - i) / ramp)
    return (np.sin(2 * np.pi * freq * i / sr) * env * amp).astype(np.float32)


def earcon(sr: int, amp: float = EARCON_AMP) -> np.ndarray:
    """两声上行短音：880Hz 90ms + 静音 20ms + 1320Hz 110ms，共 0.22 秒，float32 单声道。"""
    gap = np.zeros(sr * 20 // 1000, dtype=np.float32)
    return np.concatenate([_tone(sr, 880.0, 90, amp), gap, _tone(sr, 1320.0, 110, amp)])
```

```python
"""语音守护进程的本机控制口（只听 127.0.0.1）：

    GET  /status                -> 托盘同款状态 JSON
    POST /say {"text": "..."}   -> 让电脑用管家音色念一句（走守护进程自己的播放队列，打断照样生效）
    POST /sleep-state {"state": "awake|sleeping|consolidating"} -> P4 休眠状态位（托盘显示）

防护：只绑 127.0.0.1、只接受本机来源；带 Origin 头（浏览器网页发起）一律 403；POST 必须是 application/json
（浏览器跨站发 JSON 要先过 CORS 预检，这里不回 CORS 头，网页就发不进来）；独占端口，第二个实例绑不上。
"""

from __future__ import annotations

import json
import os
import socket
import threading
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from typing import Protocol

CONTROL_PORT = int(os.environ.get("GUANJIA_CONTROL_PORT", "18795"))
SAY_MAX_CHARS = 300
SLEEP_STATES = ("awake", "sleeping", "consolidating")
_MAX_BODY = 8192


class ControlAPI(Protocol):
    def say(self, text: str) -> tuple[bool, str]: ...

    def status(self) -> dict: ...

    def set_sleep_state(self, state: str) -> bool: ...


class _ExclusiveServer(ThreadingHTTPServer):
    allow_reuse_address = False  # Windows 上 SO_REUSEADDR 会让第二个实例也绑上同一端口，宁可报错
    daemon_threads = True

    def server_bind(self) -> None:
        if hasattr(socket, "SO_EXCLUSIVEADDRUSE"):
            self.socket.setsockopt(socket.SOL_SOCKET, socket.SO_EXCLUSIVEADDRUSE, 1)
        super().server_bind()


def make_control_server(api: ControlAPI, port: int = CONTROL_PORT, host: str = "127.0.0.1") -> ThreadingHTTPServer:
    """建好但不启动；port=0 让系统挑空闲端口（测试用）。端口被占时抛 OSError。"""

    class Handler(BaseHTTPRequestHandler):
        def log_message(self, fmt, *args):  # 不往 stderr 打访问日志
            pass

        def _send(self, code: int, obj: dict) -> None:
            data = json.dumps(obj, ensure_ascii=False).encode("utf-8")
            self.send_response(code)
            self.send_header("Content-Type", "application/json; charset=utf-8")
            self.send_header("Content-Length", str(len(data)))
            self.end_headers()
            self.wfile.write(data)

        def _guard(self) -> bool:
            if self.client_address[0] not in ("127.0.0.1", "::1"):
                self._send(403, {"ok": False, "reason": "not_local"})
                return False
            if self.headers.get("Origin"):
                self._send(403, {"ok": False, "reason": "browser_origin"})
                return False
            return True

        def _json_body(self) -> dict | None:
            if not (self.headers.get("Content-Type") or "").lower().startswith("application/json"):
                self._send(415, {"ok": False, "reason": "need_json"})
                return None
            n = int(self.headers.get("Content-Length") or 0)
            if n > _MAX_BODY:
                self._send(413, {"ok": False, "reason": "too_large"})
                return None
            try:
                body = json.loads(self.rfile.read(n) or b"{}")
            except (ValueError, UnicodeDecodeError):
                body = None
            if not isinstance(body, dict):
                self._send(400, {"ok": False, "reason": "bad_json"})
                return None
            return body

        def do_GET(self):
            if not self._guard():
                return
            if self.path == "/status":
                self._send(200, api.status())
            else:
                self._send(404, {"ok": False, "reason": "not_found"})

        def do_POST(self):
            if not self._guard():
                return
            if self.path not in ("/say", "/sleep-state"):
                self._send(404, {"ok": False, "reason": "not_found"})
                return
            body = self._json_body()
            if body is None:
                return
            if self.path == "/say":
                text = str(body.get("text") or "").strip()
                if not text:
                    self._send(400, {"ok": False, "reason": "empty"})
                    return
                if len(text) > SAY_MAX_CHARS:
                    self._send(400, {"ok": False, "reason": "too_long"})
                    return
                ok, reason = api.say(text)
                self._send(200 if ok else 409, {"ok": ok, "reason": reason})
                return
            state = str(body.get("state") or "")
            if state not in SLEEP_STATES:
                self._send(400, {"ok": False, "reason": "bad_state"})
                return
            api.set_sleep_state(state)
            self._send(200, {"ok": True, "reason": "set"})

    return _ExclusiveServer((host, port), Handler)


def start_control_server(api: ControlAPI, port: int = CONTROL_PORT) -> ThreadingHTTPServer:
    """建好并在后台线程里启动；端口被占时抛 OSError（调用方据此判断是否已有实例在跑）。"""
    server = make_control_server(api, port)
    threading.Thread(target=server.serve_forever, name="control", daemon=True).start()
    return server
```

```python
import threading

class HealthMonitor:
    """后台线程每 interval 秒查一次各依赖，结果变化时回调 on_change(Health)。checks 的键只认 gateway / tts。"""

    def __init__(self, checks: dict[str, Callable[[], bool]], on_change: Callable[[Health], None],
                 interval: float = 10.0) -> None:
        self.checks = checks
        self.on_change = on_change
        self.interval = interval
        self.health = Health()
        self._stop = threading.Event()
        self._thread: threading.Thread | None = None

    def check_once(self) -> Health:
        vals: dict[str, bool] = {}
        for name, fn in self.checks.items():
            try:
                vals[name] = bool(fn())
            except Exception:  # noqa: BLE001  检查本身出错就当不在线
                vals[name] = False
        new = replace(self.health, **vals)
        if new != self.health:
            self.health = new
            try:
                self.on_change(new)
            except Exception:  # noqa: BLE001
                log.exception("health on_change error")
        return new

    def start(self) -> None:
        self._thread = threading.Thread(target=self._loop, name="health", daemon=True)
        self._thread.start()

    def _loop(self) -> None:
        while True:
            self.check_once()
            if self._stop.wait(self.interval):
                return

    def stop(self) -> None:
        self._stop.set()
```

```python
def pick_stream_rate(in_dev, out_dev) -> int:
    """选一个输入输出都接受、且是 16k 整数倍的流采样率。

    优先 16000（Windows 默认的 MME 通道会自行重采样，省掉降采样和 AEC 的高采样率开销）；
    WASAPI 这类只认原生采样率的设备退到 48000 / 32000；都不行就抛错说明设备默认率。
    """
    dev_in = sd.query_devices(in_dev if in_dev is not None else sd.default.device[0])
    dev_out = sd.query_devices(out_dev if out_dev is not None else sd.default.device[1])
    for rate in (16000, 48000, 32000):
        try:
            sd.check_input_settings(device=in_dev, samplerate=rate, channels=1, dtype="float32")
            sd.check_output_settings(device=out_dev, samplerate=rate, channels=1, dtype="float32")
            return rate
        except Exception:  # noqa: BLE001  该采样率不被接受，试下一个
            continue
    raise RuntimeError(
        f"输入 {dev_in['name']}({dev_in['default_samplerate']:.0f}) / 输出 {dev_out['name']}({dev_out['default_samplerate']:.0f}) "
        "都不接受 16k/48k/32k，请用 --in/--out 指定 MME 设备"
    )


def make_aec(sr: int) -> Aec:
    """按设备采样率建 speex AEC：10ms 帧、250ms 滤波长度、开启预处理（降噪）。守护进程与声纹注册共用。"""
    return Aec(sr // 100, sr // 4, sr, True)


def aec_cancel(aec: Aec, mic: np.ndarray, ref: np.ndarray) -> np.ndarray:
    """对一帧 float32 做回声消除，返回同长度 float32（截到帧长，防 pyaec 返回长度不符打乱降采样相位）。"""
    mic_i16 = (np.clip(mic, -1, 1) * 32767).astype(np.int16)
    ref_i16 = (np.clip(ref, -1, 1) * 32767).astype(np.int16)
    out = np.asarray(aec.cancel_echo(mic_i16.tolist(), ref_i16.tolist()), dtype=np.float32) / 32768.0
    return out[: len(mic)]


def apply_mic_gain(x: np.ndarray, gain: float) -> np.ndarray:
    """软件增益 + tanh 软限幅：小信号近似线性放大，接近满幅时平滑压缩，不硬削波。守护进程与声纹注册共用。"""
    if gain == 1.0:
        return x
    return np.tanh(x * gain).astype(np.float32, copy=False)


@dataclass
class Frames:
    mic: np.ndarray
    ref: np.ndarray
    playing: bool  # 本块是否写出了真实语音（不含保活噪声），打断判定据此认"我们在出声"


@dataclass
class VoiceDaemon:
    in_dev: int | None = None
    out_dev: int | None = None
    speaker_gate: bool = True
    spk_threshold: float = SPK_THRESHOLD  # 声纹放行阈值
    gate_mode: str = SPK_GATE_MODE  # enforce / log
    mic_gain: float = MIC_GAIN  # 软件增益
    aec_on: bool = AEC_ENABLED  # 是否走 speex AEC
    tray_on: bool = True  # 托盘图标（--no-tray 关）
    control_port: int = CONTROL_PORT  # 本机控制口
    # 运行态
    state: str = "LISTENING"  # LISTENING / SPEAKING（一轮从开始到播完都算 SPEAKING）
    _lock: threading.Lock = field(default_factory=threading.Lock)
    _stop_evt: threading.Event = field(default_factory=threading.Event)

    def __post_init__(self) -> None:
        self.sr = pick_stream_rate(self.in_dev, self.out_dev)  # 优先 16k，见 pick_stream_rate
        self.frame = self.sr // 100
        self.in_q: queue.Queue[Frames] = queue.Queue(maxsize=500)
        self.play_q: queue.Queue[tuple[int, np.ndarray]] = queue.Queue()  # (代次, PCM)，回调按代次丢弃旧音频
        self.text_q: queue.Queue[str | SayItem] = queue.Queue()  # 识别出的话（str）或 /say 要念的话（SayItem）
        self._gen = 0  # 播放代次：打断后递增，旧代次的音频一律丢弃；只有 stop_speaking 写
        # 以下播放状态只由音频回调写，其他线程只读
        self._play_buf = np.zeros(0, dtype=np.float32)  # 正在播的那一句 PCM
        self._play_pos = 0  # _play_buf 已播到的位置
        self._buf_gen = 0  # _play_buf 所属代次；与 _gen 不符时回调自行清空
        self._played_gen = -1  # 最近真正出过声的代次
        # 保活噪声：预生成 1s 循环使用（回调里不做随机数生成）
        self._noise = (np.random.default_rng(0).standard_normal(self.sr) * 10 ** (COMFORT_NOISE_DBFS / 20)).astype(np.float32)
        self._noise_pos = 0
        self._play_events: deque[tuple[float, float, int]] = deque(maxlen=200)  # (墙钟, 时长秒, 代次)，回调追加、主循环打日志
        self._turn_first = False  # 本轮第一句还没入队（大脑线程读写）：第一句前补静音前导
        self._turn_t0 = 0.0  # 本轮开始的 monotonic 时刻，记首音延迟用
        # 识别取证：原始麦克风帧环形缓冲 (该帧对应的 16k 起始样本号, 原始帧)，只有前端线程读写
        self._raw_ring: deque[tuple[int, np.ndarray]] = deque(maxlen=RAW_RING_SEC * 100)
        self._vad_pos = 0  # 已喂给主 VAD 的 16k 样本数，与 VAD 段的 start 对齐
        self._dropped = 0  # in_q 满丢掉的帧数
        self._underflows = 0  # 输出欠载次数
        self._paused = threading.Event()  # 游戏态：由运行态监控置位，主循环据此停开音频流
        self._muted = threading.Event()  # 托盘静音：不听不说
        self._front_dirty = False  # 静音期间前端丢过帧，恢复时先复位 VAD/ASR（只有前端线程读写）
        self._exit_code: int | None = None  # 托盘要求的退出码
        self.sleep_state = "awake"  # P4 休眠状态位，由控制口 /sleep-state 设置，托盘显示
        self.last_error = ""  # 最近一轮的错误（网关 / TTS），托盘显示；下一轮成功出声后清空
        self.health = Health()  # 网关、TTS 是否在线（HealthMonitor 更新）
        self.runtime = RuntimeMonitor(self._on_runtime)

        self.down = Downsampler(self.sr)
        self.aec = make_aec(self.sr) if self.aec_on else None  # 关掉时前端直接用原始输入
        self.vad = VAD()
        self.gate = SpeakerGate(threshold=self.spk_threshold) if self.speaker_gate else None
        if self.gate and not self.gate.names():
            log.warning("声纹库为空，默认放行所有声音；请先运行 python -m guanjia.enroll 注册")
            self.gate = None
        self.asr = StreamingASR()
        self.asr_final = FinalASR()  # 整段精识别（SenseVoice int8）：段结束后替换流式结果，失败回退流式
        self.brain = Brain(session_key=MAIN_SESSION_KEY)  # 主线会话；流不可提前关（见 brain.py）
        self.tts = TTSClient(timeout=TTS_TIMEOUT_SEC)
        self.runner = TurnRunner(
            open_stream=lambda text: self.brain.stream(tag_voice_text(text)),
            synth=self.tts.synth, enqueue=self._enqueue_pcm, current_gen=lambda: self._gen,
            first_max_chars=FIRST_SENT_MAX_CHARS, max_tts_fails=TTS_MAX_FAILS)
        self._earcon = earcon(self.sr)
        self.barge = BargeDetector(BargeConfig(guard_ms=BARGE_GUARD_MS, tail_ms=BARGE_TAIL_MS, rms_min=BARGE_RMS_MIN,
                                               floor_ratio=BARGE_FLOOR_RATIO, trigger_ms=BARGE_MS))
        self._mon_ms, self._mon_peak = 0, 0.0  # barge-mon 日志计时与区间 RMS 峰值（只有前端线程读写）
        self.monitor = HealthMonitor({"gateway": lambda: tcp_alive("127.0.0.1", GATEWAY_PORT), "tts": self.tts.alive},
                                     on_change=self._on_health, interval=HEALTH_EVERY_SEC)
        self.tray = None  # run() 里按 tray_on 创建
        self.control = None  # run() 里启动
        # 前端线程状态（只有前端线程读写）
        self._asr_stream = self.asr.new_stream()  # 当前这句话的 ASR 流，每段结束换新流
        self._preroll: deque[np.ndarray] = deque(maxlen=PREROLL_MS // 10)  # 最近 0.5s 的 16k 块
        self._was_speech = False  # 上一块 VAD 是否处于人声状态，用于捕捉起判沿

    # ---------- 音频回调 ----------
    def _callback(self, indata, outdata, frames, time_info, status) -> None:
        if status.output_underflow:
            self._underflows += 1
        cur = self._gen
        if self._buf_gen != cur:  # 已换代：正在播的旧句作废
            self._play_buf, self._play_pos, self._buf_gen = np.zeros(0, dtype=np.float32), 0, cur
        out = np.zeros(frames, dtype=np.float32)
        filled = 0
        while filled < frames:
            if self._play_pos >= len(self._play_buf):
                try:
                    g, pcm = self.play_q.get_nowait()
                except queue.Empty:
                    break
                if g == cur:
                    self._play_buf, self._play_pos, self._buf_gen = pcm, 0, g
                    self._play_events.append((time.time(), len(pcm) / self.sr, g))  # 真正开始写入输出流的时刻
                continue
            k = min(frames - filled, len(self._play_buf) - self._play_pos)
            out[filled:filled + k] = self._play_buf[self._play_pos:self._play_pos + k]
            self._play_pos += k
            filled += k
        if filled:
            self._played_gen = cur
        # 叠加保活噪声（循环取预生成缓冲）：输出流从不"纯零"，音响不会因静默进入待机
        n0 = self._noise_pos
        idx = (np.arange(n0, n0 + frames)) % len(self._noise)
        out += self._noise[idx]
        self._noise_pos = (n0 + frames) % len(self._noise)
        outdata[:, 0] = out
        try:
            self.in_q.put_nowait(Frames(mic=indata[:, 0].copy(), ref=out, playing=filled > 0))
        except queue.Full:
            self._dropped += 1

    def _reset_frontend(self) -> None:
        """VAD / ASR 流 / 预滚 / 打断状态全部复位（游戏态恢复、静音恢复时调用）。"""
        self.vad = VAD()
        self._vad_pos = 0
        self._raw_ring.clear()
        self._asr_stream = self.asr.new_stream()
        self._preroll.clear()
        self._was_speech = False
        self.barge.reset()

    def _playing(self) -> bool:
        return self._play_pos < len(self._play_buf) or not self.play_q.empty()

    # ---------- 前端线程 ----------
    def _frontend(self) -> None:
        while not self._stop_evt.is_set():
            try:
                fr = self.in_q.get(timeout=0.2)
            except queue.Empty:
                continue
            if self._paused.is_set():  # 游戏态：丢弃停流前残留的帧
                continue
            if self._muted.is_set():  # 静音：不听
                self._front_dirty = True
                continue
            if self._front_dirty:
                self._reset_frontend()
                self._front_dirty = False
            try:
                self._frontend_step(fr)
            except Exception:  # noqa: BLE001  单帧出错不能让整条听觉链"变聋"
                log.exception("frontend error")

    def _frontend_step(self, fr: Frames) -> None:
        """处理一帧：(AEC) → 16k → 增益 → VAD → 预滚/ASR → 打断判定 → 段结束出文字。"""
        x = aec_cancel(self.aec, fr.mic, fr.ref) if self.aec else fr.mic
        y = apply_mic_gain(self.down.process(x), self.mic_gain)
        self._raw_ring.append((self._vad_pos, fr.mic))
        self.vad.push(y)
        self._vad_pos += len(y)
        speaking_now = self.vad.is_speech()
        if speaking_now:
            if not self._was_speech:  # 起判沿：VAD 要人声满 0.25s 才翻 true，先把预滚补喂进 ASR
                for c in self._preroll:
                    self.asr.feed(self._asr_stream, c, SR16K)
            self.asr.feed(self._asr_stream, y, SR16K)
        self._preroll.append(y)
        rms = float(np.sqrt(np.mean(x * x))) if len(x) else 0.0  # 增益前的原始电平，打断阈值按它标定
        self._barge_step(rms, fr.playing)
        self._was_speech = speaking_now
        for seg in self.vad.pop_segments():
            stream, self._asr_stream = self._asr_stream, self.asr.new_stream()  # 每句一条新流，不带上一句残留
            if seg.duration < MIN_UTT_SEC:
                continue
            self.asr.feed(stream, np.zeros(SR16K * 3 // 10, dtype=np.float32), SR16K)  # 补 0.3s 静音冲刷尾字
            self.asr.finish(stream)
            stream_text = self.asr.text(stream)  # 流式结果，留着与精识别对比
            text = self.asr_final.transcribe(seg.samples, fallback=stream_text)
            self._dump_segment(seg, text)
            if not text:  # 精识别也为空：不过声纹、不算拒绝，直接丢
                log.debug("丢弃空文本段 %.2fs", seg.duration)
                continue
            who, score = self.gate.identify(seg.samples) if self.gate else ("anyone", 1.0)
            if self.gate and who is None:
                if self.gate_mode == "enforce":
                    log.info("拒绝：非注册声音 score=%.2f text=%r (stream: %r)", score, text, stream_text)
                    continue
                who = "未识别(放行)"  # log 模式：只记录不拦截
            log.info("[%s %.2f] %s  (stream: %s)", who, score, text, stream_text)
            self._accept_utterance(text)

    def _accept_utterance(self, text: str) -> None:
        """一句话通过声纹：正在说就停（只停播放）；立刻放提示音；文字排进大脑队列。"""
        if self.state == "SPEAKING":
            self.stop_speaking("新一轮")
        if EARCON_ENABLED:
            self.play_q.put((self._gen, self._earcon))
        self.text_q.put(text)

    def _raw_for(self, seg) -> np.ndarray:
        """从原始环形缓冲取出与 VAD 段对齐的设备采样率原始音频（AEC 前、无增益）。"""
        decim = self.sr // SR16K
        start16 = int(round(seg.start * SR16K))
        end16 = start16 + len(seg.samples)
        parts = [(i, m) for i, m in self._raw_ring if i < end16 and i + len(m) // decim > start16]
        if not parts:
            return np.zeros(0, dtype=np.float32)
        raw = np.concatenate([m for _, m in parts])
        off = max(0, (start16 - parts[0][0]) * decim)
        return raw[off: off + (end16 - start16) * decim]

    def _dump_segment(self, seg, text: str) -> None:
        """落盘一段送识别的音频：_raw.wav（设备采样率原始）+ _proc.wav（增益+16k），只留最近 SEG_KEEP 段。"""
        try:
            SEG_DUMP_DIR.mkdir(parents=True, exist_ok=True)
            label = re.sub(r'[\\/:*?"<>|\s]', "", text)[:10] or "空"
            stem = f"{datetime.now():%Y%m%d-%H%M%S-%f}"[:-3] + f"_{label}"
            for suffix, pcm, sr in (("raw", self._raw_for(seg), self.sr), ("proc", seg.samples, SR16K)):
                with wave.open(str(SEG_DUMP_DIR / f"{stem}_{suffix}.wav"), "wb") as w:
                    w.setnchannels(1)
                    w.setsampwidth(2)
                    w.setframerate(sr)
                    w.writeframes((np.clip(pcm, -1, 1) * 32767).astype(np.int16).tobytes())
            procs = sorted(SEG_DUMP_DIR.glob("*_proc.wav"))
            for old in procs[:-SEG_KEEP]:
                old.unlink(missing_ok=True)
                old.with_name(old.name.replace("_proc.wav", "_raw.wav")).unlink(missing_ok=True)
        except OSError as e:  # 取证失败不影响对话
            log.warning("segment dump failed: %s", e)

    def _barge_step(self, rms: float, ref_active: bool) -> None:
        """打断判定（每 10ms 一帧，前端线程）：交给 BargeDetector；出声期间每秒打一行 barge-mon 供校准。"""
        hit = self.barge.step(rms, ref_active)
        if self.barge.playing:
            self._mon_ms += 10
            self._mon_peak = max(self._mon_peak, rms)
            if self._mon_ms >= BARGE_LOG_EVERY_MS:
                log.debug("barge-mon rms_peak=%.5f energy=%.5f floor=%.5f line=%.5f hot=%dms", self._mon_peak,
                          self.barge.energy, self.barge.floor, self.barge.line, self.barge.hot_ms)
                self._mon_ms, self._mon_peak = 0, 0.0
        else:
            self._mon_ms, self._mon_peak = 0, 0.0
        if hit and self.state == "SPEAKING" and self._played_gen == self._gen:
            log.info("barge-in: energy=%.4f floor=%.4f line=%.4f", self.barge.energy, self.barge.floor, self.barge.line)
            self.stop_speaking("barge-in")

    # ---------- 大脑线程 ----------
    def _brainloop(self) -> None:
        while not self._stop_evt.is_set():
            try:
                item = self.text_q.get(timeout=0.2)
            except queue.Empty:
                continue
            if self._paused.is_set() or self._muted.is_set():  # 游戏态 / 静音：积压的话直接丢掉
                continue
            try:
                self._handle_item(item)
            except Exception:  # noqa: BLE001  一轮出错不能让大脑线程退出
                log.exception("brain loop error")

    def _handle_item(self, item: str | SayItem) -> None:
        """一轮：语音的话进主线会话 / /say 的话直接念；等本轮播完再回到监听（被打断时 stop_speaking 已经切了）。"""
        gen = self._begin_speaking()
        self._turn_first = True
        self._turn_t0 = time.monotonic()
        try:
            if isinstance(item, SayItem):
                res = self.runner.run_say(item.text, gen)
                log.info("say: %s", item.text)
            else:
                res = self.runner.run_reply(item, gen)
                log.info("reply: %s", res.reply)
            if res.unspoken:
                log.warning("unspoken %d (aborted=%s): %s", len(res.unspoken), res.aborted, " / ".join(res.unspoken)[:300])
            if res.error:
                self._set_error(res.error)
            elif res.spoken:
                self._set_error("")
            while gen == self._gen and self._playing() and not self._stop_evt.is_set():
                time.sleep(0.05)
        finally:
            with self._lock:
                if gen == self._gen:
                    self.state = "LISTENING"

    def _enqueue_pcm(self, gen: int, pcm: np.ndarray, sr: int) -> None:
        """TurnRunner 的入队回调：重采样到流采样率；本轮第一句前补静音前导并记首音延迟。"""
        if sr != self.sr:
            x_old = np.linspace(0, 1, len(pcm), endpoint=False)
            x_new = np.linspace(0, 1, int(len(pcm) * self.sr / sr), endpoint=False)
            pcm = np.interp(x_new, x_old, pcm).astype(np.float32)
        if self._turn_first:
            pcm = np.concatenate([np.zeros(self.sr * LEAD_SILENCE_MS // 1000, dtype=np.float32), pcm])
            self._turn_first = False
            log.info("first audio %.2fs after turn start", time.monotonic() - self._turn_t0)
        self.play_q.put((gen, pcm))  # 即使此刻恰好被打断，回调也会按代次丢掉它

    def _begin_speaking(self) -> int:
        with self._lock:
            self.state = "SPEAKING"
            return self._gen

    def stop_speaking(self, reason: str) -> None:
        """打断：换代（回调自行丢弃旧代音频）、断开进行中的 TTS 请求、清播放队列、回到监听。

        不碰网关流：断开连接会让网关取消这一轮（连同它等着的审批）；大脑线程会把流读完，只是不再合成。
        """
        with self._lock:
            self._gen += 1
            self.state = "LISTENING"
            self.tts.abort()
        while True:  # 清播放队列（回调也会按代次丢弃，这里立即清掉省得积压）
            try:
                self.play_q.get_nowait()
            except queue.Empty:
                break
        log.info("stop speaking (%s)", reason)

    # ---------- 控制口 / 托盘 ----------
    def say(self, text: str) -> tuple[bool, str]:
        """控制口 /say：静音或游戏中拒绝，否则排进大脑队列（与语音轮按顺序念，不会叠在一起）。"""
        if self._muted.is_set():
            return False, "muted"
        if self._paused.is_set():
            return False, "gaming"
        self.text_q.put(SayItem(text))
        log.info("say queued: %s", text)
        return True, "queued"

    def status(self) -> dict:
        """控制口 /status：托盘同款状态。"""
        v = self.view()
        return {"view": v.key, "label": v.label, "state": self.state, "muted": self._muted.is_set(),
                "gaming": self._paused.is_set(), "runtime": self.runtime.state, "gateway": self.health.gateway,
                "tts": self.health.tts, "error": self.last_error, "sleep": self.sleep_state, "pending": self.text_q.qsize()}

    def set_sleep_state(self, state: str) -> bool:
        """控制口 /sleep-state：P4 休眠状态位，只做显示。"""
        self.sleep_state = state
        self._refresh_tray()
        return True

    def view(self) -> TrayView:
        return tray_view(muted=self._muted.is_set(), gaming=self._paused.is_set(), busy=self.state == "SPEAKING",
                         health=self.health, last_error=self.last_error, sleep_state=self.sleep_state)

    def toggle_mute(self) -> None:
        """托盘左键：静音（不听不说，立即停播）/ 取消静音。"""
        if self._muted.is_set():
            self._muted.clear()
            log.info("unmuted")
        else:
            self._muted.set()
            self.stop_speaking("静音")
            log.info("muted")
        self._refresh_tray()

    def request_exit(self, code: int) -> None:
        """托盘菜单：退出语音（0，看门狗不再拉起）/ 重启语音（3，看门狗立即拉起）。"""
        log.info("exit requested from tray: code=%d", code)
        self._exit_code = code
        self._stop_evt.set()

    def _set_error(self, msg: str) -> None:
        msg = msg[:120]
        if msg != self.last_error:
            self.last_error = msg
            if msg:
                log.warning("error: %s", msg)
            self._refresh_tray()

    def _on_health(self, h: Health) -> None:
        self.health = h
        log.info("health: gateway=%s tts=%s", h.gateway, h.tts)
        self._refresh_tray()

    def _refresh_tray(self) -> None:
        if self.tray:
            self.tray.refresh()

    # ---------- 运行态 ----------
    def _on_runtime(self, old: str, new: str) -> None:
        """监控线程回调：只置位/清标志并打断当前播放，真正停开音频流留给主循环做（流操作集中在一个线程）。"""
        if old == ACTIVE:
            log.info("runtime: 离开 ACTIVE → %s，主动侧静默", new)
        if new == GAMING:
            self._paused.set()
            self.stop_speaking("gaming")
        elif old == GAMING:
            self._paused.clear()

    def quiet(self) -> bool:
        """主动侧查询：游戏中或开机/游戏后 5 分钟静默期内返回 True，不许主动开口。"""
        return self.runtime.is_quiet()

    @property
    def quiet_until(self) -> float:
        """静默期截止时间戳（epoch 秒）；游戏中另由 quiet() 判定。"""
        return self.runtime.quiet_until

    def set_gaming(self, on: bool) -> None:
        """手动开关："我打游戏了" / "不打了"。"""
        self.runtime.set_manual_gaming(on)

    def _suspend_audio(self, s: sd.Stream) -> None:
        """进入游戏态：停流、清空积压、释放 ASR（CPU 内存）、通知 TTS 服务释放显存。主循环调用。"""
        s.stop()
        for q in (self.in_q, self.text_q):
            while not q.empty():
                q.get_nowait()
        self.asr = None
        self.asr_final = None
        threading.Thread(target=self.tts.control, args=("unload",), name="tts-unload", daemon=True).start()
        log.info("gaming: 音频流已停，ASR（流式+精识别）已释放")

    def _resume_audio(self, s: sd.Stream) -> None:
        """离开游戏态：重建 ASR/VAD 与前端状态，重开音频流，后台让 TTS 预加载。主循环调用。"""
        self.asr = StreamingASR()
        self.asr_final = FinalASR()
        self._reset_frontend()
        s.start()
        threading.Thread(target=self.tts.control, args=("load",), name="tts-load", daemon=True).start()
        log.info("gaming 结束: 音频流已恢复")

    # ---------- 主循环 ----------
    def run(self) -> None:
        log.info("device rate %d, in=%s out=%s, speakers=%s(%s), gate=%s@%.2f, mic_gain=%.1f, aec=%s, barge=%dms guard=%dms "
                 "rms_min=%.4f ratio=%.1f, tts_timeout=%.0fs, session=%s, control=127.0.0.1:%d", self.sr, self.in_dev,
                 self.out_dev, self.gate.names() if self.gate else "off", self.gate.model.stem if self.gate else "-",
                 self.gate_mode, self.spk_threshold, self.mic_gain, "on" if self.aec else "off", BARGE_MS, BARGE_GUARD_MS,
                 BARGE_RMS_MIN, BARGE_FLOOR_RATIO, TTS_TIMEOUT_SEC, MAIN_SESSION_KEY, self.control_port)
        try:
            self.control = start_control_server(self, self.control_port)
        except OSError as e:
            log.error("控制口 127.0.0.1:%d 绑不上（是不是已经有一个语音进程在跑？）：%s", self.control_port, e)
            sys.exit(EXIT_CRASH)
        threads = [threading.Thread(target=self._frontend, name="frontend", daemon=True),
                   threading.Thread(target=self._brainloop, name="brain", daemon=True)]
        for t in threads:
            t.start()
        self.monitor.start()
        if self.tray_on:
            from guanjia.tray import Tray  # 延迟导入：--no-tray 时不需要 pystray/Pillow

            self.tray = Tray(view=self.view, muted=self._muted.is_set, on_toggle_mute=self.toggle_mute,
                             on_restart=lambda: self.request_exit(EXIT_RESTART),
                             on_exit=lambda: self.request_exit(EXIT_QUIT))
            self.tray.start()
        failed = False
        shown = ""
        last_stats, stats = time.monotonic(), (0, 0)
        with sd.Stream(samplerate=self.sr, blocksize=self.frame, dtype="float32", channels=1, latency="low",
                       device=(self.in_dev, self.out_dev), callback=self._callback) as s:
            log.info("listening ... (latency in/out %.3f/%.3f s; output stream always-open, comfort noise %.0f dBFS, "
                     "lead %dms, earcon %s, dump %s)", *s.latency, COMFORT_NOISE_DBFS, LEAD_SILENCE_MS,
                     "on" if EARCON_ENABLED else "off", SEG_DUMP_DIR)
            self.runtime.start()  # 开机补写离线区间 + 5 分钟静默；之后每 2s 检测游戏态
            try:
                while not self._stop_evt.is_set():
                    time.sleep(0.5)
                    paused = self._paused.is_set()  # 本轮只读一次，防监控线程中途翻转导致误判"流死了"
                    if paused and s.active:
                        self._suspend_audio(s)
                    elif not paused and not s.active:
                        self._resume_audio(s)
                    dead = [t.name for t in threads if not t.is_alive()]
                    if dead or (not s.active and not paused):
                        log.error("worker died: threads=%s stream_active=%s，退出等待看门狗拉起", dead, s.active)
                        failed = True
                        break
                    key = self.view().key
                    if key != shown:  # 说话中 ↔ 在听 等状态变化同步到托盘
                        shown = key
                        self._refresh_tray()
                    while self._play_events:  # 回调记下的"真正写入输出流"的时刻与时长
                        t0, dur, g = self._play_events.popleft()
                        log.info("play: start=%s dur=%.2fs gen=%d", datetime.fromtimestamp(t0).strftime("%H:%M:%S.%f")[:-3],
                                 dur, g)
                    if time.monotonic() - last_stats >= STATS_EVERY_SEC:
                        last_stats = time.monotonic()
                        if (self._dropped, self._underflows) != stats:
                            stats = (self._dropped, self._underflows)
                            log.warning("累计丢帧 %d，输出欠载 %d", *stats)
            except KeyboardInterrupt:
                self._exit_code = EXIT_QUIT
        self._stop_evt.set()
        self.runtime.stop()  # 最后一次心跳，下次开机据此算离线区间
        self.monitor.stop()
        if self.tray:
            self.tray.stop()
        self.control.shutdown()
        code = EXIT_CRASH if failed else (EXIT_QUIT if self._exit_code is None else self._exit_code)
        log.info("voice daemon exit code=%d", code)
        sys.exit(code)
```

```ts
/**
 * 「说出来」工具：让家里电脑用管家音色（SCV）念一句话。
 *
 *   模型 ──speak{text}──> 本插件 ──POST 127.0.0.1:18795/say──> 语音守护进程的播放队列（打断照样生效）
 *
 * 不经过 shell；守护进程没跑、静音、游戏中都返回明确的「没有念：原因」。分级 L1（levels.json）。
 * 工具搜索模式下它是延期工具：模型用 tool_call（id: speak，args: {text}）调用，AGENTS.md 里写明了。
 */

export const DEFAULT_SPEAK_URL = "http://127.0.0.1:18795/say";
export const SPEAK_MAX_CHARS = 300;
export const SPEAK_TIMEOUT_MS = 3_000;
/** 语音轮标记「[语音 2026-10-10 18:05 周六]」；前面允许再有一个网关加的 [时间] 信封 */
export const VOICE_TAG_RE = /^\s*(?:\[[^\]]*\]\s*)?\[语音[^\]]*\]\s*/;

/** 去掉语音轮标记，口头确认 / 习惯判断按主人说的原话做 */
export function stripVoiceTag(text: string): string {
  return text.replace(VOICE_TAG_RE, "");
}

type FetchLike = (
  url: string,
  init: { method: string; headers: Record<string, string>; body: string; signal: AbortSignal },
) => Promise<{ status: number; text(): Promise<string> }>;

export interface SpeakToolOptions {
  url?: string;
  fetchImpl?: FetchLike;
  timeoutMs?: number;
}

const REASON_CN: Record<string, string> = {
  muted: "电脑现在是静音状态（托盘里点过静音）",
  gaming: "主人在打游戏，电脑暂时不出声",
  empty: "要念的内容是空的",
  too_long: `一次最多念 ${SPEAK_MAX_CHARS} 字`,
};

function textResult(text: string, details: Record<string, unknown>) {
  return { content: [{ type: "text", text }], details };
}

export function createSpeakTool(opts: SpeakToolOptions = {}) {
  const url = opts.url ?? DEFAULT_SPEAK_URL;
  const doFetch = opts.fetchImpl ?? (globalThis.fetch as unknown as FetchLike);
  const timeoutMs = opts.timeoutMs ?? SPEAK_TIMEOUT_MS;
  return {
    name: "speak",
    label: "Speak aloud",
    description:
      "Speak a short sentence aloud on the home PC speakers in the butler's own voice (SCV). " +
      "Use when the owner asks to read or say something out loud on the computer (念一句 / 读出来 / 在电脑上说). " +
      "Input: text, up to 300 characters. Fails with a clear reason if the voice daemon is not running, muted, or the owner is gaming.",
    parameters: {
      type: "object",
      properties: { text: { type: "string", description: "要念出来的话（口语，最多 300 字）" } },
      required: ["text"],
      additionalProperties: false,
    },
    async execute(_toolCallId: string, params: { text?: unknown }) {
      const text = typeof params?.text === "string" ? params.text.trim() : "";
      if (!text) return textResult(`没有念：${REASON_CN.empty}。`, { ok: false, reason: "empty" });
      if (text.length > SPEAK_MAX_CHARS) return textResult(`没有念：${REASON_CN.too_long}，请缩短。`, { ok: false, reason: "too_long" });
      let res: { status: number; text(): Promise<string> };
      try {
        res = await doFetch(url, {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ text }),
          signal: AbortSignal.timeout(timeoutMs),
        });
      } catch (err) {
        return textResult(
          `没有念：电脑上的语音守护进程没有在运行（${url} 连不上）。请主人看一眼托盘，或重启电脑后再试。`,
          { ok: false, reason: "daemon_down", error: String(err) },
        );
      }
      let body: any = {};
      try {
        body = JSON.parse(await res.text());
      } catch {
        // 非 JSON 按状态码处理
      }
      if (res.status === 200 && body?.ok) return textResult(`已让电脑念出来：「${text}」`, { ok: true, reason: "queued" });
      const reason = String(body?.reason ?? `http_${res.status}`);
      return textResult(`没有念：${REASON_CN[reason] ?? `语音守护进程拒绝了（${reason}）`}。`, { ok: false, reason });
    },
  };
}
```

```ts
 *   2. 网关服务            → 上云脱敏代理（redact.ts）

 *   4. speak 工具          → 让家里电脑用管家音色念一句（speak.ts，调本机语音守护进程，分级 L1）
 * 所有状态落在 workspace/guanjia/，审计写 workspace/guanjia/audit.jsonl。

const pluginDir = path.dirname(fileURLToPath(import.meta.url));
const defaultsDir = path.join(pluginDir, "defaults");

export default definePluginEntry({
  id: "guanjia-guard",
  name: "Guanjia Guard",
  description: "L0-L3 tool gating, cloud redaction proxy, habit confirmation flow.",
  register(api: any) {
    const cfg = (api.pluginConfig ?? {}) as {
      workspaceDir?: string;
      proxy?: { enabled?: boolean; port?: number; upstreamOrigin?: string };
      habitTz?: string;
      speakUrl?: string;
    };
    const workspaceDir = cfg.workspaceDir ?? path.join(os.homedir(), ".openclaw", "workspace");
    const store = createStore(workspaceDir, defaultsDir);
    const defaults = JSON.parse(fs.readFileSync(path.join(defaultsDir, "levels.json"), "utf8")) as LevelsFile;
    const guard = createGuard(store, defaults);

    /** 网关服务启动时拿到的调度器 getter；用户确认习惯草案时用它建 cron */

    // 1) 工具调用分级
    api.on("before_tool_call", (event: any, ctx: any) => guard.beforeToolCall(event, ctx), { priority: 100 });

    // 3) 用户开口：登记触发来源 → L2 确认优先 → 否则看要不要问习惯草案
    const handledMessages = new Set<string>();
    api.on("before_prompt_build", async (event: any, ctx: any) => {
      guard.noteRun(ctx?.runId, ctx?.trigger);
      if (ctx?.trigger && ctx.trigger !== "user") return;
      if (guard.isProactive(ctx?.runId, ctx?.sessionKey)) return;
      // 同一条用户消息可能因重试多次构建 prompt，只处理一次
      const msgId = event.currentUserMessageId ?? `${ctx?.runId}`;
      if (handledMessages.has(msgId)) return;
      handledMessages.add(msgId);
      if (handledMessages.size > 500) handledMessages.delete(handledMessages.values().next().value!);

      const userText: string = stripVoiceTag(event.currentUserMessage ?? event.prompt ?? "");
      if (!userText.trim()) return;
      const confirmNote = guard.onUserTurn(ctx?.sessionKey, userText);
      if (confirmNote) return { appendContext: confirmNote };
      const cron = getCron?.();
      const habitNote = await habitOnUserTurn(store, userText, cron ? (input) => cron.add(input) : undefined, cfg.habitTz ?? "Asia/Shanghai");
      if (habitNote) return { appendContext: habitNote };
    });

    // 4) 让电脑念出来（清单 contracts.tools 里已声明 speak）
    api.registerTool(createSpeakTool({ url: cfg.speakUrl }));

    // 2) 脱敏代理随网关起停
    let stopProxy: (() => Promise<void>) | undefined;
    api.registerService({
      id: "guanjia-guard-service",
      start(ctx: any) {
        getCron = ctx.getCron;
        const p = cfg.proxy ?? {};
        if (p.enabled === false) return;
        stopProxy = startRedactProxy({
          port: p.port ?? 18797,
          upstreamOrigin: p.upstreamOrigin ?? "https://api.siliconflow.cn",
          store,
          logger: api.logger,
        });
      },
      async stop() {
        getCron = undefined;
        await stopProxy?.();
        stopProxy = undefined;
      },
    });
  },
});
```

```powershell
#   拉起 python -m guanjia.voice，按退出码决定：
#     0    = 托盘「退出语音」→ 看门狗也退出，不再拉起
#     3    = 托盘「重启语音」→ 立即重启
#     其它 = 崩溃 → 退避 5s、10s、20s…最多 60s 后重启（稳定跑满 5 分钟后退避复位）
#   进程树：本进程绑进 KILL_ON_JOB_CLOSE 的 Job Object，子孙进程自动继承；本进程一退出，python 跟着结束（不按进程名杀）
#   计划任务被结束（schtasks /End 只杀 wscript）：每 2 秒看一眼父进程，父进程没了就退出
#   单实例：命名互斥量，第二个看门狗直接退出
param(
    [string]$Repo = 'F:\coding\guanjia',
    [string]$Exe = 'F:\coding\guanjia\.venv\Scripts\python.exe',
    [string]$ArgLine = '-m guanjia.voice -v --log-file F:/coding/guanjia/tmp/voice.log',

    [int]$BackoffMaxSec = 60,

New-Item -ItemType Directory -Force -Path $LogDir | Out-Null

function Write-Log([string]$Message) {
    $line = '{0:yyyy-MM-dd HH:mm:ss} [{1}] {2}' -f (Get-Date), $PID, $Message
    Add-Content -Path $LogPath -Value $line -Encoding UTF8
}

$mutex = New-Object System.Threading.Mutex($true, $MutexName, [ref]$created)
if (-not $created) {
    Write-Log 'another supervisor is running, exit'
    exit 0
}

Add-Type -TypeDefinition @"
using System;
using System.Runtime.InteropServices;
public static class GjJob {
    [DllImport("kernel32.dll", CharSet = CharSet.Unicode)] static extern IntPtr CreateJobObject(IntPtr a, string n);
    [DllImport("kernel32.dll")] static extern bool SetInformationJobObject(IntPtr h, int c, IntPtr i, uint l);
    [DllImport("kernel32.dll")] static extern bool AssignProcessToJobObject(IntPtr j, IntPtr p);
    [DllImport("kernel32.dll")] static extern IntPtr GetCurrentProcess();
    public static IntPtr Handle;
    public static bool Bind() {
        Handle = CreateJobObject(IntPtr.Zero, null);
        IntPtr buf = Marshal.AllocHGlobal(144);
        for (int i = 0; i < 144; i++) Marshal.WriteByte(buf, i, 0);
        Marshal.WriteInt32(buf, 16, 0x2000);
        bool ok = SetInformationJobObject(Handle, 9, buf, 144);
        Marshal.FreeHGlobal(buf);
        return ok && AssignProcessToJobObject(Handle, GetCurrentProcess());
    }
}
"@

$env:GUANJIA_VOICE_MODEL = ''

    $p = Get-Process -Id $ParentPid -ErrorAction SilentlyContinue
    return [bool]($p -and $p.StartTime -eq $ParentStart)  # 比对启动时间，防 PID 被复用
}

function Test-Port([int]$Port) {
    $c = New-Object System.Net.Sockets.TcpClient
    try { return ($c.ConnectAsync('127.0.0.1', $Port).Wait(1000) -and $c.Connected) } catch { return $false } finally { $c.Close() }
}

function Test-Http([string]$Url) {
    try {
        $req = [System.Net.HttpWebRequest]::Create($Url)
        $req.Proxy = $null  # 不走系统代理（Clash）
        $req.Timeout = 2000
        $resp = $req.GetResponse()
        $ok = [int]$resp.StatusCode -eq 200
        $resp.Close()
        return $ok
    } catch { return $false }
}

function Wait-Deps {
    if ($SkipDeps) { return }
    $t0 = Get-Date
    while ($true) {
        $gw = Test-Port 18789
        $tts = Test-Http 'http://127.0.0.1:18791/health'
        if ($gw -and $tts) { Write-Log 'deps ready (gateway, tts)'; return }
        $waited = [int]((Get-Date) - $t0).TotalSeconds
        if ($waited -ge $DepsTimeoutSec) { Write-Log ('deps not ready after {0}s (gateway={1} tts={2}), starting anyway' -f $waited, $gw, $tts); return }
        if (-not (Test-ParentAlive)) { Write-Log 'parent gone while waiting deps, exit'; exit 0 }
        Start-Sleep -Seconds 3
    }
}

$backoff = $BackoffStartSec
while ($true) {
    Wait-Deps
    $t0 = Get-Date
    $p = Start-Process -FilePath $Exe -ArgumentList $ArgLine -WorkingDirectory $Repo -NoNewWindow -PassThru -RedirectStandardError (Join-Path $LogDir 'voice-stderr.txt')
    $null = $p.Handle  # 先取句柄：PowerShell 5.1 不取句柄的话进程退出后 ExitCode 读出来是空
    Write-Log "voice started pid=$($p.Id)"
    while (-not $p.WaitForExit(2000)) {
        if (-not (Test-ParentAlive)) { Write-Log 'parent gone (task ended), exit; job closes and takes python with it'; exit 0 }
    }
    $code = $p.ExitCode
    $ran = [int]((Get-Date) - $t0).TotalSeconds
    Write-Log "voice exited code=$code after ${ran}s"
    if ($code -eq 0) { Write-Log 'quit requested (tray), supervisor exit'; break }
    if ($code -eq 3) { Write-Log 'restart requested (tray)'; $backoff = $BackoffStartSec; continue }
    if ($ran -ge 300) { $backoff = $BackoffStartSec }
    Write-Log "restart in ${backoff}s"
    Start-Sleep -Seconds $backoff
    $backoff = [Math]::Min($backoff * 2, $BackoffMaxSec)
}
$mutex.ReleaseMutex()
```
