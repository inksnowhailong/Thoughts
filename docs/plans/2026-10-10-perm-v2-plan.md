# 管家「确认策略 v2：大多数事直接做，少数先口头问一句」Implementation Plan

> **For agentic workers:** To implement this plan, use `executing-plans` (inline) or `subagent-driven-development` (parallel, explicit user request only). Follow project Git rules — do not create branches or worktrees unless the user asks. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 分级插件 `guanjia-guard` 改成「默认直接做，只有删除、破坏系统、关机重启、结束进程、下载后运行、读密钥、改管家自己规则这几类先在对话里口头问一句」；主人说「允许 / 可以 / 行」就做这一次，说「以后都允许」就把这件事记进线上 `levels.json` 的 overrides 以后不再问（读密钥、改管家规则两类不许记）；不再让主人去微信点 `/approve`；定时任务、心跳里遇到先问的事不做、写审计；新增 `launch_app`、`get_location`、`get_weather` 三个专用工具；给面板定好「已记住的放行」读写契约并附 Python 参考实现；最后给出一段可并入 P2.1 上线序列的上线小节。

**Architecture:** 分级表 `defaults/levels.json` 重写成「`defaultLevel: L1` + 少数 L2 规则」，每条 L2 规则带类别 `category` 和 `remember`（能否记住）；规则引擎 `levels.ts` 增加 `also`（多条件）、`$path`、`$text` 三个匹配能力。`guard.ts` 的 L2 口头确认沿用 P2 的机制，新增「以后都允许」→ `remember.ts` 生成只匹配这一件事的放行规则（结束进程按程序名）并原子写入线上表；L3 不再带外审批，只留给「tool_call 的真实目标无法确定」时直接拒绝。`ps-tools.ts` 用 `child_process.execFile` 固定调用工作区里的启动器和定位脚本（不经 shell）。面板侧只通过线上 `levels.json` 交接，参考实现 `src/guanjia/remembered_overrides.py`。

**Tech Stack:** OpenClaw 2026.9.6（Node v24.21.0，插件 TypeScript 由网关直接加载），测试沿用 `node:assert/strict` + `npx --yes tsx`；Python 3.12 venv（最小断言脚本，不用 pytest）；Windows PowerShell 5.1。

### 脚本类操作的归类（建议与理由）

- **运行一个已存在的脚本文件**（`python foo.py`、`powershell -File x.ps1`、`.\x.bat`）：**直接做**。主人这次要放开的就是普通命令，启动器被问正是这一类；脚本是主人放的，或者是管家写的（写的时候已经扫过正文，见下一条）。命令行本身带删除、关机等字样时照样问（例如 `x.ps1; del y`）。
- **写一个脚本文件**（`.ps1 .bat .cmd .vbs .js .py .sh .reg …`）：**直接做，但扫正文**——正文里出现先问清单里的操作（删除、关机、结束进程、下载后运行……）就先问（类别 `script`）。写到管家自己的目录（`workspace\tools\` 等）一律先问、不可记住。
- **诚实的边界：** 规则只看工具参数里的文字，挡得住模型的正常写法，挡不住刻意换写法。已知盲区：运行已有脚本时看不到脚本内容；分两步「先下载到 `.txt`、改名、下一轮再运行」；用变量拼出命令名（`$c='Remove-'+'Item'; & $c x`）；Python/Node 里绕一层调用（`subprocess.run(['cmd','/c','rd',…])` 这种拆开的写法）；往后台命令行里分段输入。OpenClaw 自己的 exec 审批是全放（`security=full ask=off`），所以这套规则是「防模型听错、手滑」的护栏，不是防恶意的安全边界。

### 「允许」与「以后都允许」

- 同意词：在 v1 的 `确认/确定/执行/同意/好的/好/可以/行/是的/对/ok/yes` 上加 `允许`、`放行`。否定、叫停、反问（`不/别/算了/取消/等等/停/吗/？`）仍然不算。
- 记住词：`以后都允许 / 一直允许 / 永远允许 / 以后不用问了 / 以后别问了 / 以后都可以 / 以后就直接做吧`，前面可以带一个同意词（「可以，以后都可以」）；出现 `不允许/不行/算了/吗/？` 或「别+其它动词」（「以后都允许，别删」）就不算。记住词本身也算同意。
- 记住时生成的放行规则：只记 `exec`（其它工具的先问事项说了「以后都允许」也只放行这一次，并告诉主人）。规则只匹配这条命令本身（首尾和词间空白多少、斜杠方向、大小写不算差别；后面多串一条命令就不算同一件事）；结束进程按程序名记，`taskkill /im X`、`Stop-Process -Name X`、`Get-Process X | Stop-Process` 三种写法都认，但整条命令只能做这一件事。字段：`id`（`rem-` + 12 位十六进制）、`source: "remembered"`、`createdAt`、`expiresAt: "9999-12-31T00:00:00.000Z"`、`scope: "global"`、`tool/param/pattern`、`level: "L1"`、`summary`、`reason`。
- 确认按会话隔离（待确认动作按 `sessionKey` 存，3 分钟过期）；记住的放行是全局的，定时任务里也生效。

### 已核实：语音轮里插件能拿到并认出确认语（证据在被控机，路径相对 `node_modules\openclaw\dist\`）

### L3（带外审批）以后用在哪

v2 起插件不再发 `requireApproval`。L3 只剩「拒绝」一个用途：tool_call 的真实目标无法确定（client 来源、选择器互相矛盾、不在分级表里的裸名字），直接拦下并告诉模型用完整 id 调用。分级表里如果有人手写了 L3，按「口头先问、不可记住」处理。**以后**唯一值得恢复带外审批的场景是：定时任务、心跳里遇到先问的事——那时没人在对话里，P3 接入微信后可以改成把这件事推到主人微信让他批（现在先拦下、写审计 `block-no-confirmer`）。`openclaw.json` 的 `approvals.plugin` 配置保留不动，留给那时用。

### 上线顺序为什么是「先停网关再同步分级表」

旧插件不认识新表的 `$path`、`also`：如果在旧插件还在跑时就换上新表，`read` 的敏感路径规则（`param: "$path"`）在旧代码里永远不命中，读 `openclaw.json` 会被当成普通 `read`（L0）直接放行。所以分级表、AGENTS 块、技能都在**网关停下之后**同步，再授权、再启动。回滚同理：代码和分级表必须一起退回。

 * 行为分级判定（D6 / D8，确认策略 v2）。纯函数，不做 IO，方便单独测试。
 *
 *   overrides(未过期) → rules(首个命中) → tools(按名) → defaultLevel
 *                                   │
 *                        主动发起(cron/心跳) 再降一档；v2 的分级表写了 proactiveDowngrade: false，不降
 *
 * L0/L1 直接做；L2 先口头问一句；L3 拒绝（只给无法确定真实目标的 tool_call）。
 * 结构化工具搜索的外层 tool_call{id,args} 先用 resolveToolCallTarget 还原成真实工具，再交给 classify。

export type Level = "L0" | "L1" | "L2" | "L3";

/** 先问的类别：决定提问措辞，以及能不能「以后都允许」 */
export type AskCategory = "delete" | "system" | "power" | "kill" | "download-run" | "opaque" | "script" | "secret" | "self-config";

/**
 * 一个匹配条件。param 的特殊取值：
 *   $path            path 或 file_path，任一命中即可
 *   $text            参数里全部字符串值（含嵌套）用换行拼起来
 *   $derivedPaths    宿主推导出的所有路径都命中
 *   $anyDerivedPaths 宿主推导出的路径任一命中
 *   不写             匹配整个参数的 JSON
 */
export interface Condition {
  param?: string;
  pattern?: string;
}

export interface LevelRule extends Condition {
  tool: string;
  /** 额外条件，必须全部命中 */
  also?: Condition[];
  level: Level;
  category?: AskCategory;
  /** false 表示这类每次都问，不能「以后都允许」 */
  remember?: boolean;
  note?: string;
}

  expiresAt: string;
  reason?: string;
  id?: string;

  source?: string;
  summary?: string;

const ORDER: Level[] = ["L0", "L1", "L2", "L3"];

/** 与 OpenClaw tool-policy-shared 的 TOOL_NAME_ALIASES 保持一致 */
const TOOL_NAME_ALIASES: Record<string, string> = { bash: "exec", "apply-patch": "apply_patch", cron: "automations" };
/** OpenClaw 读取 tool_call 目标的参数名，按优先级 */
const SELECTOR_KEYS = ["id", "toolId", "name"] as const;
/** 目录 id 形如 openclaw:core:exec、mcp:<server>:<tool>、client:client:<tool> */
const CATALOG_ID_RE = /^(openclaw|mcp|client):[^:]*:(.+)$/i;

const isRecord = (v: unknown): v is Record<string, unknown> => !!v && typeof v === "object" && !Array.isArray(v);

/** 主动发起降一档：L0/L1 → +1，L2 → L3，L3 不变 */
export function downgrade(level: Level): Level {
  return ORDER[Math.min(ORDER.indexOf(level) + 1, 3)];
}

/** 参数里全部字符串值（含嵌套），用于扫描脚本正文、补丁内容 */
function allStrings(v: unknown, out: string[] = []): string[] {
  if (typeof v === "string") out.push(v);
  else if (Array.isArray(v)) v.forEach((x) => allStrings(x, out));
  else if (isRecord(v)) Object.values(v).forEach((x) => allStrings(x, out));
  return out;
}

/** 判断一个条件是否命中本次调用 */
function conditionMatches(cond: Condition, params: Record<string, unknown>, derivedPaths?: readonly string[]): boolean {
  if (!cond.pattern) return true;
  const re = new RegExp(cond.pattern, "i");
  const test = (v: unknown) => typeof v === "string" && re.test(v);
  switch (cond.param) {
    case "$derivedPaths":
      return !!derivedPaths && derivedPaths.length > 0 && derivedPaths.every((p) => re.test(p));
    case "$anyDerivedPaths":
      return !!derivedPaths && derivedPaths.some((p) => re.test(p));
    case "$path":
      return test(params.path) || test(params.file_path);
    case "$text":
      return re.test(allStrings(params).join("\n"));
    case undefined:
      return re.test(JSON.stringify(params));
    default:
      return test(params[cond.param]);
  }
}

/** 判断一条规则是否命中本次工具调用 */
function ruleMatches(rule: LevelRule, toolName: string, params: Record<string, unknown>, derivedPaths?: readonly string[]): boolean {
  if (rule.tool !== toolName) return false;
  return conditionMatches(rule, params, derivedPaths) && (rule.also ?? []).every((c) => conditionMatches(c, params, derivedPaths));
}

/**
 * 把外层 tool_call 的参数还原成真实工具名与参数（对齐 OpenClaw readToolSearchCallArgs）。

  const key = SELECTOR_KEYS.find((k) => typeof params[k] === "string" && (params[k] as string).trim() !== "");
  if (!key) return undefined;
  // 没有嵌套 args 时 OpenClaw 会挑"在目录里查得到"的那个选择器，插件看不到目录，选择器互相矛盾就无法确定真实目标
  const selectors = new Set(SELECTOR_KEYS.map((k) => params[k]).filter((v): v is string => typeof v === "string" && v.trim() !== "").map((v) => v.trim()));
  if (selectors.size > 1) return { toolName: "tool_call", source: "ambiguous", params };
  const selector = (params[key] as string).trim();
  const m = CATALOG_ID_RE.exec(selector);
  const rawName = (m ? m[2] : selector).trim().toLowerCase();
  const isDotted = (k: string) => k.startsWith("args.") && k.length > 5;
  const dotted = Object.fromEntries(Object.entries(params).filter(([k]) => isDotted(k)).map(([k, v]) => [k.slice(5), v]));
  const nested = params.args ?? params.input;
  let input: Record<string, unknown>;
  if (isRecord(nested) && Object.keys(nested).length > 0) input = { ...dotted, ...nested };
  // 非对象参数不猜，按无参数定级
  else if (nested != null && !isRecord(nested)) input = {};
  else input = { ...dotted, ...Object.fromEntries(Object.entries(params).filter(([k]) => k !== "args" && k !== "input" && k !== key && !isDotted(k))) };
  const canonical = TOOL_NAME_ALIASES[rawName] ?? rawName;
  // findEntry 按名字精确匹配、不转小写也不认别名：裸名字和规范名不一致时，插件无法确定 OpenClaw 会匹配到哪个工具
  const source = m ? m[1].toLowerCase() : selector === canonical ? undefined : "ambiguous";
  return { toolName: canonical, source, params: input };
}

/**
 * 给一次工具调用定级。
 * @param levels 分级表（workspace/guanjia/levels.json）
 * @param call 工具名、参数、宿主推导路径、会话 key
 * @param proactive 是否为 cron/心跳等主动发起的会话
 * @param now 当前时间（便于测试注入）
 */
export function classify(
  levels: LevelsFile,
  call: { toolName: string; params: Record<string, unknown>; derivedPaths?: readonly string[]; sessionKey?: string },
  proactive: boolean,
  now = new Date(),
): Classification {
  let result: Omit<Classification, "downgraded"> | undefined;

  // 1) D8 放行/提权：没有有效期或已过期的一律忽略
  for (const o of levels.overrides ?? []) {
    const exp = Date.parse(o.expiresAt);
    if (!Number.isFinite(exp) || exp <= now.getTime()) continue;
    const inScope = !o.scope || o.scope === "global" || o.scope === `session:${call.sessionKey}`;
    if (inScope && ruleMatches(o, call.toolName, call.params, call.derivedPaths)) {
      result = { level: o.level, source: "override", note: o.reason ?? o.note, rememberable: false, overrideId: o.id };
      break;
    }
  }

  // 2) 参数规则 3) 工具名 4) 默认
  if (!result) {
    const rule = levels.rules.find((r) => ruleMatches(r, call.toolName, call.params, call.derivedPaths));
    if (rule) result = { level: rule.level, source: "rule", note: rule.note, category: rule.category, rememberable: rule.remember !== false };
    else if (levels.tools[call.toolName]) result = { level: levels.tools[call.toolName], source: "tool", rememberable: true };
    else result = { level: levels.defaultLevel, source: "default", rememberable: true };
  }

  const shouldDowngrade = proactive && levels.proactiveDowngrade !== false;
  return { ...result, level: shouldDowngrade ? downgrade(result.level) : result.level, downgraded: shouldDowngrade };
}

  const keys = Object.keys(levels);
  const lines = keys.map((k, i) => {
    const v = levels[k];
    let body: string;
    if (Array.isArray(v)) body = v.length === 0 ? "[]" : `[\n${v.map((x) => "    " + oneLine(x)).join(",\n")}\n  ]`;
    else if (v && typeof v === "object") {

/** Windows 上别的进程正开着文件时 rename 会 EPERM/EBUSY，短暂重试 */
function renameWithRetry(from: string, to: string) {
  for (let i = 0; ; i++) {
    try {
      fs.renameSync(from, to);
      return;
    } catch (err: any) {
      if (i >= 4 || (err?.code !== "EPERM" && err?.code !== "EBUSY" && err?.code !== "EACCES")) throw err;
      Atomics.wait(new Int32Array(new SharedArrayBuffer(4)), 0, 0, 50);
    }
  }
}

    fs.writeFileSync(tmp, formatLevelsJson(levels), "utf8");

  } catch (err: any) {
    try { fs.unlinkSync(tmp); } catch { /* 临时文件可能没建成 */ }
    return { ok: false, reason: `write_failed: ${String(err?.message ?? err)}` };
  }
  return { ok: true, id: override.id!, existed: false };
}

 * 同一工具 + 同一操作目标 → 同一指纹，确认只对这件事生效。
 * 不用全部参数：模型重试时常有无关差异（多个换行、多带一个可选参数），全量比对会让确认永远对不上。
 * 目标做归一化：小写、斜杠统一、去首尾空白。没有目标参数的工具退回全量参数比对。
 */
const fingerprintOf = (toolName: string, params: Record<string, unknown>) => {
  const key = TARGET_KEYS.find((k) => typeof params[k] === "string");
  const target = key ? `${key}=${String(params[key]).trim().toLowerCase().replace(/\\/g, "/")}` : stableJson(params);
  return crypto.createHash("sha256").update(toolName + "\u0000" + target).digest("hex").slice(0, 16);
};

function stableJson(v: unknown): string {
  if (Array.isArray(v)) return `[${v.map(stableJson).join(",")}]`;
  if (v && typeof v === "object") {
    return `{${Object.keys(v).sort().map((k) => JSON.stringify(k) + ":" + stableJson((v as any)[k])).join(",")}}`;
  }
  return JSON.stringify(v);
}

/** 给人看的一行动作摘要（提问 / 审计用），截断避免把大段参数带出去 */
function summarize(toolName: string, params: Record<string, unknown>): string {
  const main = params.command ?? params.path ?? params.file_path ?? params.url ?? params.action ?? params.to;
  const s = typeof main === "string" ? main : JSON.stringify(params);
  return `${toolName}: ${s.length > 120 ? s.slice(0, 117) + "..." : s}`;
}

/** 与 OpenClaw ToolSearchRuntime 的 sanitizeToolCallIdPart 一致：内层 toolCallId 里嵌的是清洗后的外层 id */
export function sanitizeToolCallIdPart(value: string): string {
  return value.trim().replace(/[^A-Za-z0-9_.:-]+/g, "_").slice(0, 120) || "call";
}

/** 从内层 toolCallId 取外层 id；不是 tool_search_code:<外层id>:<工具名>:<序号> 形状时返回 undefined */
export function parentToolCallIdOf(toolCallId: unknown): string | undefined {
  if (typeof toolCallId !== "string") return undefined;
  return /^tool_search_code:(.*):[^:]+:\d+$/.exec(toolCallId)?.[1];
}

/** 记不住时给模型的解释 */
const REMEMBER_FAIL_CN: Record<string, string> = {
  not_exec: "这类操作没法精确记住",
  no_command: "这条命令是空的，没法记住",
  kill_without_name: "这次是按进程号结束的，没有程序名可记",
};

export function createGuard(store: Store, defaults: LevelsFile) {
  const pending = new Map<string, PendingAction>();
  /** runId → 触发来源（user/cron/heartbeat），由 prompt 阶段钩子登记；工具钩子上下文里没有 trigger */
  const runTriggers = new Map<string, string>();
  /** 清洗后的外层 toolCallId → 放行登记，只保留最近 500 条 */
  const outerGrants = new Map<string, OuterGrant>();

  /** 记录一次运行的触发来源，只保留最近 200 条 */
  function noteRun(runId: string | undefined, trigger: string | undefined) {
    if (!runId || !trigger) return;
    runTriggers.set(runId, trigger);
    if (runTriggers.size > 200) runTriggers.delete(runTriggers.keys().next().value!);
  }

  /** 是否主动发起：cron/心跳触发，或会话 key 落在 cron 命名空间 */
  function isProactive(runId?: string, sessionKey?: string) {
    const t = runId ? runTriggers.get(runId) : undefined;
    return t === "cron" || t === "heartbeat" || /:cron:/.test(sessionKey ?? "");
  }

  /**
   * 用户新开口时调用：同意就把该会话最近一个待确认动作标记为已批准；"以后都允许"再记进 overrides。
   * @param userText 用户原话（可带「[语音 …]」标记，这里剥）
   * @returns 给模型的追加上下文
   */
  function onUserTurn(sessionKey: string | undefined, userText: string): string | undefined {
    if (!sessionKey) return undefined;
    const p = pending.get(sessionKey);
    if (!p || p.expiresAt < Date.now()) return undefined;
    const voice = hasVoiceTag(userText);
    const remember = isRememberRequest(userText);
    if (!remember && !isConfirmation(userText)) {
      pending.delete(sessionKey);
      store.audit({ kind: "tool", decision: "l2-dropped", sessionKey, summary: p.summary, voice });
      return undefined;
    }
    p.approved = true;
    p.expiresAt = Date.now() + PENDING_TTL_MS;
    const retry = "现在用与刚才完全相同的参数再调用一次该工具。";
    if (!remember) {
      store.audit({ kind: "tool", decision: "l2-confirmed", sessionKey, summary: p.summary, voice });
      return `（系统：用户已口头同意刚才待确认的操作「${p.summary}」。${retry}）`;
    }
    if (!p.rememberable) {
      store.audit({ kind: "tool", decision: "l2-remember-refused", sessionKey, summary: p.summary, category: p.category, voice });
      const what = p.category ? CATEGORY_CN[p.category] : "这类操作";
      return `（系统：用户同意了这一次「${p.summary}」，但「${what}」每次都要问，不能记住。${retry}做完后用一句话告诉用户：这类以后还会再问。）`;
    }
    const built = buildRememberedOverride(p.toolName, p.params, p.category, p.summary);
    const saved = built.ok ? appendOverride(store, built.override) : undefined;
    if (!built.ok || !saved?.ok) {
      const reason = !built.ok ? built.reason : (saved as { reason: string }).reason;
      store.audit({ kind: "tool", decision: "l2-remember-failed", sessionKey, summary: p.summary, reason, voice });
      const why = REMEMBER_FAIL_CN[reason] ?? "保存放行规则失败";
      return `（系统：用户同意了这一次「${p.summary}」，但${why}，下次还会问。${retry}做完后用一句话告诉用户这一点。）`;
    }
    store.audit({ kind: "tool", decision: "l2-remembered", sessionKey, summary: p.summary, overrideId: saved.id, existed: saved.existed, voice });
    return `（系统：用户已口头同意「${p.summary}」并要求以后不用再问，已记住（可在管家面板撤销）。${retry}做完后用一句话告诉用户：以后这件事直接做。）`;
  }

  /** 外层 tool_call 放行时登记；外层没有 toolCallId 时 OpenClaw 用 "direct" 作父 id */
  function grantOuter(callId: string | undefined, grant: Omit<OuterGrant, "expiresAt">) {
    outerGrants.set(sanitizeToolCallIdPart(callId ?? "direct"), { ...grant, expiresAt: Date.now() + OUTER_GRANT_TTL_MS });
    if (outerGrants.size > 500) outerGrants.delete(outerGrants.keys().next().value!);
  }

  /** 内层触发时取走对应登记（只能用一次）；对不上或已过期返回 undefined */
  function takeOuterGrant(callId: unknown, toolName: string, params: Record<string, unknown>): OuterGrant | undefined {
    const parent = parentToolCallIdOf(callId);
    if (parent === undefined) return undefined;
    const grant = outerGrants.get(parent);
    if (!grant) return undefined;
    outerGrants.delete(parent);
    const same = grant.toolName === toolName && grant.fingerprint === fingerprintOf(toolName, params);
    return same && grant.expiresAt > Date.now() ? grant : undefined;
  }

  /** before_tool_call 处理器 */
  function beforeToolCall(event: any, ctx: any) {
    const rawParams = (event.params ?? {}) as Record<string, unknown>;
    const rawToolName: string = event.toolName;
    const callId: string | undefined = event.toolCallId ?? ctx?.toolCallId;

    const grant = takeOuterGrant(callId, rawToolName, rawParams);
    if (grant) {
      store.audit({
        kind: "tool",
        tool: rawToolName,
        level: grant.level,
        source: "outer-grant",
        sessionKey: ctx?.sessionKey ?? grant.sessionKey,
        summary: summarize(rawToolName, rawParams),
        paramKeys: Object.keys(rawParams).sort(),
        decision: "allow-inner-dedup",
      });
      return;
    }

    const levels = store.readJson<LevelsFile>("levels.json", defaults);
    const target = rawToolName === "tool_call" ? resolveToolCallTarget(rawParams) : undefined;
    const toolName = target?.toolName ?? rawToolName;
    const params = target?.params ?? rawParams;
    const sessionKey: string | undefined = ctx?.sessionKey;
    const proactive = isProactive(ctx?.runId ?? event.runId, sessionKey);
    // client 工具没有内层钩子；裸名字可能按名字匹配到 client 工具；选择器矛盾时真实目标不确定——三种都拒绝
    const forceL3 = target?.source === "client" || target?.source === "ambiguous" || (!!target && target.source === undefined && !levels.tools[target.toolName]);
    const c: Classification = forceL3
      ? { level: "L3", source: "client", note: "tool_call 的真实目标无法确定（client 来源、选择器矛盾或不在分级表里的裸名字）", rememberable: false, downgraded: false }
      : classify(levels, { toolName, params, derivedPaths: event.derivedPaths, sessionKey }, proactive);
    const summary = summarize(toolName, params);
    const base = {
      kind: "tool",
      tool: toolName,
      level: c.level,
      source: c.source,
      proactive,
      sessionKey,
      summary,
      paramKeys: Object.keys(params).sort(),
      ...(c.category ? { category: c.category } : {}),
      ...(c.overrideId ? { overrideId: c.overrideId } : {}),
      ...(target ? { via: "tool_call", catalogSource: target.source ?? "bare" } : {}),
    };
    /** 只有外层 tool_call 需要登记；直接调用的工具不会再触发内层 */
    const grantIfOuter = () => {
      if (target) grantOuter(callId, { toolName, fingerprint: fingerprintOf(toolName, params), level: c.level, sessionKey });
    };

    if (c.level === "L0" || c.level === "L1") {
      grantIfOuter();
      store.audit({ ...base, decision: "allow" });
      return;
    }

    if (c.level === "L3" && c.source === "client") {
      store.audit({ ...base, decision: "block-refused" });
      return {
        block: true,
        blockReason: `已拒绝：${summary}。原因：${c.note}。不要换写法重试；用工具目录里的完整 id 调用（例如 openclaw:core:exec），或直接调用该工具。`,
      };
    }

    // L2 口头确认；分级表里手写的 L3（v2 默认表没有）也按"先问、不可记住"处理，旧表配新代码时不会把以前要审批的事全拒掉
    const rememberable = c.level === "L2" && c.rememberable;
    const fp = fingerprintOf(toolName, params);
    const p = sessionKey ? pending.get(sessionKey) : undefined;
    if (p && p.approved && p.fingerprint === fp && p.expiresAt > Date.now()) {
      pending.delete(sessionKey!);
      grantIfOuter();
      store.audit({ ...base, decision: "allow-confirmed" });
      return;
    }
    const what = c.category ? CATEGORY_CN[c.category] : "需要确认的操作";
    if (proactive || !sessionKey) {
      store.audit({ ...base, decision: "block-no-confirmer" });
      return {
        block: true,
        blockReason: `需要确认（${what}）：${summary}。这是定时任务或心跳里发起的，没人能当场确认，已拦下并记录。不要重试，也不要换写法；等主人在场时再提。`,
      };
    }
    pending.set(sessionKey, { sessionKey, fingerprint: fp, summary, toolName, params, category: c.category, rememberable, expiresAt: Date.now() + PENDING_TTL_MS, approved: false });
    store.audit({ ...base, decision: "block-need-confirm" });
    const how = rememberable
      ? "用户说「允许 / 可以 / 行」就做这一次；说「以后都允许」就做并记住，下次不再问。"
      : "用户说「允许 / 可以 / 行」就做这一次；这类每次都要问，不要提「以后都允许」。";
    return {
      block: true,
      blockReason: `需要确认（${what}）：${summary}。先用一句口语问用户要不要这么做，不要让用户去微信或网页里点。${how}用户同意后，用完全相同的参数再调用一次；不要换写法绕过。`,
    };
  }

  return { beforeToolCall, onUserTurn, noteRun, isProactive };
}

 *   launch_app{name}  ──execFile──> powershell -File workspace\tools\launch-app.ps1 -Name <name>   （L1）
 *   get_location{}    ──execFile──> powershell -File workspace\tools\get-location.ps1              （L0）
 *   get_weather{city?} ─ 没给城市先跑定位脚本 ─> open-meteo 预报（有城市先查 open-meteo 地名）  （L0）
 *
 * 都不经过 shell，脚本路径固定；launch_app 的 name 只许英文字母、数字、下划线、短横。
 * 工具搜索模式下它们是延期工具：模型用 tool_call（id: launch_app / get_location / get_weather）调用，AGENTS.md 里写明了。
 */

export const APP_NAME_RE = /^[A-Za-z0-9_-]{1,40}$/;
export const LAUNCH_TIMEOUT_MS = 20_000;
export const LOCATION_TIMEOUT_MS = 15_000;
export const WEATHER_TIMEOUT_MS = 8_000;
const BEIJING = { lat: 39.9, lon: 116.41 };

export type RunPs = (scriptPath: string, args: string[], timeoutMs: number) => Promise<{ stdout: string; code: number | null }>;
type FetchLike = (url: string, init: { signal: AbortSignal }) => Promise<{ status: number; text(): Promise<string> }>;

export interface PsToolOptions {
  workspaceDir: string;
  runPs?: RunPs;
  fetchImpl?: FetchLike;
}

/** 固定参数调 Windows PowerShell 跑一个脚本文件；退出码非 0 也照样交回 stdout（脚本用退出码区分错误） */
export const defaultRunPs: RunPs = (scriptPath, args, timeoutMs) =>
  new Promise((resolve) => {
    execFile(
      "powershell.exe",
      ["-NoProfile", "-NonInteractive", "-ExecutionPolicy", "Bypass", "-File", scriptPath, ...args],
      { windowsHide: true, timeout: timeoutMs, encoding: "utf8" },
      (err: any, stdout) => resolve({ stdout: String(stdout ?? ""), code: err ? (typeof err.code === "number" ? err.code : null) : 0 }),
    );
  });

function textResult(text: string, details: Record<string, unknown>) {
  return { content: [{ type: "text", text }], details };
}

/** 脚本只输出一行 JSON；取最后一个能解析的行 */
function lastJson(stdout: string): any {
  const lines = stdout.split(/\r?\n/).map((l) => l.trim()).filter(Boolean);
  for (let i = lines.length - 1; i >= 0; i--) {
    try {
      return JSON.parse(lines[i]);
    } catch {
      // 继续往前找
    }
  }
  return undefined;
}

export function createLaunchAppTool(opts: PsToolOptions) {
  const runPs = opts.runPs ?? defaultRunPs;
  const script = path.join(opts.workspaceDir, "tools", "launch-app.ps1");
  return {
    name: "launch_app",
    label: "Launch app",
    description:
      "Launch a game or program registered in apps.json on the home PC (英雄联盟/LOL, Steam, WeGame, 网易云 ...). " +
      "Input: name = the apps.json key in English, e.g. lol, naraka, bf6, steam, wegame, music. " +
      "Returns ok, or the list of known keys when the name is not registered.",
    parameters: {
      type: "object",
      properties: { name: { type: "string", description: "apps.json 里的英文键，例如 lol" } },
      required: ["name"],
      additionalProperties: false,
    },
    async execute(_toolCallId: string, params: { name?: unknown }) {
      const name = typeof params?.name === "string" ? params.name.trim() : "";
      if (!APP_NAME_RE.test(name)) {
        return textResult("没有启动：name 只能是 apps.json 里的英文键（字母、数字、下划线、短横），例如 lol。", { ok: false, error: "bad_name" });
      }
      const { stdout, code } = await runPs(script, ["-Name", name], LAUNCH_TIMEOUT_MS);
      const r = lastJson(stdout);
      if (!r) return textResult(`没有启动：启动器没有返回结果（退出码 ${code}）。`, { ok: false, error: "no_output", code });
      if (r.ok) return textResult(`已启动 ${r.app}。`, { ok: true, app: r.app });
      const known = Array.isArray(r.known) ? r.known.join("、") : "";
      const text =
        r.error === "not_in_map" ? `没有启动：apps.json 里没有「${name}」。已登记的有：${known}。`
        : r.error === "no_target" ? `没有启动：${r.app} 还没登记路径（${r.note ?? ""}）。`
        : r.error === "missing_file" ? `没有启动：${r.app} 的路径失效了（${r.target}）。`
        : `没有启动：${r.error ?? "未知错误"}。`;
      return textResult(text, { ok: false, error: r.error ?? "unknown", app: r.app });
    },
  };
}

/** 跑定位脚本；失败时按北京 */
async function locate(runPs: RunPs, script: string): Promise<{ lat: number; lon: number; source: string; reason?: string }> {
  const { stdout } = await runPs(script, [], LOCATION_TIMEOUT_MS);
  const r = lastJson(stdout);
  if (r && Number.isFinite(r.lat) && Number.isFinite(r.lon)) return { lat: r.lat, lon: r.lon, source: String(r.source), reason: r.reason };
  return { ...BEIJING, source: "fallback-beijing", reason: "script-failed" };
}

  const script = path.join(opts.workspaceDir, "tools", "get-location.ps1");
  return {
    name: "get_location",
    label: "Get location",
    description:
      "Get the home PC's current latitude/longitude from the Windows location service (not IP-based, so a VPN does not move it). " +

/** WMO 天气代码 → 中文 */
export function weatherCn(code: number): string {
  if (code === 0) return "晴";
  if (code <= 3) return "多云";
  if (code === 45 || code === 48) return "有雾";
  if (code >= 51 && code <= 57) return "毛毛雨";
  if (code >= 61 && code <= 67) return "雨";
  if (code >= 71 && code <= 77) return "雪";
  if (code >= 80 && code <= 82) return "阵雨";
  if (code === 85 || code === 86) return "阵雪";
  if (code >= 95) return "雷雨";
  return "天气不明";
}

const rainy = (code: number) => (code >= 51 && code <= 67) || (code >= 80 && code <= 82) || code >= 95 || (code >= 71 && code <= 77) || code === 85 || code === 86;

export function createGetWeatherTool(opts: PsToolOptions) {
  const runPs = opts.runPs ?? defaultRunPs;
  const doFetch = opts.fetchImpl ?? (globalThis.fetch as unknown as FetchLike);
  const script = path.join(opts.workspaceDir, "tools", "get-location.ps1");
  const getJson = async (url: string) => {
    const res = await doFetch(url, { signal: AbortSignal.timeout(WEATHER_TIMEOUT_MS) });
    if (res.status !== 200) throw new Error(`http_${res.status}`);
    return JSON.parse(await res.text());
  };
  return {
    name: "get_weather",
    label: "Get weather",
    description:
      "Current weather plus today's and tomorrow's forecast (temperature, rain chance, whether to bring an umbrella). " +
      "Input: optional city name (Chinese or pinyin). Without a city it uses the home PC's own location.",
    parameters: {
      type: "object",
      properties: { city: { type: "string", description: "城市名，可省略（省略 = 家这边）" } },
      additionalProperties: false,
    },
    async execute(_toolCallId: string, params: { city?: unknown }) {
      const city = typeof params?.city === "string" ? params.city.trim() : "";
      let lat: number, lon: number, place: string;
      try {
        if (city) {
          const g = await getJson(`https://geocoding-api.open-meteo.com/v1/search?name=${encodeURIComponent(city)}&count=1&language=zh`);
          const hit = g?.results?.[0];
          if (!hit) return textResult(`没查到「${city}」这个地方，换个写法（例如拼音）再试。`, { ok: false, error: "city_not_found" });
          lat = hit.latitude; lon = hit.longitude; place = hit.name ?? city;
        } else {
          const loc = await locate(runPs, script);
          lat = loc.lat; lon = loc.lon; place = loc.source === "fallback-beijing" ? "北京" : "家这边";
        }
        const la = Math.round(lat * 100) / 100, lo = Math.round(lon * 100) / 100;
        const w = await getJson(
          `https://api.open-meteo.com/v1/forecast?latitude=${la}&longitude=${lo}` +
          "&current=temperature_2m,apparent_temperature,weather_code,precipitation" +
          "&daily=weather_code,temperature_2m_max,temperature_2m_min,precipitation_probability_max&timezone=Asia%2FShanghai&forecast_days=2",
        );
        const d = w.daily, cur = w.current;
        const day = (i: number) => `${Math.round(d.temperature_2m_min[i])}到${Math.round(d.temperature_2m_max[i])}度，${weatherCn(d.weather_code[i])}，降水概率${d.precipitation_probability_max[i]}%`;
        const umbrella = [0, 1].some((i) => rainy(d.weather_code[i]) || d.precipitation_probability_max[i] >= 40);
        const text = `${place}：现在${Math.round(cur.temperature_2m)}度（体感${Math.round(cur.apparent_temperature)}度），${weatherCn(cur.weather_code)}；今天${day(0)}；明天${day(1)}。${umbrella ? "要带伞。" : "不用带伞。"}`;
        return textResult(text, { ok: true, place, lat: la, lon: lo, umbrella });
      } catch (err) {
        return textResult("没查到天气：天气服务连不上。改用 get_location 加 web_fetch 查。", { ok: false, error: "fetch_failed", detail: String(err) });
      }
    },
  };
}

- **回答默认不超过两句话。** 内容更长时先说两句要点，再问"要我展开讲吗？"，用户说要才展开。"念给我听""总结一下"也一样，不是全文照念。

主人口头说「以后都允许」时，分级插件 guanjia-guard 往线上分级表

    读最新文件 → 只改 overrides（别的键原样保留）→ 写同目录临时文件 → os.replace 原子替换
    只删 source == "remembered" 的条目；主人手写的 overrides、rules、tools 一律不动

插件每次工具调用都重新读这个文件，所以撤销立即生效，不用重启网关。

from __future__ import annotations

import json
import os
import time
from pathlib import Path

LEVELS_PATH = Path.home() / ".openclaw" / "workspace" / "guanjia" / "levels.json"
REMEMBERED = "remembered"
_REPLACE_RETRIES = 5


def load_levels(path: Path = LEVELS_PATH) -> dict:
    """读分级表；文件缺失或损坏时抛 ValueError（不能拿空表覆盖主人的文件）。"""
    try:
        text = path.read_text(encoding="utf-8-sig")
        data = json.loads(text)
    except (OSError, ValueError) as e:
        raise ValueError(f"levels.json 读不出来：{e}") from e
    if not isinstance(data, dict):
        raise ValueError("levels.json 顶层不是对象")
    return data


def _dumps(v) -> str:
    """与 JS 的 JSON.stringify 相同：不转义中文、紧凑分隔符（嵌套的 also 条件也要逐字节一致）。"""
    return json.dumps(v, ensure_ascii=False, separators=(",", ":"))


def _one_line(v) -> str:
    if not isinstance(v, dict):
        return _dumps(v)
    return "{ " + ", ".join(f"{_dumps(k)}: {_dumps(x)}" for k, x in v.items()) + " }"


def format_levels(levels: dict) -> str:
    """与插件 remember.ts 的 formatLevelsJson 同一排版：顶层每键一行，tools 每个工具一行，rules / overrides 每条一行。"""
    lines = []
    keys = list(levels)
    for i, k in enumerate(keys):
        v = levels[k]
        if isinstance(v, list):
            body = "[]" if not v else "[\n" + ",\n".join("    " + _one_line(x) for x in v) + "\n  ]"
        elif isinstance(v, dict):
            body = "{}" if not v else "{\n" + ",\n".join(f"    {_dumps(kk)}: {_dumps(vv)}" for kk, vv in v.items()) + "\n  }"
        else:
            body = _dumps(v)
        lines.append(f"  {_dumps(k)}: {body}{',' if i < len(keys) - 1 else ''}")
    return "{\n" + "\n".join(lines) + "\n}\n"


def _atomic_write(path: Path, text: str) -> None:
    """同目录临时文件 + os.replace。临时文件名带 pid 和时间，不会和插件的临时文件撞名。
    Windows 上插件恰好在读这个文件时 os.replace 可能 PermissionError，短暂重试。"""
    tmp = path.with_name(f"{path.name}.panel-{os.getpid()}-{time.time_ns()}.tmp")
    tmp.write_text(text, encoding="utf-8", newline="\n")
    try:
        for i in range(_REPLACE_RETRIES):
            try:
                os.replace(tmp, path)
                return
            except PermissionError:
                if i == _REPLACE_RETRIES - 1:
                    raise
                time.sleep(0.05)
    finally:
        if tmp.exists():
            tmp.unlink()


def list_remembered(path: Path = LEVELS_PATH) -> list[dict]:
    """已记住的放行，按记住的时间先后。只返回面板要显示的字段。"""
    items = []
    for o in load_levels(path).get("overrides") or []:
        if isinstance(o, dict) and o.get("source") == REMEMBERED and o.get("id"):
            items.append({k: o.get(k) for k in ("id", "summary", "tool", "param", "pattern", "createdAt", "expiresAt")})
    items.sort(key=lambda x: str(x.get("createdAt") or ""))
    return items


def revoke(override_id: str, path: Path = LEVELS_PATH) -> tuple[bool, str]:
    """按 id 撤销一条已记住的放行。返回 (成功?, 原因)：
    removed / not_found / not_remembered（id 对上了但不是口头记住的，不许删）/ unreadable。"""
    try:
        levels = load_levels(path)
    except ValueError:
        return False, "unreadable"
    overrides = levels.get("overrides") or []
    hit = next((o for o in overrides if isinstance(o, dict) and o.get("id") == override_id), None)
    if hit is None:
        return False, "not_found"
    if hit.get("source") != REMEMBERED:
        return False, "not_remembered"
    levels["overrides"] = [o for o in overrides if o is not hit]
    _atomic_write(path, format_levels(levels))
    return True, "removed"


def sync_defaults(defaults: Path, path: Path = LEVELS_PATH) -> int:
    """上线用：线上表换成仓库默认表，但保留线上已有的全部 overrides（已记住的和主人手写的）。
    线上文件不存在时直接用默认表；存在但读不出来时抛 ValueError（让操作的人决定）。返回保留的条数。"""
    new = load_levels(defaults)
    kept = load_levels(path).get("overrides") or [] if path.exists() else []
    new["overrides"] = list(kept)
    _atomic_write(path, format_levels(new))
    return len(kept)


def _main(argv: list[str]) -> int:
    """python -m guanjia.remembered_overrides list [levels.json]
    python -m guanjia.remembered_overrides revoke <id> [levels.json]
    python -m guanjia.remembered_overrides sync-defaults <defaults.json> [levels.json]"""
    if argv[:1] == ["list"]:
        for item in list_remembered(Path(argv[1]) if len(argv) > 1 else LEVELS_PATH):
            print(json.dumps(item, ensure_ascii=False))
        return 0
    if argv[:1] == ["revoke"] and len(argv) >= 2:
        ok, reason = revoke(argv[1], Path(argv[2]) if len(argv) > 2 else LEVELS_PATH)
        print(f"revoke {argv[1]}: {reason}")
        return 0 if ok else 1
    if argv[:1] == ["sync-defaults"] and len(argv) >= 2:
        n = sync_defaults(Path(argv[1]), Path(argv[2]) if len(argv) > 2 else LEVELS_PATH)
        print(f"synced overrides={n}")
        return 0
    print(_main.__doc__)
    return 2


if __name__ == "__main__":
    import sys
